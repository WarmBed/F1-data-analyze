# 🔲 Workspace 自動平鋪功能 - 快速指南

## ✨ 功能說明

當您載入一個已保存的 Workspace 時，系統會**自動**將所有分頁中的視窗進行平鋪排列（Tile Windows），無需手動操作。

## 📝 使用步驟

### 1. 保存 Workspace
```
File > Save Workspace
→ 輸入名稱
→ 點擊「儲存」
```

### 2. 載入 Workspace
```
File > Load Workspace
→ 選擇要載入的 Workspace
→ 點擊「載入」
```

### 3. 自動平鋪 ✅
系統會自動：
- ✅ 重建所有分頁和視窗
- ✅ 平鋪每個分頁的視窗
- ✅ 顯示載入成功訊息

```
[WORKSPACE] 📐 平鋪分頁 'Tab 1': 3 個視窗

```

## 💡 注意事項

1. **HOME 分頁不會被平鋪** - 只處理分析分頁
2. **隱藏視窗會被跳過** - 只平鋪可見視窗
3. **自動執行** - 無需手動點擊「Tile Windows」

## 🔍 如何驗證

1. 保存一個有多個視窗的 Workspace
2. 關閉 F1T GUI
3. 重新啟動並載入該 Workspace
4. 觀察視窗是否自動平鋪排列
5. 查看終端的 `[WORKSPACE]` 日誌

## ❓ 常見問題

**Q: 為什麼某些分頁沒有平鋪？**  
A: 可能該分頁沒有可見視窗，或者是 HOME 分頁。

**Q: 可以關閉自動平鋪嗎？**  
A: 目前是自動執行，未來可能會添加配置選項。

**Q: 平鋪後可以手動調整視窗大小嗎？**  
A: 可以！平鋪只是初始排列，之後可自由調整。
