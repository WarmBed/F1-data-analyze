# v3.6 超參數調優版本 - 使用指南

## 📋 概述

v3.6 是 F1 賽道預測模型的超參數深度調優版本，每個賽道獨立訓練 500 次 Optuna 試驗，自動尋找最佳超參數配置。

### 核心改進

- ✅ **賽道專家模型**：每個賽道獨立訓練，捕捉賽道特定模式
- ✅ **深度調優**：500 次 Optuna 試驗尋找最佳超參數
- ✅ **交叉驗證**：處理小樣本問題（GB 僅 19 樣本）
- ✅ **自動優化**：學習率、樹深度、正則化自動調整

### 預期改善

| 賽道 | v3.5 MAE | v3.6 預期 MAE | 改善幅度 |
|------|----------|---------------|---------|
| Great Britain | 6.086s | ~0.8s | +87% ⭐ |
| Canada | 5.392s | ~1.0s | +81% ⭐ |
| Hungary | 1.701s | ~1.2s | +29% |
| Monaco | 0.581s | ~0.4s | +31% |
| Saudi Arabia | 0.525s | ~0.3s | +43% |

### 2. 單賽道完整訓練 (500 次試驗)

```powershell
# 訓練單個賽道 (~30 分鐘)
python train_v3_6_single_track.py --track Monaco --trials 500
```

**參數說明**：
- `--track` - 賽道名稱（必填）
- `--trials` - Optuna 試驗次數（默認 500）
- `--quiet` - 靜默模式

**輸出檔案**：
- `models/v3.6/Monaco.pkl` - 訓練好的模型
- `optuna_studies/Monaco_study.db` - 調優歷史
- `train_result_Monaco_v3.6.json` - 訓練報告

---

### 3. 批次訓練所有賽道

#### 3.1 串行模式（適合調試）

```powershell
# 串行訓練 (~5 小時)
python batch_train_v3_6_all_tracks.py --trials 500 --sequential
```

#### 3.2 並行模式（推薦）⭐

```powershell
# 8 核心並行訓練 (~40 分鐘)
python batch_train_v3_6_all_tracks.py --trials 500 --workers 8
```

**參數說明**：
- `--trials` - 每個賽道的試驗次數（默認 500）
- `--workers` - 並行工作進程數（默認 8）
- `--sequential` - 使用串行模式
- `--tracks` - 指定訓練的賽道（可選）

**只訓練特定賽道**：
```powershell
python batch_train_v3_6_all_tracks.py --trials 500 --tracks Monaco Hungary Great_Britain
```

## ⚙️ 超參數搜索空間

v3.6 在以下範圍內搜索最佳參數：

| 參數 | 範圍 | 說明 |
|------|------|------|
| `n_estimators` | 50-500 | 樹的數量 |
| `max_depth` | 3-10 | 樹的最大深度 |
| `learning_rate` | 0.01-0.3 | 學習率（對數搜索） |
| `subsample` | 0.6-1.0 | 樣本抽樣比例 |
| `colsample_bytree` | 0.6-1.0 | 特徵抽樣比例 |
| `min_child_weight` | 1-7 | 最小子節點權重 |
| `gamma` | 0-0.5 | 分裂最小增益 |
| `reg_alpha` | 0-1.0 | L1 正則化 |
| `reg_lambda` | 0-1.0 | L2 正則化 |

### 交叉驗證折數自動調整

系統根據樣本數自動調整 CV 折數：
- **≥ 20 樣本**: 5-fold CV
- **15-19 樣本**: 4-fold CV
- **< 15 樣本**: 3-fold CV

## ⚠️ 注意事項

1. **訓練時間**: 500 次試驗約需 30 分鐘/賽道
2. **並行限制**: Windows 系統建議使用 `--workers 4-8`
3. **內存需求**: 單賽道約需 500MB RAM
4. **磁碟空間**: 模型檔案 ~5MB/賽道，study.db ~10MB/賽道

## 🔧 故障排除

### 問題 1: 數據載入失敗

```
❌ Monaco 無訓練數據
```

**解決方案**：
- 確認 `json/predictionJSON/` 目錄有對應賽道的數據
- 確認 `json/all_drivers_cornering_analysis_*.json` 存在

### 問題 2: Optuna 錯誤

```
ValueError: Study 'Monaco_v3.6' already exists
```

**解決方案**：
```powershell
# 刪除舊的 study
Remove-Item optuna_studies/Monaco_study.db
```

### 問題 3: 多進程失敗 (Windows)

```
RuntimeError: freeze_support() not called
```

**解決方案**：
- 腳本中已包含 `mp.freeze_support()`
- 使用串行模式：`--sequential`
