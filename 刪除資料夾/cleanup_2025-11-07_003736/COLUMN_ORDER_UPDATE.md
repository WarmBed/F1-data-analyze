| 8 | Q 名次 | `actual_q_rank` | 🟢 **綠色粗體** | **1** |
| 9 | 變化 | `rank_change` | 🟢🔴⚪ **顏色標示** | **+8**, **-6**, **→** |

### 🎨 顏色方案

#### 變化欄位（第 9 欄）
```
+8, +2, +1  → 🟢 QColor(0, 150, 0)   深綠色粗體 (進步)
-6, -3, -1  → 🔴 QColor(200, 0, 0)   深紅色粗體 (退步)
→           → ⚪ QColor(100, 100, 100) 灰色 (持平)
N/A         → ⚫ QColor(120, 120, 120) 淺灰色 (無結果)
```

#### Q 名次欄位（第 8 欄）
```
1, 2, 3...  → 🟢 QColor(0, 100, 0) 綠色粗體
```

#### △ FP3 欄位（第 6 欄）
```
根據 improvement 值自動計算梯度背景色
正值 = 暖色調 (橙/紅)
負值 = 冷色調 (藍/綠)
```

#### 車手/車隊欄位（第 1-2 欄）
```
使用 color_palette_provider 獲取車手專屬背景色
例如：VER = 深藍色, LEC = 紅色, HAM = 青綠色
```
