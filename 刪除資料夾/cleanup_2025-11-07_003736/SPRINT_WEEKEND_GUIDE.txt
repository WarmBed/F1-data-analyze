【Session Fallback 機制】
當使用者指定 -s FP3 但賽事無 FP3 session 時（Sprint 週末），系統會：

1. 檢測到 FP3 不存在
2. 自動嘗試載入 Sprint session
3. 顯示 "[SUCCESS] 自動降級：使用 Sprint 數據（替代 FP3）"
4. 繼續執行分析功能

【修改的檔案】
✅ CLI_modules/cli/analyzer/f1_analysis_modular_main.py
   → load_race_data() 方法添加 FP3→Sprint 自動降級

【原始問題】
Austria、Brazil、Qatar 採用 Sprint 週末，無 FP3 session
→ 功能 47/70 請求 FP3 時會報錯: "Session type 'FP3' does not exist"

【解決方案】
實現 Session Fallback 機制：
1. 檢測 FP3 不存在
2. 自動嘗試 Sprint session
3. 使用 Sprint 數據繼續分析

【實際效果】
執行: python f1_analysis_modular_main.py -f 47 -y 2024 -r Austria -s FP3

[SUCCESS] 自動降級：使用 2024 Austria Sprint 數據（替代 FP3）
