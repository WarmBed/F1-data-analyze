#### 參考資料

- **特徵差異**:
  - v3.5: 17 個基礎特徵
  - v3.8.1: 17 基礎特徵 + 2 歷史特徵
    - `driver_historical_track_performance`: 車手在該賽道的歷史平均表現
    - `driver_track_performance_gap`: 當前與歷史表現的差距

#### 關鍵實現要點

1. **歷史特徵計算邏輯**（參考 batch_train_all_tracks_v3.8.1.py）:
   ```python
   # 使用 2022-2024 訓練數據計算歷史基準
   historical_baselines = {}
   for driver in unique_drivers:
       historical_data = train_data[train_data['driver'] == driver]
       if len(historical_data) > 0:
           historical_baselines[driver] = historical_data['quali_time'].mean()
       else:
           # 新車手使用賽道平均
           historical_baselines[driver] = train_data['quali_time'].mean()
   
   # 計算 2025 特徵
   features['driver_historical_track_performance'] = historical_baselines[driver]
   features['driver_track_performance_gap'] = current_quali_time - historical_baselines[driver]
   ```

2. **數據載入流程**:
   - 讀取 `fp_q_data_2025_*.json` → 基礎特徵 (1-17)
   - 讀取 `all_drivers_cornering_analysis_2025_*.json` → 彎角速度特徵
   - 載入 2022-2024 訓練數據 → 計算歷史特徵 (18-19)
   - 合併為完整的 19 維特徵向量

3. **預測執行**:
   ```python
   for track in tracks:
       model = joblib.load(f'models/track_specific_v3/{track}.pkl')
       X_test = prepare_features_v381(track, year=2025)  # 19 features
       predictions = model.predict(X_test)
   ```

4. **輸出格式**（與 v3.5 一致）:
   ```json
   {
     "Azerbaijan": {
       "predictions": [
         {
           "driver": "VER",
           "actual_time": 103.009,
           "predicted_time": 102.856,
           "error": -0.153,
           "actual_rank": 1,
           "predicted_rank": 1,
           "rank_diff": 0
         }
       ],
       "metrics": {
         "mae": 0.543,
         "rmse": 0.687,
         "r2": 0.912
       }
     }
   }
   ```
