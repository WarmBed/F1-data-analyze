## 🔬 成功與失敗模式分析

### 成功模式 (Saudi Arabia, Japan, Italy, Azerbaijan)

**共同特徵**:
1. ✅ **改進率穩定**: < 5% 的溫和改進
   - Saudi Arabia: +1.89%
   - Japan: +1.36%
   - Italy: +0.74%
   - Azerbaijan: +4.82% (技術型賽道例外)

2. ✅ **天氣一致性**: FP3 和 Q 天氣條件相似
   - 無極端天氣變化 (雨天切換)

3. ✅ **改進率特徵有效**: 權重適中或高
   - Azerbaijan: 80.44% (最高)
   - Italy: 28.93%
   - Japan: 17.90%

4. ✅ **訓練數據完整**: 無過度清洗
   - 保留足夠多樣性樣本

**預測特點**:
- 時間誤差 < 2%
- 排名誤差 ≤ 4
- Top5 準確率 ≥ 80%

---

### 失敗模式 (Great Britain, Canada, Hungary)

**共同特徵**:
1. ❌ **過度數據清洗**: 移除全部或大部分異常年份
   - Great Britain: 移除全部 2022 (20/39)
   - Hungary: 移除全部 2022 (20/60)
   - Canada: 輕微清洗 (2/59)

2. ❌ **極端改進率**: 訓練集與驗證集差異大
   - Great Britain 2022: -14.334s (Q 下雨)
   - Hungary 2022: +26.007s (FP3 受干擾)
   - Canada: +3.62% (高於平均)

3. ❌ **改進率特徵失效**: 權重過低或無效
   - Canada: 1.52% (幾乎無用)
   - Great Britain: 9.62% (不足)

4. ❌ **泛化失敗**: 模型無法處理未見過的條件
   - 訓練性能優秀但驗證崩潰

**預測特點**:
- 時間誤差 > 5% (系統性偏差)
- 預測值缺乏區分度 (全部相同或接近)
- Top5 準確率 ≤ 40%
- Spearman 低或負相關

## 💡 關鍵洞察

### 1. 預測區分度是 Top5 準確率的關鍵

**問題案例**:
- **Great Britain**: 所有 Top5 車手預測時間 91.083s (完全相同)
- **Canada**: 所有 Top5 車手預測排名 8.5 (完全相同)

**結論**: 即使 MAE 可接受，如果預測值缺乏區分度，Top5 預測必然失敗

**解決方案**: 監測預測標準差，如果 `std(predicted_times) < 0.5s`，則切換至 v3.4 或混合模型

---

### 2. 過度數據清洗 ≠ 更好的泛化

**訓練性能提升 vs 驗證性能下降**:
- Great Britain 訓練: MAE 0.321s → 0.056s (-82.6%)
- Great Britain 驗證: Spearman 0.347 → 0.209 (-39.8%)

**結論**: 移除全部異常數據導致模型無法學習異常模式，遇到新異常時完全失效

**解決方案**: 保留部分異常樣本 + 添加異常標記特徵

---

### 3. 用戶天氣假設得到驗證 ✅

**用戶原假設**: "FP3沒下雨 但Q下雨"

**數據證據**:
- GB 2022: Q 比 FP3 慢 -14.334s → 支持「Q 下雨」
- Hungary 2022: Q 比 FP3 快 +26.007s → 支持「FP3 受干擾」
- GB/Hungary 2025 驗證退化 → 可能再次出現天氣異常

**結論**: 天氣變化是改進率異常的核心原因，需要天氣特徵建模

---

### 4. 改進率特徵適用性有賽道差異

**高效賽道**: 技術型 (Azerbaijan, Italy, Japan)
- 賽道演變明顯，FP3→Q 改進可預測

**低效賽道**: 街道/低抓地力 (Canada, Monaco)
- 賽道演變不明顯，改進率特徵貢獻低

**結論**: 需要賽道分類建模，針對不同類型賽道使用不同特徵權重

    # 4. 默認使用 v3.5

def ensemble_prediction(race_name, fp3_data):
    # v3.4 預測 (處理異常)

    if race_name in ['Great Britain', 'Hungary']:

        weight_v34 = 0.3

    final_pred = weight_v34 * pred_v34 + weight_v35 * pred_v35
    return final_pred
