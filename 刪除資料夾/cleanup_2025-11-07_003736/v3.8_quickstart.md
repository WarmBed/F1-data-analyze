### 移除的無效特徵 ❌

```python
# 1. track_avg_improvement_rate - 常數特徵
# 問題：同一賽道所有樣本值相同（無變異性）
# Japan: 0.0136 → 所有 59 個樣本都是 0.0136

# 2. adjusted_ideal_lap - 線性冗餘
# 問題：= ideal_lap * (1 - track_rate)
# 排序與 ideal_lap 完全相同，不提供新資訊

# 3. driver_historical_improvement - 資訊冗餘
# 問題：= is_top_driver * 0.002
# 完全由 is_top_driver 決定，無獨立資訊
```

features = [

## 🎓 核心概念

### 為何移除這三個特徵？

#### 1. 常數特徵無法分裂節點
```
XGBoost 決策樹需要特徵有變異性才能分裂：
- track_avg_improvement_rate = 0.0136（所有樣本相同）
- 無法區分車手 → 重要性 = 0
```

#### 2. 線性變換不改變排序
```
排序資訊才是關鍵：
- adjusted_ideal_lap = ideal_lap * 0.9864
- 排序完全相同 → XGBoost 只保留 ideal_lap
```

#### 3. 完全相關特徵是冗餘的
```
決定係數 R² = 1.0：
- driver_historical_improvement = is_top_driver * 0.002
- 不提供獨立資訊 → 自動忽略
```
