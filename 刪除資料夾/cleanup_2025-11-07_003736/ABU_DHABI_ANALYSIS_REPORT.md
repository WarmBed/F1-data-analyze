# 阿布達比（Abu Dhabi）效能分析報告

**分析時間：** 2025-01-09  
**模型版本：** v3.0  
**對比基準：** 墨西哥（Mexico）- 優秀表現賽道

---

## 📊 執行摘要

阿布達比賽道在 v3.0 模型中表現為**良好水準**（R² 0.5467），但未達到**優秀水準**（R² >0.8）。通過與表現優秀的墨西哥賽道對比，發現**特徵分佈嚴重失衡**是導致效能不足的根本原因。

### 核心問題

1. **S2 過度主導**：單一特徵占比 46.85%（墨西哥僅 28.62%）
2. **S1 重要性崩塌**：僅 6.41%（墨西哥為 29.55%，下降 78.3%）
3. **測試誤差偏高**：MAE 0.475秒 vs 墨西哥 0.379秒（高出 25.3%）
4. **R² 顯著落後**：0.5467 vs 墨西哥 0.8044（差距 0.26，落後 32%）

## 🚨 關鍵發現：四大效能瓶頸

### 發現 1：S2 過度主導

**詳情：**
- 阿布達比 S2 占比 **46.85%**（墨西哥 28.62%）
- 單一特徵超過總重要性的**近 50%**

**影響：**
- 模型過度依賴 S2，忽略其他 7 個特徵
- 降低模型的泛化能力（測試 R² 僅 0.55）
- S2 數據的任何噪聲都會被放大

**可能原因：**
- 阿布達比 S2 的變異性遠高於 S1/S3
- S2 可能包含決定性的技術路段（例如低速技術彎組合）
- 數據收集或處理過程中 S2 特徵更穩定

### 發現 2：S1 重要性崩塌

**詳情：**
- 阿布達比 S1 僅 **6.41%**（墨西哥 29.55%）
- 下降幅度高達 **78.3%**

**影響：**
- S1 對排位賽的預測能力被嚴重低估
- 損失了 S1 路段的車手差異資訊
- 可能存在數據品質問題

**可能原因：**
- S1 數據中存在缺失值或離群值
- S1 與 S2 高度相關，被 S2 壓制
- 阿布達比 S1 路段變化較小，區分度不足

### 發現 3：Ideal Lap 占比異常高

**詳情：**
- 阿布達比 16.82%（墨西哥 7.35%）
- 高出 **128.8%**

**影響：**
- Ideal Lap = S1 + S2 + S3，存在**多重共線性**
- 特徵之間相互抵消，降低模型效能
- 實際預測能力被虛增（特徵重疊）

**可能原因：**
- S1+S2+S3 的直接加總無法完全代表 Ideal Lap
- 阿布達比的 Lap 時間變異性與 Sector 時間不同步
- 模型嘗試用 Ideal Lap 補償 S1 的不足

### 發現 4：測試誤差偏高

**詳情：**
- 測試 MAE **0.475秒**（墨西哥 0.379秒）
- 高出 **25.3%**

**影響：**
- 預測誤差大，實用性降低
- 泛化能力不足，對新數據敏感
- 過擬合風險（訓練 MAE 反而更低）

**可能原因：**
- 特徵失衡導致模型記憶訓練集而非學習規律
- 測試集中可能存在與訓練集分佈不同的樣本
- 阿布達比賽道特性年份間變化較大（例如賽道改建）

## 💡 改進建議

### 1. 數據品質檢查（高優先級）

**行動項目：**
- 檢查阿布達比 2022-2024 年份的 **S1 原始數據**
- 確認是否存在：
  - 缺失值（NA 或 0 值）
  - 極端離群值（例如 S1 時間異常高/低）
  - 數據收集錯誤（例如 S1 與 S2 時間交換）

**驗證方法：**
```python
# 檢查 S1 數據分佈
import pandas as pd
df = pd.read_json('json/track_feature_Japan_2023_Q.json')
print(df['ideal_s1'].describe())
print(df['ideal_s1'].isna().sum())
```

### 2. 特徵工程優化（高優先級）

**方案 A：移除冗餘特徵**
- **移除 `ideal_lap`**：與 S1+S2+S3 高度相關（r > 0.95）
- **效果預期**：降低多重共線性，強化 S1 的重要性

**方案 B：增加交互特徵**
- **新增 `s1_s2_ratio`**：S1 / S2 比率（捕捉路段平衡）
- **新增 `sector_variance`**：std(S1, S2, S3)（捕捉一致性）
- **效果預期**：提供更多區分性資訊

**方案 C：特徵標準化**
- **對 Sector 時間進行歸一化**：確保 S1/S2/S3 在相同尺度
- **效果預期**：避免 S2 因絕對數值較大而主導

### 3. 模型參數調整（中優先級）

**當前參數：**
```python
XGBRegressor(
    n_estimators=50,
    max_depth=3,
    learning_rate=0.1,
    random_state=42
)
```

**建議調整：**
```python
XGBRegressor(
    n_estimators=100,        # ↑ 增加樹數量
    max_depth=4,             # ↑ 允許更複雜交互
    learning_rate=0.05,      # ↓ 降低學習率（配合更多樹）
    min_child_weight=5,      # ↑ 防止過擬合於單一特徵
    subsample=0.8,           # 新增：行採樣降低過擬合
    colsample_bytree=0.8,    # 新增：列採樣平衡特徵
    random_state=42
)
```

**效果預期：**
- `min_child_weight` 增加 → 降低 S2 的過度主導
- `max_depth` 增加 → 捕捉 S1 與其他特徵的交互
- 採樣參數 → 提高泛化能力（降低測試 MAE）

### 4. 樣本分佈分析（低優先級）

**檢查項目：**
- 各年份樣本量是否均衡（2022/2023/2024）
- 各車隊是否有代表性（避免偏向某個車隊）
- 是否存在賽道改建導致的數據斷層

**驗證方法：**
```python
# 檢查年份分佈
df_grouped = df.groupby('year').size()
print(df_grouped)

# 檢查車隊分佈
df_team = df.groupby('team').size()
print(df_team)
```

## 🎯 預期改進效果

### 短期目標（移除 ideal_lap）
