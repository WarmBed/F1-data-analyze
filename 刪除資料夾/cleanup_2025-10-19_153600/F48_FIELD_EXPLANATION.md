# F48 加速度分析欄位說明文檔

## 📊 表格欄位詳解

### 1. 排名
- **說明**：按照資料原始順序或排序後的名次
- **用途**：快速識別車手位置

### 2. 車手
- **說明**：車手代碼（3字母）
- **格式**：VER, HAM, LEC 等
- **背景色**：車隊配色

### 3. 車隊
- **說明**：車隊名稱
- **格式**：Red Bull Racing, Mercedes, Ferrari 等
- **背景色**：車隊配色

### 4. 最高速度
- **說明**：車手在賽道段內達到的最高速度
- **單位**：km/h
- **顏色編碼**：
  - 綠色：> 325 km/h（極快）
  - 藍色：300-325 km/h（快）
  - 黑色：< 300 km/h（一般）

### 5. ⭐ 加速時間（賽道段）
- **說明**：車手在指定賽道段距離範圍內完成加速所需的時間
- **計算方式**：
  ```
  起點：segment_distance_start（例如 3547.1m）
  終點：segment_distance_end（例如 4101.2m）
  加速時間 = 終點時間 - 起點時間
  ```
- **單位**：秒（s）
- **範例**：HAM 9.759s，LEC 10.120s
- **邏輯**：
  - ✅ 時間越短 = 性能越好
  - ✅ 升序排列（最快在前）
- **與舊版本的差異**：
  - ❌ 舊版本：使用速度範圍（80→270 km/h）計算時間
  - ✅ 新版本：使用實際賽道段距離範圍計算時間

### 6. ⭐ 平均加速度（賽道段）
- **說明**：車手在賽道段內的平均加速度
- **計算公式**：
  ```
  速度變化（m/s）= (結束速度 - 起始速度) / 3.6
  平均加速度 = 速度變化 / 加速時間
  ```
- **單位**：m/s²
- **範例**：HAM 5.24 m/s²，LEC 4.97 m/s²
- **邏輯**：
  - ✅ 加速度越大 = 性能越好
  - ✅ 降序排列（最大在前）
- **物理意義**：
  - 1 m/s² ≈ 0.1G（重力加速度）
  - 5 m/s² ≈ 0.5G（F1 典型加速度）

### 7. ⭐ 速度增益（賽道段）
- **說明**：車手在賽道段內實際增加的速度
- **計算公式**：
  ```
  速度增益 = segment_end_speed_kmh - segment_start_speed_kmh
  ```
- **單位**：km/h
- **範例**：
  - HAM: 103 → 287 km/h，速度增益 = **184 km/h**
  - LEC: 108 → 289 km/h，速度增益 = **181 km/h**
- **邏輯**：
  - ✅ 增益越大 = 在該段加速越多
  - ✅ 降序排列（最大在前）
- **Tooltip 顯示**：
  - 滑鼠懸停顯示：「103 → 287 km/h」
  - 幫助用戶理解速度變化過程

### 8. ⭐ 加速性能視覺化
- **說明**：棒狀圖視覺化加速時間
- **視覺設計**：
  ```
  ┌─────────────────────────────────────┐
  │  ▓▓▓▓▓▓▓▓▓▓░░░░░  9.759s          │
  │  └─ 深藍 ─┘└灰┘   (最高速時間)     │
  └─────────────────────────────────────┘
  ```
- **棒狀圖邏輯**：
  - **棒狀圖長度**：基於 `segment_accel_time`（賽道段加速時間）
  - **顏色**：深藍色實心（代表加速階段）
  - **長度計算**：
    ```
    相對比例 = (車手時間 - 最快時間) / (最慢時間 - 最快時間)
    棒狀圖長度 = 最大寬度 × 相對比例
    ```
  - ✅ **時間越短 = 棒狀圖越短 = 性能越好**

### 🎯 排序邏輯總結

#### CLI 計算邏輯
```python
def _calculate_segment_acceleration(self, car_data, segment_distance_start, segment_distance_end):
    # 1. 找到最接近起點和終點的數據索引
    start_idx = (car_data['Distance'] - segment_distance_start).abs().idxmin()
    end_idx = (car_data['Distance'] - segment_distance_end).abs().idxmin()
    
    # 2. 提取速度和時間
    start_speed = car_data.loc[start_idx, 'Speed']
    end_speed = car_data.loc[end_idx, 'Speed']
    start_time = car_data.loc[start_idx, 'Time'].total_seconds()
    end_time = car_data.loc[end_idx, 'Time'].total_seconds()
    
    # 3. 計算
    time_diff = end_time - start_time
    speed_change_ms = (end_speed - start_speed) / 3.6  # km/h → m/s
    avg_acceleration = speed_change_ms / time_diff
    
    return {
        "time_seconds": time_diff,
        "avg_acceleration_ms2": avg_acceleration,
        "start_speed_kmh": start_speed,
        "end_speed_kmh": end_speed,
        "speed_gain_kmh": end_speed - start_speed
    }
```

### ❓ 常見問題

**Q1: 為什麼 HAM 的加速時間較長但加速度更快？**
A: 舊版本使用速度範圍（80→270 km/h）計算，導致數據矛盾。新版本使用實際賽道段距離，數據邏輯一致。

**Q2: 速度增益大 = 性能好嗎？**
A: 不一定。速度增益大可能是因為起始速度低。真正的性能指標是**平均加速度**和**加速時間**。

**Q3: 為什麼 LEC 起始速度最高但性能最差？**
A: 起始速度高可能代表前一段彎道出彎速度快，但在直線段的加速能力不如其他車手。

**Q4: 棒狀圖長短代表什麼？**
A: 棒狀圖長度代表加速時間。棒越短 = 時間越短 = 性能越好。
