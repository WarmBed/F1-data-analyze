## 🐛 已知問題檢查

### ❌ Bug 1: 後綴仍顯示中文
**症狀**: 切換語言後，後綴仍然顯示 `[未開賽]`

**可能原因**:
1. 翻譯鍵未正確添加到 `gui_i18n.py`
2. GUI 未重新載入翻譯

**解決方案**:
```powershell
# 重新啟動 GUI
python f1t_gui_main.py
```

---

### ❌ Bug 2: 後綴重複顯示
**症狀**: 顯示為 `United States (2025-10-26) [未開賽] [Upcoming]`

**可能原因**: `_format_race_display()` 邏輯錯誤，重複添加後綴

**檢查方法**:
```python
# 查看 f1t_gui_main.py line 2393
suffix = tr("season_calendar_upcoming_suffix", "[未開賽]")
if suffix and suffix in event.display_label:
    return event.display_label  # 已有後綴，不重複添加
```
