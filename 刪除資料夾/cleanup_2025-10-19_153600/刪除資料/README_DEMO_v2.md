# 🏎️ F1T DEMO - 改進版使用說明

**版本**: 2.0  
**更新日期**: 2025-10-11  
**改進內容**: 優化視窗添加邏輯 + 新增標籤頁按鈕

---

## 🎯 主要改進

### ✅ 改進 1: 視窗添加到當前標籤頁

**之前的行為**:
- 點擊分析按鈕 → 自動創建新標籤頁
- 每個分析類型佔用一個標籤頁

**現在的行為**:
- 點擊分析按鈕 → 在**當前標籤頁**的 MDI 區域添加視窗
- 可以在同一標籤頁中添加多個不同類型的分析視窗
- 更符合實際使用習慣

### ✅ 改進 2: 手動創建新標籤頁

**新增功能**:
- 頂部工具欄新增 **"➕ 新增標籤頁"** 按鈕
- 點擊後顯示選單，選擇要創建的標籤頁類型
- 用戶完全控制何時創建新標籤頁

---

## 🚀 使用流程

### 工作流程 1: 單標籤多視窗模式

```
1. 點擊 "➕ 新增標籤頁" → 選擇 "🌧️ 降雨分析"
   ✅ 創建一個空白的降雨分析工作區

2. 點擊 "🌧️ 降雨分析" 按鈕（頂部）
   ✅ 在當前標籤頁添加降雨分析視窗

3. 點擊 "⏱️ 圈速分析" 按鈕
   ✅ 在同一標籤頁再添加圈速分析視窗

4. 點擊 "🏁 輪胎策略" 按鈕
   ✅ 繼續在同一標籤頁添加輪胎策略視窗

結果: 一個標籤頁內有 3 個不同類型的分析視窗
```

### 工作流程 2: 多標籤專項模式

```
1. 點擊 "➕ 新增標籤頁" → 選擇 "🌧️ 降雨分析"
   ✅ 創建降雨分析標籤頁

2. 點擊 "➕ 新增標籤頁" → 選擇 "⏱️ 圈速分析"
   ✅ 創建圈速分析標籤頁

3. 點擊 "➕ 新增標籤頁" → 選擇 "🏁 輪胎策略"
   ✅ 創建輪胎策略標籤頁

4. 在每個標籤頁中點擊對應的分析按鈕
   ✅ 每個標籤頁專注於一種分析類型

結果: 3 個標籤頁，每個專注於不同的分析
```

### 工作流程 3: 混合模式

```
1. 點擊 "➕ 新增標籤頁" → 選擇 "🌧️ 降雨分析"
2. 在該標籤添加多個降雨分析相關視窗
3. 點擊 "➕ 新增標籤頁" → 選擇 "⏱️ 圈速分析"  
4. 在該標籤添加多個圈速分析相關視窗
5. 右鍵點擊標籤 → 彈出到第二螢幕

結果: 靈活的多工作區佈局
```

## 🎨 界面說明

### 頂部工具欄

```
┌──────────────────────────────────────────────────────────────┐
│ 🏎️ F1T DEMO  [➕ 新增標籤頁] [🌧️][⏱️][🏁][⚡]                │
└──────────────────────────────────────────────────────────────┘
    ↑                ↑              ↑
    標題        創建新標籤    添加視窗到當前標籤
```

### 按鈕功能

| 按鈕 | 功能 | 行為 |
|------|------|------|
| **➕ 新增標籤頁** | 創建新的空白標籤頁 | 顯示選單，選擇標籤類型 |
| **🌧️ 降雨分析** | 添加降雨分析視窗 | 在當前標籤頁的 MDI 區域添加 |
| **⏱️ 圈速分析** | 添加圈速分析視窗 | 在當前標籤頁的 MDI 區域添加 |
| **🏁 輪胎策略** | 添加輪胎策略視窗 | 在當前標籤頁的 MDI 區域添加 |
| **⚡ 遙測比較** | 添加遙測比較視窗 | 在當前標籤頁的 MDI 區域添加 |

## 🧪 測試場景

### 場景 1: 歡迎頁保護測試

**步驟**:
1. 啟動 DEMO，停留在歡迎頁
2. 點擊任意分析按鈕（如 "🌧️ 降雨分析"）

**預期結果**:
- ✅ 顯示提示訊息："歡迎頁不支援添加視窗！"
- ✅ 引導用戶先創建標籤頁
- ✅ 歡迎頁保持不變

### 場景 2: 單標籤多視窗測試

**步驟**:
1. 點擊 "➕ 新增標籤頁" → 選擇 "🌧️ 降雨分析"
2. 點擊 "🌧️ 降雨分析" 按鈕 3 次
3. 點擊 "⏱️ 圈速分析" 按鈕 2 次

**預期結果**:
- ✅ 創建 1 個標籤頁
- ✅ 標籤頁內有 5 個視窗（3 個降雨 + 2 個圈速）
- ✅ 視窗自動層疊排列（偏移 30 像素）
- ✅ 每個視窗獨立且可操作

### 場景 3: 多標籤專項測試

**步驟**:
1. 點擊 "➕ 新增標籤頁" → 選擇不同類型，創建 4 個標籤
2. 切換到每個標籤
3. 點擊對應的分析按鈕添加視窗

**預期結果**:
- ✅ 創建 4 個不同類型的標籤頁
- ✅ 每個標籤頁有獨立的 MDI 區域
- ✅ 視窗只添加到當前活動標籤
- ✅ 切換標籤時內容保持獨立

### 場景 4: MDI 視窗管理測試

**步驟**:
1. 創建標籤頁並添加 5+ 個視窗
2. 右鍵點擊 MDI 區域 → 選擇 "🔲 層疊視窗"
3. 右鍵點擊 MDI 區域 → 選擇 "⬜ 平舖視窗"
4. 右鍵點擊 MDI 區域 → 選擇 "❌ 關閉所有視窗"

**預期結果**:
- ✅ 層疊排列整齊
- ✅ 平舖充滿整個 MDI 區域
- ✅ 一鍵關閉所有視窗
- ✅ 右鍵選單功能正常

### 場景 5: 標籤彈出測試

**步驟**:
1. 創建標籤頁並添加 3+ 個視窗
2. 右鍵點擊標籤 → 選擇 "🔓 彈出為獨立視窗"
3. 在獨立視窗中繼續添加視窗
4. 關閉獨立視窗

**預期結果**:
- ✅ 標籤彈出為獨立視窗
- ✅ 所有視窗完整保留
- ✅ 可以在獨立視窗中繼續添加視窗
- ✅ 關閉後自動彈回標籤頁
- ✅ 所有視窗和狀態完整保留

## 🐛 已知限制

### 限制 1: 歡迎頁不支援添加視窗

**原因**: 歡迎頁是靜態說明頁面，不包含 MDI 區域

**解決方案**: 提示用戶先創建標籤頁

### 限制 2: 視窗標題自動編號

**行為**: 視窗標題自動添加 `#1, #2, #3...` 編號

**原因**: 區分同一標籤頁內的多個同類視窗

**影響**: 無負面影響，反而更清晰
