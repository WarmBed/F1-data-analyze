# 🏎️ 直線速度分析使用指南 (Function 48)

## 📌 功能說明

**Function 48 - 全車手直線速度與加速分析** 提供：
- ✅ 統一終點速度計算（最高 10 位車手的平均值）
- ✅ 全車手加速性能排名
- ✅ 個人最高速度追蹤
- ✅ 最高速度達成時間分析
- ✅ 平均加速度計算
- ✅ v3.3.1 演算法（往後搜索高油門起點）

---

## 🎯 使用方法

### **方法 1: CLI 命令行（最快速）**

```powershell
# 基本格式
python f1_analysis_modular_main.py -f 48 -y <年份> -r <賽事> -s <會話>

# 範例 1: 分析 2025 Japan 正賽
python f1_analysis_modular_main.py -f 48 -y 2025 -r Japan -s R

# 範例 2: 分析 2025 China 正賽
python f1_analysis_modular_main.py -f 48 -y 2025 -r China -s R

# 範例 3: 分析 2025 Australia 正賽
python f1_analysis_modular_main.py -f 48 -y 2025 -r Australia -s R

# 範例 4: 分析 2024 Monza 正賽（高速賽道）
python f1_analysis_modular_main.py -f 48 -y 2024 -r Italy -s R
```

**執行時間**：約 30-60 秒（視網路速度和緩存）

## 📊 數據結構說明

### **metadata（元數據）**
```json
{
  "year": 2025,
  "race": "Japan",
  "session": "R",
  "analysis_type": "all_drivers_straight_line_speed",
  "function_id": "48",
  "algorithm_version": "3.3.1_unified_endpoint_with_max_speed",
  "unified_end_speed_kmh": 310.5,
  "timestamp": "2025-10-18T13:03:05.123456+00:00"
}
```

### **drivers（車手數據）**
```json
{
  "driver": "VER",
  "team": "Red Bull Racing",
  "max_speed_kmh": 315.2,
  "segment_accel_time_seconds": 4.56,
  "segment_avg_acceleration_ms2": 12.34,
  "segment_start_speed_kmh": 89.5,
  "max_speed_time_seconds": 7.123,
  "segment_distance_meters": 456.78
}
```

### **關鍵欄位說明**

| 欄位 | 說明 | 單位 |
|------|------|------|
| `max_speed_kmh` | 車手達到的最高速度 | km/h |
| `segment_accel_time_seconds` | 加速到統一終點的時間 | 秒 |
| `segment_avg_acceleration_ms2` | 平均加速度 | m/s² |
| `segment_start_speed_kmh` | 起始速度 | km/h |
| `max_speed_time_seconds` | 達到最高速度的時間 | 秒 |
| `unified_end_speed_kmh` | 統一終點速度（最高 10 位平均） | km/h |

## 🚨 常見問題排除

### **問題 1: 出現 N/A 值**
**症狀**：某些車手的最高速度時間顯示為 N/A

**原因**：使用舊版演算法（v3.3 之前）

**解決**：
1. 確認使用 v3.3.1 版本
2. 重新執行分析：`python f1_analysis_modular_main.py -f 48 -y 2025 -r <賽事> -s R`

---

### **問題 2: API 錯誤 `NoneType.__format__`**
**症狀**：GUI 顯示 API 錯誤

**原因**：嘗試格式化 None 值

**解決**：已在 v3.3.1 修正（Line 311, 331-340, 372-378）

---

### **問題 3: 找不到數據檔案**
**症狀**：GUI 提示找不到 JSON 檔案

**解決方案**：
1. **方案 1（推薦）**：手動執行 CLI 生成數據
   ```powershell
   python f1_analysis_modular_main.py -f 48 -y 2025 -r <賽事> -s R
   ```

2. **方案 2**：通過 API 獲取數據（需要 API 服務器運行）
   ```powershell
   # 啟動 API 服務器
   python refactored_api.py
   ```

---

### **問題 4: CLI 執行失敗**
**症狀**：CLI 返回錯誤碼 1

**檢查步驟**：
1. 檢查日誌檔案：`logs/f1_cli_error_2025-10-18.log`
2. 確認賽道名稱正確（大寫開頭，例如 "Japan" 而非 "japan"）
3. 確認網路連線（FastF1 需要下載數據）

## 📝 技術細節

### **演算法流程（v3.3.1）**

1. **載入遙測數據**：從 FastF1 獲取車手遙測數據
2. **硬編碼起點**：使用賽道專屬的起點位置
3. **往後搜索高油門**：如果起點油門 < 95%，往後搜索第一個 ≥ 95% 的點
4. **統一終點計算**：取最高 10 位車手的平均最高速度作為統一終點
5. **加速時間計算**：從實際起點到達統一終點速度的時間
6. **個人最高速度追蹤**：記錄車手達到個人最高速度的時間
7. **數據回退機制**：預掃描失敗時使用統一速度數據
8. **排名和導出**：按加速時間排名並導出 JSON
