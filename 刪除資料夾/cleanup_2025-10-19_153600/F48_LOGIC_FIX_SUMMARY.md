# F48 欄位更新與邏輯修正總結

## 📋 更新日期：2025-10-17

### ✅ 完成的修正

#### 1. 加速時間的遞增遞減邏輯 ✅
**問題**：加速時間的排序邏輯需要確認
**解決**：
- ✅ **邏輯確認**：加速時間越短 = 性能越好
- ✅ **排序方式**：升序排列（最短在前）
- ✅ **QTableWidget 原生排序**：點擊欄位標題自動按數值排序
- ✅ **數據類型**：使用 `Qt.UserRole` 存儲浮點數確保正確排序

**實現細節**：
```python
# 欄位 4: 加速時間
seg_time_item.setData(Qt.UserRole, segment_accel_time)  # 存儲數值用於排序
# Qt 自動處理：點擊標題 → 第一次升序（快→慢）→ 第二次降序（慢→快）
```

#### 2. 加速性能視覺化採用加速時間為依據 ✅
**問題**：視覺化棒狀圖應該基於賽道段加速時間，而非其他指標
**解決**：
- ✅ **修正數據來源**：從 `time_to_max` 改為 `segment_accel_time`
- ✅ **簡化視覺設計**：單一深藍色實心棒，長度代表時間
- ✅ **邏輯一致性**：棒越短 = 時間越短 = 性能越好
- ✅ **相對比例計算**：基於最快與最慢車手的時間範圍

**修正前後對比**：
```python
# ❌ 修正前：使用複雜的速度範圍計算
accel_100_300_time = index.data(Qt.UserRole)
time_to_max = index.data(Qt.UserRole + 2)
# 繪製：深藍棒（100→300）+ 灰色棒（300→最高速）

# ✅ 修正後：直接使用賽道段加速時間
segment_accel_time = index.data(Qt.UserRole)
# 繪製：單一深藍色實心棒
bar_width = bar_max_width * relative_ratio
# 相對比例 = (車手時間 - 最快時間) / (最慢時間 - 最快時間)
```

#### 3. 速度增益改為起始速度 ✅
**問題**：速度增益欄位的意義不明確
**解決**：
- ✅ **欄位名稱**：「速度增益」→「起始速度」
- ✅ **數據來源**：從 `segment_speed_gain_kmh` 改為 `segment_start_speed_kmh`
- ✅ **顯示格式**：直接顯示起始速度值（例如：103 km/h）
- ✅ **Tooltip 增強**：顯示「起始→結束: XXX → YYY km/h」

**欄位意義說明**：

| 項目 | 速度增益（舊）| 起始速度（新）|
|------|-------------|-------------|
| **數據** | 結束速度 - 起始速度 | 進入賽道段時的速度 |
| **範例** | HAM: 184 km/h（287-103）| HAM: 103 km/h |
| **意義** | 該段加速了多少 | 彎道出彎速度 |
| **用途** | 不直觀，容易混淆 | 直觀反映出彎性能 |
| **排序** | 降序（大→小）| 降序（高→低）|

**實際數據範例（Singapore 2025 R）**：
```
車手  起始速度  結束速度  加速時間  平均加速度  分析
---------------------------------------------------------
LEC   107 km/h  288 km/h  10.120 s  4.97 m/s²  彎道快，直線慢
HAM   103 km/h  287 km/h   9.759 s  5.24 m/s²  均衡
SAI    87 km/h  289 km/h   9.480 s  5.92 m/s²  彎道慢，直線快
VER    84 km/h  282 km/h   9.559 s  5.75 m/s²  彎道最慢
```

**數據洞察**：
- **LEC**：起始速度最高（107 km/h）→ 彎道出彎最快 → 但加速時間最長 → 可能使用高下壓力設定
- **SAI**：起始速度較低（87 km/h）→ 彎道出彎較慢 → 但加速時間最短 → 直線加速優秀
- **VER**：起始速度最低（84 km/h）→ 彎道出彎最慢 → 但加速時間仍短於 LEC → 直線性能好

### 🎓 數據分析指南

#### 如何解讀表格數據

1. **評估彎道性能**：看「起始速度」
   - 起始速度高 → 彎道出彎快 → 可能高下壓力設定

2. **評估直線性能**：看「加速時間」和「平均加速度」
   - 加速時間短 → 直線加速快 → 可能低下壓力設定
   - 平均加速度高 → 加速能力強 → 引擎馬力強

3. **評估整體性能**：綜合分析
   - 起始速度高 + 加速時間短 = 完美平衡
   - 起始速度高 + 加速時間長 = 彎道快、直線慢（高下壓力）
   - 起始速度低 + 加速時間短 = 彎道慢、直線快（低下壓力）
