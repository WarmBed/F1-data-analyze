- **s**: 時間（加速時間、煞車時間）
- **m**: 距離（煞車距離）

## 🐛 煞車邏輯修復 (額外完成)

在添加單位的過程中，發現並修復了煞車性能分析的核心邏輯錯誤：

### 問題診斷
**原始問題**: 所有車手無法獲取煞車數據（返回 None）
**根本原因**: 煞車起始點檢測邏輯錯誤

```python
# ❌ 錯誤邏輯（原始）
if accel >= ACCEL_THRESHOLD:  # 加速度 >= -1.0 表示不在煞車
    brake_start_idx = idx  # 錯誤：立即在終點找到非煞車點
    break
# 結果：起點 = 終點（3575.8m = 3575.8m，煞車距離 0m）
```

### 修復方案
**修正邏輯**: 使用狀態機，先找到煞車區，再找到煞車起始邊界

```python
# ✅ 正確邏輯（修復後）
in_brake_zone = False
for i in range(end_idx_position, len(sorted_indices)):
    if accel < ACCEL_THRESHOLD:
        in_brake_zone = True  # 進入煞車區
    elif in_brake_zone and accel >= ACCEL_THRESHOLD:
        brake_start_idx = idx  # 離開煞車區（找到起始邊界）
        break
# 結果：起點 3450.8m，終點 3575.8m，煞車距離 125.0m ✅
```

### 修復成果
- ✅ 煞車區域正確識別（125.0m 煞車距離）
- ✅ 20 位車手全部成功分析
- ✅ JSON 檔案成功生成
- ✅ 數據合理（減速度 9.96-15.90 m/s²，1.02-1.62 G）
