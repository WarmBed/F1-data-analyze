## 關鍵發現與建議

### 1. McLaren FP2 模擬策略最激進

McLaren 的 FP2 Long Run 配速最接近正賽開始階段 (第 2-3 圈)，這意味著:
- 他們可能使用接近正賽起步的高燃油載荷進行模擬
- 或者 McLaren 的輪胎管理使得 FP2 與正賽初期退化曲線相似

### 2. Red Bull 策略變化最大

Red Bull 的中位數 (5) 與平均數 (19.9) 差距極大，顯示:
- 不同賽道採用不同的 FP2 模擬策略
- 部分賽事使用低燃油載荷進行後期 Stint 模擬
- VER 和 PER 的策略設定可能有顯著差異

### 3. Ferrari 策略最穩定

LEC 的中位數 (4) 和平均數 (4.8) 非常接近，SAI 也類似 (6 vs 9.5)，顯示:
- Ferrari 在 FP2 Long Run 中使用標準化的燃油策略
- 可預測性高，適合進行季度分析

### 4. 建議的默認模擬圈數設定

1. **數據來源**: FastF1 API 2024 賽季數據
