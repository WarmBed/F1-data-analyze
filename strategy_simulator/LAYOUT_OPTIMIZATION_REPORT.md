### **問題 1: 左側面板寬度不足導致欄位被隱藏**

#### **現象**
- 輸入欄位被截斷
- 文字顯示不完整
- Long Run 按鈕與來源選擇擠在同一行

#### **修復方案**

##### A) 增加面板寬度
```python
# main_window.py
# 修改前：
self.input_panel.setMinimumWidth(320)
self.input_panel.setMaximumWidth(450)

# 修改後：
self.input_panel.setMinimumWidth(380)  # ✅ +60px
self.input_panel.setMaximumWidth(520)  # ✅ +70px
```

**效果：** 所有欄位有足夠空間顯示完整內容

##### B) 重新設計輪胎衰退區塊
```python
# input_panel.py - _create_degradation_section()

# 修改前：
[來源: 下拉選單] [Long Run 設定按鈕]  ← 擠在同一行

# 修改後：
[來源: 下拉選單（整行寬度）]
[📊 Long Run 設定（整行寬度按鈕）]  ← 移到下方獨立一行
```

**按鈕樣式優化：**
- 添加 emoji 圖標 📊
- 增加最小高度 `min-height: 28px`
- 整行寬度，更容易點擊

### **問題 2: 進站損失配置來源不明確**

#### **現象**
用戶不知道當前使用的是：
- 賽道配置的進站損失？
- 手動設定的值？

#### **修復方案**

##### A) 添加配置來源提示標籤
```python
# 在「進站損失」下方新增提示標籤
self.pit_loss_source_label = QLabel("ℹ️ 使用手動設定")
```

**三種狀態顯示：**

1️⃣ **使用賽道配置** (綠色背景)
```
✅ 使用賽道配置 (綠旗 22.0秒, SC 11.5秒)
```

2️⃣ **使用手動設定** (灰色背景)
```
ℹ️ 使用手動設定 (綠旗 24.0秒, SC 12.0秒)
```

3️⃣ **用戶修改後** (藍色背景)
```
ℹ️ 使用手動設定 (綠旗 23.5秒, SC 11.8秒)
```

##### B) 自動更新邏輯

**場景 1: 切換賽道時**
```python
# update_track_parameters()
if pit_loss_green is not None:
    # 賽道有配置 → 顯示綠色提示
    self.pit_loss_source_label.setText("✅ 使用賽道配置 (...)")
    # 綠色背景 #e8f5e9
else:
    # 賽道無配置 → 顯示灰色提示
    self.pit_loss_source_label.setText("ℹ️ 使用手動設定 (...)")
    # 灰色背景 #f5f5f5
```

**場景 2: 用戶手動修改時**
```python
# _on_pit_loss_changed() - 新方法
def _on_pit_loss_changed(self):
    # 監聽 pit_green_spin 和 pit_sc_spin 的 valueChanged 信號
    self.pit_loss_source_label.setText("ℹ️ 使用手動設定 (...)")
    # 藍色背景 #e3f2fd
```

### **問題 3: 比賽場景設定用途不明確**

#### **用戶疑問**
> "比賽場景設定 (這是靜態策略排名使用對吧?)"

#### **解答與修復**

##### A) 實際用途
**比賽場景設定（SC Event Injector）** 是用於：
- ✅ **動態模擬標籤** (`simulation_tab.py`)
- ✅ **完整賽事標籤** (`full_race_tab.py`)
- ❌ **NOT** 靜態策略排名

**功能說明：**
```
手動設定 Safety Car (SC) 或 Virtual Safety Car (VSC) 事件：
- 發生圈數 (例如第 25 圈)
- 持續時間 (例如 4 圈)
- 類型 (SC 或 VSC)
```

##### B) 添加說明標籤
```python
# _create_race_conditions_section()
info_label = QLabel("💡 SC 事件設定用於「動態模擬」標籤\n可手動設定 SC/VSC 發生圈數和持續時間")
```

**樣式：**
- 灰色背景 #f5f5f5
- 藍色左邊框 (3px solid #2196f3)
- 小字體 10px
- 自動換行
