# 🧪 分頁重新命名功能 - 手動測試清單

## 📋 **測試前準備**
```powershell
# 啟動 GUI
python f1t_gui_main.py
```

---

## ✅ **測試案例**

### 🎯 **案例 1: 基本重命名**
- [ ] 點擊 [+] 按鈕創建新分頁（應顯示 "Tab 一"）
- [ ] 在 "Tab 一" 標籤上按右鍵
- [ ] 確認顯示選單：
  ```
  彈出為獨立視窗
  ──────────────
  重新命名分頁
  ```
- [ ] 點擊「重新命名分頁」
- [ ] 確認彈出對話框，預設內容為 "Tab 一"
- [ ] 輸入新名稱：`我的工作區`
- [ ] 點擊「確定」
- [ ] 確認分頁標籤更新為 `我的工作區`
- [ ] 檢查 Console 輸出是否包含：
  ```
  [TAB_RENAME] 分頁 1 已重新命名為: 我的工作區
  ```

---

### 🎯 **案例 2: 重複名稱處理**
- [ ] 創建兩個新分頁（Tab 二、Tab 三）
- [ ] 將 "Tab 二" 重命名為 `測試分頁`
- [ ] 嘗試將 "Tab 三" 重命名為 `測試分頁`
- [ ] 確認系統自動更新為 `測試分頁 (1)`
- [ ] 再創建一個分頁，重命名為 `測試分頁`
- [ ] 確認系統自動更新為 `測試分頁 (2)`

---

### 🎯 **案例 3: 主頁限制**
- [ ] 在「主頁」標籤上按右鍵
- [ ] 確認**沒有顯示任何選單**
- [ ] 檢查 Console 輸出是否包含：
  ```
  [TAB_MENU] HOME 主頁不支援彈出功能 / HOME 主頁不支援重新命名
  ```

---

### 🎯 **案例 4: 彈出視窗同步**
- [ ] 創建新分頁 "Tab 四"
- [ ] 重命名為 `分析視窗`
- [ ] 在 `分析視窗` 標籤上按右鍵，選擇「彈出為獨立視窗」
- [ ] 確認分頁標籤變為 `🔗 分析視窗`
- [ ] 確認獨立視窗標題為 `分析視窗 - F1 TelemetryStation Pro`
- [ ] 在主視窗的 `🔗 分析視窗` 標籤上按右鍵
- [ ] 確認顯示選單：
  ```
  返回主視窗
  ──────────────
  重新命名分頁
  ```
- [ ] 點擊「重新命名分頁」
- [ ] 輸入新名稱：`資料分析`
- [ ] 點擊「確定」
- [ ] 確認主視窗標籤更新為 `🔗 資料分析`
- [ ] **確認獨立視窗標題同步更新為** `資料分析 - F1 TelemetryStation Pro`

---

### 🎯 **案例 5: 取消操作**
- [ ] 在任意分頁標籤上按右鍵
- [ ] 選擇「重新命名分頁」
- [ ] 不修改名稱，直接點擊「取消」
- [ ] 確認分頁名稱未改變
- [ ] 再次嘗試，輸入新名稱後點擊「取消」
- [ ] 確認分頁名稱未改變

---

### 🎯 **案例 6: 空白名稱處理**
- [ ] 在任意分頁標籤上按右鍵
- [ ] 選擇「重新命名分頁」
- [ ] 清空輸入框（只輸入空白）
- [ ] 點擊「確定」
- [ ] 確認名稱未改變（系統應忽略空白輸入）

---

### 🎯 **案例 7: 特殊符號測試**
- [ ] 創建新分頁
- [ ] 重命名為 `分析@2025#日本站`
- [ ] 確認名稱正確顯示
- [ ] 重命名為 `測試/資料夾\檔案`
- [ ] 確認名稱正確顯示（無限制）

---

### 🎯 **案例 8: 多語言切換**
- [ ] 在主選單選擇「Language」→「English」
- [ ] 創建新分頁（應顯示 "Tab 1"）
- [ ] 在分頁標籤上按右鍵
- [ ] 確認選單顯示英文：
  ```
  Pop Out as Independent Window
  ──────────────────────────────
  Rename Tab
  ```
- [ ] 點擊 "Rename Tab"
- [ ] 確認對話框標題為 "Rename Tab"
- [ ] 確認提示為 "Enter new tab name:"
- [ ] 切換回中文，確認所有文字恢復為中文

---

### 🎯 **案例 9: 長名稱測試**
- [ ] 創建新分頁
- [ ] 重命名為超長名稱（100+ 字元）：
  ```
  這是一個非常非常非常非常非常非常非常非常非常非常非常非常非常非常非常非常非常非常非常非常非常長的分頁名稱用來測試系統是否能正確處理超長名稱
  ```
- [ ] 確認名稱正確顯示（可能會被截斷，但不應崩潰）

---

### 🎯 **案例 10: 返回主視窗後重命名**
- [ ] 彈出一個分頁為獨立視窗
- [ ] 在獨立視窗中重命名分頁
- [ ] 點擊「返回主視窗」
- [ ] 確認分頁名稱保持更新後的名稱
- [ ] 再次重命名，確認功能正常
