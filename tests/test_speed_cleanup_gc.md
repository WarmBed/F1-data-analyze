## 🔍 如果發現洩漏

### 需要檢查的項目

1. **終端日誌中是否有錯誤**
   - [ ] cleanup 方法是否完整執行
   - [ ] 是否有 Exception 或 traceback

2. **引用追蹤**
   - [ ] 查看終端中的 `[CRITICAL] 🔍` 引用分析輸出
   - [ ] 記錄哪些類型持有了強引用

3. **信號斷開**
   - [ ] 確認所有信號都已斷開
   - [ ] 查看是否有 `disconnect()` 失敗的訊息

4. **全域管理器**
   - [ ] 確認從 analysis_manager 解除註冊
   - [ ] 確認從 linkage_manager 解除註冊

- [ ] 完整的終端日誌輸出
