# 全車手直線速度分析 - 視覺化設計說明

## 設計理念

### 原始需求
用戶希望看到類似這樣的視覺化：
```
│  VER  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░  7.12s → 328.5 km/h                    │
│       ├────────────┼──────────┤                                     │
│       100 km/h   300 km/h   328.5 km/h (最高速)                     │
│       (起點)    (100-300參考) (終點)                                 │
```

### 設計目標
1. **清晰顯示三個關鍵速度點**：
   - 100 km/h（起點）
   - 300 km/h（參考點，固定標準）
   - 最高速（終點，每位車手不同）

2. **視覺化加速過程**：
   - 實心綠色棒：100-300 km/h 加速區間（已知時間）
   - 虛線淺綠棒：300-最高速 加速區間（推算時間）

3. **標註時間資訊**：
   - 實心區上方：顯示 100-300 的實測時間（例如 1.20s）
   - 下方中央：顯示總時間（例如 總時間: 7.12s）

## 視覺化架構

### 繪製元素分層

```
層級 1: 背景
├─ 白色/選中色背景

層級 2: 加速棒（主視覺）
├─ 實心棒（100→300 km/h）
│  ├─ 綠色填充 RGB(80, 200, 120)
│  ├─ 深綠邊框 RGB(60, 160, 100) 2px
│  └─ 寬度：根據 (300-100)/(max-100) 比例計算
│
└─ 虛線棒（300→最高速）
   ├─ 淺綠背景 RGB(200, 240, 200)
   ├─ 虛線邊框 RGB(120, 180, 140) 2px DashLine
   ├─ 中間虛線 RGB(150, 150, 150) 1px DashLine
   └─ 寬度：剩餘的速度範圍

層級 3: 速度標記
├─ 100 km/h 標記（左側）
├─ 300 km/h 標記（中間參考點）
└─ 最高速標記（右側，動態數值）

層級 4: 時間標籤
├─ 100-300 時間（實心區上方，綠色粗體）
└─ 總時間（下方中央，黑色粗體）

層級 5: 右側數值文字
└─ "7.12s → 328.5 km/h"（黑色粗體 8pt）
```

## 關鍵計算公式

### 1. 速度位置計算
```python
# 總寬度（像素）
total_width = option.rect.width() - 170  # 預留右側文字

# 100 km/h 位置
speed_100_pos = 0  # 起點

# 300 km/h 位置（比例計算）
speed_300_ratio = (300 - 100) / (max_speed - 100)
speed_300_pos = total_width * speed_300_ratio

# 最高速位置
speed_max_pos = total_width  # 終點
```

**範例計算**（VER: 326 km/h）：
```
total_width = 500px
speed_300_ratio = (300-100) / (326-100) = 200/226 = 0.885
speed_300_pos = 500 * 0.885 = 442px
speed_max_pos = 500px
```

### 2. 時間推算公式
```python
# 假設線性加速
speed_range_100_300 = 200  # 300 - 100
speed_range_100_max = max_speed - 100
time_to_max = (speed_range_100_max / speed_range_100_300) * accel_100_300_time
```

**範例計算**（VER: 326 km/h, 1.20s for 100-300）：
```
speed_range_100_max = 326 - 100 = 226 km/h
time_to_max = (226 / 200) * 1.20 = 1.356s
```

### 顏色方案

- **填充**: RGB(80, 200, 120) - 鮮綠色
- **邊框**: RGB(60, 160, 100) - 深綠色
- **含義**: 已知的加速數據（實測）

# _populate_row() 設置

## 特殊處理

### 情況 1: 最高速 ≤ 300 km/h
如果 `max_speed <= 300`，不繪製虛線棒，只顯示實心棒的一部分。

```python
if max_speed > 300:
    # 繪製虛線棒
else:
    # 只繪製實心棒到 max_speed 位置
```

### 情況 2: 缺少 100-300 數據
如果 `accel_100_300_time` 為 0 或 None：
- 不顯示實心區上方的時間標籤
- 使用推算的總時間

```python
if accel_100_300_time and accel_100_300_time > 0:
    painter.drawText(...)  # 顯示時間
```
