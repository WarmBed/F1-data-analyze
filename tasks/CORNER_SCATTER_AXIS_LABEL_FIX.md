---

## 🐛 問題描述

### 原始問題
在 `corner_performance_scatter_widget.py` 中的散點圖，當視窗縮小時：
- X軸標題「進彎速度 (-50m) [km/h]」被下方邊界截斷
- Y軸標題「出彎速度 (+50m) [km/h]」被左側邊界截斷
- colorbar 標籤「彎中心速度 (km/h)」可能與右側邊界過於接近

### 技術原因
```python
# ❌ 原始代碼
self.figure.tight_layout(rect=[0, 0, 1, 0.96])
```

`tight_layout` 的 `rect` 參數定義了圖表內容的邊界：
- `rect=[left, bottom, right, top]`，單位為圖形的比例（0-1）
- 原始設定：左=0, 底=0, 右=1, 上=0.96
- **問題**：左側和底部沒有預留空間給軸標題

---

## ✅ 解決方案

### 修改內容
調整 `tight_layout` 參數，為四周增加適當邊距：

```python
# ✅ 修復後的代碼
self.figure.tight_layout(rect=[0.05, 0.08, 0.95, 0.96], pad=2.0)
```

### 參數說明
| 參數 | 原始值 | 新值 | 說明 |
|------|--------|------|------|
| `left` | 0 | 0.05 | 增加左側 5% 空間（容納 Y軸標題） |
| `bottom` | 0 | 0.08 | 增加底部 8% 空間（容納 X軸標題） |
| `right` | 1 | 0.95 | 減少右側 5% 空間（避免 colorbar 過於靠邊） |
| `top` | 0.96 | 0.96 | 維持頂部空間 |
| `pad` | (無) | 2.0 | 增加子圖之間的間距 |

### 視覺效果

## 🔍 技術細節

### Matplotlib tight_layout 原理
- **自動調整**：自動計算子圖位置以避免重疊
- **rect 參數**：定義可用繪圖區域的邊界
- **pad 參數**：子圖之間的額外間距（單位：字體大小的倍數）

### 邊距計算邏輯
```python
# 圖形尺寸：12 x 10 英吋（dpi=100 → 1200 x 1000 像素）

# 左側邊距（Y軸標題）
left_margin = 0.05 × 1200px = 60px  # 足夠容納旋轉的中文文字

# 底部邊距（X軸標題）
bottom_margin = 0.08 × 1000px = 80px  # 足夠容納一行文字 + 刻度標籤

# 右側邊距（colorbar）
right_margin = 0.05 × 1200px = 60px  # 避免 colorbar 過於靠邊

# 頂部邊距（保留空間）
top_margin = 0.04 × 1000px = 40px  # 預留頂部空間
```

## 🎯 最佳實踐

### 通用建議
1. **使用 tight_layout 時務必設定 rect**：為軸標題預留空間
2. **測試不同視窗尺寸**：確保在最小視窗下也能完整顯示
3. **考慮文字長度**：中文字符通常需要更多空間
4. **colorbar 需要額外空間**：右側邊距需要更大

### 其他模組參考
如果其他模組也有類似問題，可參考此修復方案：
```python
# 推薦設定（適用於大多數圖表）
self.figure.tight_layout(rect=[0.05, 0.08, 0.95, 0.96], pad=2.0)

# 如果圖表沒有 colorbar，可減少右側邊距
self.figure.tight_layout(rect=[0.05, 0.08, 0.98, 0.96], pad=2.0)

# 如果軸標題很長，可增加對應邊距
self.figure.tight_layout(rect=[0.08, 0.10, 0.95, 0.96], pad=2.0)
```
