# F1T 策略模擬器重構計劃

**建立日期**: 2026-01-04
**狀態**: 進行中
**優先級**: 高

---

## 1. 問題分析

### 1.1 現有問題
- **Long Run 模組重複**：獨立建立 `longrun_dialog.py` 而非複用主 GUI 模組
- **無動態模擬視覺化**：只有靜態表格，看不到逐圈位置變化
- **Monte Carlo 結果不直觀**：只顯示數字，沒有分布圖
- **SC/VSC 事件僅概率計算**：無法手動注入事件測試特定場景
- **GUI 老舊**：佈局不夠現代，缺乏動畫效果

### 1.2 用戶期望
- 逐圈動態模擬動畫（類似 AWS F1 Insights）
- Monte Carlo 結果分布可視化
- SC/VSC 事件手動注入
- 與主 GUI 風格一致

**功能**：
- 顯示賽道俯視圖（簡化版）
- 逐圈動畫展示車手位置變化
- 進站動畫效果
- SC/VSC 狀態指示

**UI 設計**：

## 6. 技術細節

### 6.1 動畫實現方案
- 使用 `QTimer` 進行逐圈播放控制
- 使用 `pyqtgraph` 繪製簡化賽道和車手位置
- 支援暫停、播放、快進控制

### 6.2 Monte Carlo 圖表
- 使用 `matplotlib` 或 `pyqtgraph` 繪製
- 直方圖：顯示完賽時間分布
- 箱型圖：顯示位置變化範圍

### 6.3 與主 GUI 整合
- Long Run 模組：直接實例化 `LongRunAnalysis` 類別
- 共用 API 載入器：`UniversalDataLoader`
