## 🔍 圖表元素說明

### 箱型圖組成

```
            上鬚線 (Q3 + 1.5×IQR)
               |
        ┌──────┴──────┐
        │             │ Q3 (第三四分位數)
        │      ━━━━━━ │ 平均值線 (綠色虛線)
        │      ━━━━━━ │ 中位數線 (紅色)
        │             │ Q1 (第一四分位數)
        └──────┬──────┘
               |
            下鬚線 (Q1 - 1.5×IQR)
               
           ●  ●       異常值 (黑點)
```

### 統計意義

| 元素 | 說明 | 解讀 |
|------|------|------|
| **箱子高度** | IQR (Q3-Q1) | 圈速穩定性（越小越穩定） |
| **中位數位置** | 50th percentile | 典型圈速 |
| **平均值與中位數差距** | 偏態 | 有無極端值影響 |
| **鬚線長度** | 1.5×IQR | 正常範圍 |
| **異常值** | 超出鬚線 | 特殊情況圈（事故、安全車等） |

## 🏁 實際分析範例

### 案例：2025 比利時大獎賽

**背景**：Spa-Francorchamps 賽道，全長 7.004 km，單圈 ~105 秒

**預期觀察**：

1. **VER (Verstappen)** 
   - 箱型圖應該位於較低位置（快圈速）
   - 箱子較小（穩定性高）
   - 異常值少

2. **LEC (Leclerc)**
   - 與 VER 接近或稍慢
   - Ferrari 在 Spa 通常有競爭力

3. **Backmarkers (後段車隊)**
   - 箱型圖位置明顯較高
   - 可能有更多異常值（藍旗影響）

4. **新手車手**
   - 箱子較大（圈速不穩定）
   - 異常值較多

**分析步驟**：

1. **整體比較**
   - 觀察所有箱型圖的垂直位置 → 車手/車隊速度排名
   - 比較箱子高度 → 各車手穩定性

2. **焦點車手**
   - 點擊查看 VER 的統計數字
   - 計算與 LEC 的平均圈速差距

3. **異常圈分析**
   - 識別有大量異常值的車手
   - 結合賽事記錄（事故、安全車、黃旗）

4. **車隊比較**
   - 同車隊兩位車手的箱型圖是否接近？
   - 是否有明顯的一號/二號車手差距？

## 📊 數據解釋指南

### 圈速統計指標

| 指標 | 定義 | 正常範圍 (Spa) | 解讀 |
|------|------|----------------|------|
| **平均時間** | 所有圈的算術平均 | 105-110 秒 | 整體速度水平 |
| **中位數** | 排序後的中間值 | 105-110 秒 | 典型圈速（不受極端值影響） |
| **Q1** | 25% 分位數 | 104-109 秒 | 較快的四分之一 |
| **Q3** | 75% 分位數 | 106-111 秒 | 較慢的四分之一 |
| **IQR** | Q3 - Q1 | 1-3 秒 | 穩定性指標 |

### IQR 大小解讀

- **IQR < 1 秒**: 極度穩定（頂尖車手）
- **IQR 1-2 秒**: 良好穩定性（中段車手）
- **IQR 2-3 秒**: 普通穩定性（後段車手或新手）
- **IQR > 3 秒**: 不穩定（可能受事故/策略影響）

### 異常值解讀

**正常情況下的異常值**：
- 進站圈（慢）
- 出站圈（慢）
- 安全車圈（慢）
- 最快圈挑戰（快或慢）
- 黃旗/紅旗圈（慢）

**值得關注的異常值**：
- 極慢圈：可能事故、機械問題
- 極快圈：可能是最快圈或拖尾流

## 🎓 進階使用技巧

### 技巧 1: 識別車隊配對

**方法**：觀察相同顏色的兩個箱型圖

**範例**：
- 紅色 (Ferrari): LEC + SAI
- 藍色 (Red Bull): VER + PER

**分析**：
- 兩個箱型圖是否重疊？→ 車隊穩定性
- 一個明顯快於另一個？→ 一號/二號車手差距

---

### 技巧 2: 比較會話類型

**方法**：分別開啟不同會話的箱型圖

1. 開啟 **FP1** (練習賽 1)
2. 開啟 **Q** (排位賽)
3. 開啟 **R** (正賽)

**觀察**：
- 練習賽通常 IQR 較大（試車、調整）
- 排位賽通常圈速最快（輕油、新胎）
- 正賽圈速較慢但更穩定（重油、輪胎管理）

---

### 技巧 3: 閾值實驗

**目的**：理解 IQR 方法的敏感度

**步驟**：
1. 設定閾值 = **0.5** → 觀察保留多少圈
2. 設定閾值 = **1.0** → 標準偏嚴格
3. 設定閾值 = **1.5** → 預設值
4. 設定閾值 = **2.0** → 較寬鬆
5. 設定閾值 = **3.0** → 極寬鬆

**記錄**：每個閾值下的總圈數變化

---

### 技巧 4: 匯出比較

**目的**：創建多賽事對比報告

**步驟**：
1. 匯出 **2025 Belgium R** → `boxplot_belgium.png`
2. 匯出 **2025 Japan R** → `boxplot_japan.png`
3. 匯出 **2025 China R** → `boxplot_china.png`

**使用**：放入簡報或報告中並排比較

## 🙋 常見問題 FAQ

**Q: 為什麼進站圈需要過濾？**
A: 進站圈速度極慢（pit lane 限速 80 km/h），會嚴重扭曲統計數據。

**Q: IQR 是什麼？**
A: Interquartile Range（四分位距），統計學上的離散程度指標，= Q3 - Q1。

**Q: 為什麼使用 1.5×IQR 作為異常值判定？**
A: 這是統計學上的標準方法（Tukey's method），廣泛應用於箱型圖。

**Q: 可以只顯示部分車手嗎？**
A: 目前版本 (v1.0) 顯示所有車手，未來版本將加入車手選擇器。

**Q: 匯出的 PNG 解析度是多少？**
A: 300 DPI，適合高品質列印和簡報使用。

**Q: 支援批次匯出多個賽事嗎？**
A: 目前需要手動逐一匯出，批次功能計劃於 v1.2 加入。
