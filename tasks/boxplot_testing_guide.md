## 🐛 已知問題記錄

### Issue #1: Import 警告（已解決 ✅）
**問題描述：**
- Lint 顯示無法解析 `..base.telemetry_chart_widget_base`

**解決方案：**
- 修改為直接繼承 QWidget
- 不依賴複雜的基類

**狀態：** ✅ 已解決

---

### Issue #2: Matplotlib 警告（已解決 ✅）
**問題描述：**
```
MatplotlibDeprecationWarning: The 'labels' parameter of boxplot() has been renamed 'tick_labels'
```

**解決方案：**
- 將 `labels=drivers` 改為 `tick_labels=drivers`

**狀態：** ✅ 已解決

---

### Issue #3: 測試檔案相對導入（已解決 ✅）
**問題描述：**
- 單獨執行測試檔案時 import 失敗

**解決方案：**
- 在測試代碼添加專案根目錄到 `sys.path`

**狀態：** ✅ 已解決
