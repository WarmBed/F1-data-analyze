## 🎯 快速測試流程

### 步驟 1: 啟動主程式
```powershell
python f1t_gui_main.py
```

**預期結果**: 
- ✅ GUI 視窗正常啟動
- ✅ 無 AttributeError 錯誤
- ✅ 控制台無紅色錯誤訊息

---

### 步驟 2: 選擇賽事參數

1. 在主視窗上方的下拉選單中選擇：
   - **年份**: 2025
   - **賽事**: Japan
   - **賽段**: R (Race)

2. 確認參數已正確選中（顯示在介面上）

**預期結果**:
- ✅ 下拉選單可正常操作
- ✅ 選中的參數正確顯示

---

### 步驟 3: 開啟理想圈分析

1. 在左側功能樹中找到 **"📊 Ideal Lap Analysis"**
2. 右鍵點擊 → 選擇 **"Analyze"**

**預期結果**:
- ✅ 彈出理想圈分析選項對話框
- ✅ 對話框顯示 3 個選項：
  - 📊 排名表格 (Ranking Table)
  - 🔥 分段熱力圖 (Sector Heatmap) - 尚未實作
  - 📈 分段比較圖 (Sector Comparison) - 尚未實作

---

### 步驟 4: 選擇排名表格

1. 在對話框中點擊選中 **"📊 排名表格 (Ranking Table)"**
2. 點擊 **"確認"** 按鈕

**預期結果**:
- ✅ 對話框關閉
- ✅ 控制台輸出類似：
  ```
  [IDEAL_LAP] 🏁 檢測到理想圈分析請求: Ideal Lap Analysis
  [IDEAL_LAP] ✅ 使用者選擇了 1 個分析類型: ['ranking_table']
  [IDEAL_LAP] 📋 賽事參數: 2025 Japan R
  [IDEAL_LAP] 🚀 創建分析視窗: ranking_table
  ```

---

### 步驟 5: 驗證視窗創建

**預期結果**:

#### A. MDI 視窗
- ✅ 在 MDI 區域出現新的子視窗
- ✅ 視窗標題為 `Ideal Lap Ranking_2025_Japan_R`
- ✅ 視窗大小為 1400x900

#### B. 視窗內容結構
- ✅ **上方**: 統計摘要面板（📊 賽事統計摘要）
- ✅ **中間**: 主表格（10 欄位 x 20 車手）
- ✅ **下方**: 控制面板（重新載入、匯出按鈕）

---

### 步驟 6: 驗證資料載入

**如果本地有 JSON 檔案** (`json/ideal_lap_ranking_2025_Japan_R.json`):

**預期結果**:
- ✅ 表格自動填充 20 位車手資料
- ✅ 控制台輸出：
  ```
  [DATA_LOADER] ✅ 已載入本地 JSON 檔案
  [MDI] 資料載入完成，開始渲染表格
  ```

**如果沒有本地 JSON 檔案**:

**預期結果**:
- ⚠️ 表格為空
- ⚠️ 控制台輸出：
  ```
  [DATA_LOADER] ⚠️ 找不到資料檔案且 CLI 調用已禁用
  [DATA_LOADER] 💡 提示: 請使用 API 獲取資料或手動執行 CLI
  ```

**手動生成資料**:
```powershell
python f1_analysis_modular_main.py -f 53 -y 2025 -r Japan -s R
```

---

### 步驟 7: 驗證表格功能

#### 7.1 欄位內容檢查

檢查表格是否顯示以下 10 個欄位：

| # | 欄位名稱 | 內容範例 | 檢查點 |
|---|----------|----------|--------|
| 1 | 排名 | 1, 2, 3... | ✅ 數字 1-20 |
| 2 | 車手 | VER, LEC, HAM | ✅ 3 字母代碼 |
| 3 | 車隊 | Red Bull Racing | ✅ 完整車隊名稱 |
| 4 | 車手最速圈 | 1:31.106 | ✅ MM:SS.mmm 格式 |
| 5 | 理想圈 | 1:30.625 | ✅ MM:SS.mmm 格式 |
| 6 | 差異 | +0.481s | ✅ 正值，有 +/- 符號 |
| 7 | 全場最速實際圈 | 1:30.965 (ANT) | ✅ 包含創造者代碼 |
| 8 | 與全場最速差距 | +0.141s | ✅ 正值或 0 |
| 9 | 分段 | ✗✗✗ | ✅ 3 個 ✓ 或 ✗ |
| 10 | 操作 | [詳情] | ✅ 按鈕可見 |

---

#### 7.2 顏色編碼檢查

**車手欄位背景色**:
- ✅ VER (Red Bull) = 藍色背景
- ✅ LEC (Ferrari) = 紅色背景
- ✅ HAM (Mercedes) = 銀色背景

**差異欄位顏色梯度**:
- ✅ 0-0.2s = 綠色
- ✅ 0.2-0.5s = 黃色
- ✅ >0.5s = 紅色

**與全場最速差距顏色**:
- ✅ <0.5s = 深綠色
- ✅ 0.5-1s = 淺綠色
- ✅ 1-2s = 黃色
- ✅ >2s = 紅色

---

#### 7.3 排序功能測試

**測試步驟**:
1. 點擊 **"理想圈"** 欄位標題
2. 再次點擊

**預期結果**:
- ✅ 第一次點擊：升序排序（最快 → 最慢）
- ✅ 第二次點擊：降序排序（最慢 → 最快）
- ✅ 表格內容即時更新

**重複測試其他欄位**:
- 排名
- 車手最速圈
- 差異
- 與全場最速差距

---

#### 7.4 Tooltip 懸停測試

**測試步驟**:
1. 將滑鼠懸停在 **"理想圈"** 欄位上
2. 等待 1-2 秒

**預期結果**:
- ✅ 出現浮動提示視窗
- ✅ 顯示內容：
  ```
  理想圈: 1:30.625
  S1: 31.320s (Lap 42)
  S2: 41.605s (Lap 23)
  S3: 17.700s (Lap 18)
  ```

**重複測試其他欄位**:
- 車手最速圈（顯示分段時間 + 圈數）
- 差異（顯示百分比 + 評估）
- 全場最速實際圈（顯示創造者 + 圈數）
