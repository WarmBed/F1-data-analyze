# 理想圈排名表格 - 快速使用指南

## 🚀 啟動步驟

### 1. 啟動 F1T GUI
```powershell
python f1t_gui_main.py
```

### 2. 開啟理想圈分析
在左側功能樹中找到並點擊：
```
📊 Ideal Lap Analysis (理想圈分析)
```

### 3. 選擇分析類型
在彈出的對話框中選擇：
- ✅ **Ranking Table (All Drivers Overview)** ← 選這個！
- ⏳ Sector Heatmap (S1/S2/S3 Performance) - 尚未實作
- ⏳ Sector Comparison (Ideal vs Fastest) - 尚未實作

點擊 **"確認"**

### 4. 輸入賽事參數
- **年份**: 2025（或其他可用年份）
- **賽事**: Japan（或其他賽事）
- **賽段**: R（正賽）/ Q（排位賽）/ FP1/FP2/FP3（練習賽）

點擊 **"確認"**

### 5. 查看結果
系統會自動載入並顯示：
- 📊 **統計摘要面板**（上方）
- 📋 **排名表格**（主要區域）
- 🔄 **控制面板**（底部）

## 🎨 顏色編碼說明

### 差異欄位（評估單圈潛力）
- 🟢 **綠色** (0-0.2s): 接近完美單圈，潛力已充分發揮
- 🟡 **黃色** (0.2-0.5s): 有中等提升空間
- 🔴 **紅色** (>0.5s): 有明顯改善空間，潛力尚未發揮

### 與全場最速差距欄位（評估競爭力）
- 🟢 **深綠色** (<0.5s): 極具競爭力
- 🟢 **淺綠色** (0.5-1s): 具競爭力
- 🟡 **黃色** (1-2s): 中游水平
- 🔴 **紅色** (>2s): 落後

## 📊 統計摘要面板解讀

### 基本資訊
- **總車手數**: 參賽車手總數（通常為 20）

### 全場最速實際圈
- **時間**: 所有車手真實跑出的最快單圈
- **創造者**: 車手代碼 + 圈數
- **意義**: 實際賽況的最佳單圈表現

### 理想圈統計
- **最快理想圈**: 理論上最快的單圈（如果某車手同時發揮三個分段最佳）
- **理想圈範圍**: 最快與最慢理想圈的差距

### 潛力分析
- **平均差異**: 所有車手「最速圈 - 理想圈」的平均值
  - 數值越大 = 整體發揮不穩定
  - 數值越小 = 車手們都接近完美單圈
  
- **完美單圈達成率**: 同時發揮三個分段最佳的車手數
  - 0/20 (0%) = 沒有車手達成完美單圈
  - 通常很難達成，因為需要在同一圈同時發揮三個分段的極限

## ❓ 常見問題

### Q: 為什麼表格是空的？
**A**: 請確認：
1. 本地有對應的 JSON 檔案（`json/ideal_lap_ranking_{year}_{race}_{session}.json`）
2. 或者 API 服務器正常運行
3. 檢查控制台輸出的錯誤訊息

**解決方法**：手動執行 CLI 生成 JSON
```powershell
python f1_analysis_modular_main.py -f 53 -y 2025 -r Japan -s R
```

### Q: 差異欄位顯示負值是什麼意思？
**A**: 這是不正常的情況，理論上不會發生。差異應該是 **最速圈 - 理想圈**，必定 ≥ 0。
- 如果出現負值，請檢查 JSON 資料的正確性

### Q: 為什麼某些車手的分段標記全是 ✗？
**A**: 分段標記 ✓ 表示該分段來自最速圈：
- ✓✓✓ = 完美單圈（三個分段都來自最速圈）
- ✗✗✗ = 沒有任何分段來自最速圈（理想圈由其他圈組成）

### Q: 全場最速實際圈是什麼？
**A**: 
- **實際圈**: 車手真正跑出的完整單圈
- **理想圈**: 將不同圈的最佳分段組合而成（理論值）
- **全場最速實際圈**: 所有車手中，實際跑出的最快單圈

範例：
- VER 最速圈: 1:31.106（實際跑出）
- VER 理想圈: 1:30.625（S1 來自 Lap 42, S2 來自 Lap 23, S3 來自 Lap 18）
- 全場最速: 1:30.965 (ANT, Lap 42)（所有車手中最快的實際圈）
