# Tutorial Resources

This folder contains tutorial images and GIFs for the Welcome Tutorial dialog.

## Required Files

Place the following files in this folder:

| File Name | Description | Recommended Size |
|-----------|-------------|------------------|
| `welcome.gif` or `welcome.png` | Welcome screen illustration | 400x300 px |
| `select_session.gif` or `select_session.png` | Session selection demo | 400x300 px |
| `open_module.gif` or `open_module.png` | Module opening demo | 400x300 px |
| `live_timing.gif` or `live_timing.png` | Live timing feature demo | 400x300 px |
| `ready.gif` or `ready.png` | Ready/completion illustration | 400x300 px |

## Notes

- GIF format is preferred for animated demonstrations
- PNG format is used as fallback for static images
- If no image files are found, the tutorial will display text-only content
- Recommended dimensions: 400x300 pixels for optimal display

## Creating Tutorial GIFs

You can use tools like:
- [ScreenToGif](https://www.screentogif.com/) (Windows)
- [LICEcap](https://www.cockos.com/licecap/) (Windows/Mac)
- [Peek](https://github.com/phw/peek) (Linux)

Record the relevant UI interactions and save as GIF files.
