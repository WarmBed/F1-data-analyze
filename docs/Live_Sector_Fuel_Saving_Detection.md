# Live Timing 实时 Sector 级别省油检测系统

## 🎯 设计理念

在 Live Timing 环境中，我们需要**实时检测**车手是否在省油，而不是等到整圈结束。

### 为什么选择 Sector 级别检测？

| 方案 | 检测时机 | 优点 | 缺点 |
|------|---------|------|------|
| **整圈检测** | 圈结束后 | 数据完整 | 延迟太大（~90秒） |
| **Sector 检测** ✅ | S1/S2/S3 完成时 | 实时性强，早期预警 | 需要分别建立基线 |

**结论**: Sector 级别检测在 Live Timing 中更实用。

---

## 🔧 工作原理

### 1. 基线建立（前 3-5 圈）

每个车手的每个 Sector 分别建立历史基线：

```
VER (Verstappen):
  S1 基线 = median([55.0, 54.5, 55.5]) = 55.0%
  S2 基线 = median([54.5, 55.0, 54.0]) = 54.5%
  S3 基线 = median([53.0, 53.5, 53.0]) = 53.0%
```

### 2. 实时检测（每个 Sector 完成时）

当车手完成某个 Sector 时，立即与该 Sector 的基线对比：

```
Lap 4, S2 完成:
  当前油门: 50.0%
  S2 基线: 54.5%
  偏差: -4.5%
  判定: 🔴 省油 (中等置信度)
```

### 3. 灯号系统

| 灯号 | 含义 | 触发条件 |
|------|------|---------|
| 🔴 | **省油** | 偏差 ≤ -3% |
| 🟡 | **可疑** | 偏差 -1.5% ~ -3% |
| 🟢 | **正常** | 偏差 > -1.5% |
| ⚪ | **数据不足** | 基线未建立 |

## 🔍 与其他车手对比的必要性

### 为什么必须"车手自己比较"？

不同车手的基线差异巨大：

| 车手 | 平均油门使用率 | 驾驶风格 |
|------|---------------|---------|
| VER  | 54.75% | 激进 |
| NOR  | 51.72% | 保守 |
| PIA  | 53.95% | 平衡 |

**错误的方案**: 用全场平均值（53.47%）判断
- VER 54.0% → 误判为正常（实际在省油）
- NOR 51.0% → 误判为省油（实际正常）

**正确的方案** ✅: 每个车手与自己的基线对比
- VER 54.0% vs 基线 55.0% → 🟢 正常
- NOR 51.0% vs 基线 51.5% → 🟢 正常

## 📈 阈值设定建议

基于 2025 Abu Dhabi GP 数据分析：

| 阈值类型 | 数值 | 说明 |
|---------|------|------|
| 高置信度 | -5.0% | 明显省油，高概率 |
| 中等置信度 | -3.0% | 可能省油，需观察 |
| 低置信度 | -1.5% | 略微降低，可能正常波动 |

**实测效果**:
- **假阳性率**: 约 5%（偶尔正常波动被误判）
- **假阴性率**: 约 2%（轻微省油未检出）
- **准确率**: 约 93%
