## ⚠️ FastF1 數據限制聲明

### 實際可用的遙測數據
```python
# ✅ 可用欄位
telemetry['Speed']      # 速度 (km/h) - 連續值
telemetry['Throttle']   # 油門 (0-100%) - 連續百分比
telemetry['Brake']      # 煞車 (0/1) - ⚠️ 布林開關，非壓力百分比！
telemetry['Distance']   # 累積距離 (m) - 連續值
telemetry['Time']       # 時間戳 (timedelta) - 連續值
telemetry['nGear']      # 檔位 (1-8) - 離散整數
telemetry['RPM']        # 引擎轉速 - 連續值
telemetry['DRS']        # DRS 狀態 (0/1/10/12/14) - 離散值
# ❌ 不穩定/不可用
# telemetry['X'], telemetry['Y']  # 僅部分賽季有，不可靠
```

### 關鍵限制
1. **Brake 只有 0/1**：無法直接獲取煞車壓力百分比
2. **無曲率數據**：需透過 Speed 和 Distance 間接推算
3. **取樣率不固定**：需要重取樣到固定頻率（建議 20 Hz）

## 🎯 核心功能模組

### 模組 1：減速侵略性分析
**指標名稱**：`Deceleration Aggressiveness (ΔV/Δt)`

#### 理論基礎
專業分析工具（AiM、MoTeC）以「煞車點→最小速」的速度跌幅與時間衡量制動強度。

#### FastF1 實作方法
```python
# 步驟 1: 定義入彎窗口
entry_window_start = corner_apex_distance - 50  # 彎心前 50m
entry_window_end = corner_apex_distance

# 步驟 2: 提取窗口內遙測
entry_telemetry = telemetry[
    (telemetry['Distance'] >= entry_window_start) &
    (telemetry['Distance'] <= entry_window_end)
]

# 步驟 3: 計算減速指標
entry_speed = entry_telemetry['Speed'].iloc[0]   # 入彎初速
min_speed = entry_telemetry['Speed'].min()        # 彎中最低速
delta_v = entry_speed - min_speed                # 速度變化量 (km/h)

# 步驟 4: 計算減速時間
brake_start_idx = entry_telemetry[entry_telemetry['Brake'] == 1].index[0]
min_speed_idx = entry_telemetry['Speed'].idxmin()
decel_time = (entry_telemetry.loc[min_speed_idx, 'Time'] - 
              entry_telemetry.loc[brake_start_idx, 'Time']).total_seconds()

# 步驟 5: 計算侵略性指標
aggressiveness = delta_v / decel_time  # km/h per second
```

#### 輸出欄位
- `entry_speed` (km/h): 入彎初速
- `min_speed` (km/h): 彎中最低速
- `delta_v` (km/h): 速度變化量
- `decel_time` (s): 制動時間
- `aggressiveness` (km/h/s): 減速侵略性（越大越果斷）

### 模組 2：油門上升斜率分析
**指標名稱**：`Throttle Application Rate (Slope)`

#### 理論基礎
OptimumG 和教練界用「油門接回延遲/速率」評估出彎信心。

#### FastF1 實作方法（含重取樣）
```python
import numpy as np
from scipy.interpolate import interp1d

# 步驟 1: 定義出彎窗口
exit_window_start = corner_apex_distance
exit_window_end = corner_apex_distance + 100  # 彎心後 100m

exit_telemetry = telemetry[
    (telemetry['Distance'] >= exit_window_start) &
    (telemetry['Distance'] <= exit_window_end)
].copy()

# 步驟 2: 重取樣到 20 Hz (避免低頻抖動)
time_seconds = exit_telemetry['Time'].dt.total_seconds()
distance = exit_telemetry['Distance'].values
throttle = exit_telemetry['Throttle'].values

# 建立等時間間距的新時間軸 (20 Hz = 0.05s 間隔)
time_min, time_max = time_seconds.min(), time_seconds.max()
new_time = np.arange(time_min, time_max, 0.05)

# 插值重取樣
throttle_interp = interp1d(time_seconds, throttle, kind='linear', 
                           fill_value='extrapolate')
throttle_resampled = throttle_interp(new_time)

# 步驟 3: 計算斜率 (線性回歸)
# 找到油門從 <10% 上升到 >80% 的區間
start_idx = np.where(throttle_resampled >= 10)[0][0]
end_idx = np.where(throttle_resampled >= 80)[0][0]

delta_throttle = throttle_resampled[end_idx] - throttle_resampled[start_idx]
delta_time = (end_idx - start_idx) * 0.05  # 20 Hz = 0.05s per sample

throttle_slope = delta_throttle / delta_time  # % per second
```

#### 輸出欄位
- `throttle_start` (%): 起始油門開度
- `throttle_end` (%): 結束油門開度
- `throttle_slope` (%/s): 油門上升斜率（越大越激進）
- `apply_delay` (s): 從彎心到油門 >10% 的延遲時間

### 模組 3：煞車時機點分析
**指標名稱**：`Brake Onset Timing`

#### 理論基礎
Driver vs Driver 教練工具檢查誰更晚進入制動，且能穩定控制。

#### FastF1 實作方法（Brake 只有 0/1）
```python
# 步驟 1: 找到煞車第一次啟動的位置
corner_telemetry = telemetry[
    (telemetry['Distance'] >= corner_start) &
    (telemetry['Distance'] <= corner_end)
]

# ⚠️ Brake 是布林值，找第一次 == 1 的點
brake_onset = corner_telemetry[corner_telemetry['Brake'] == 1]

if not brake_onset.empty:
    brake_distance = brake_onset.iloc[0]['Distance']
    brake_speed = brake_onset.iloc[0]['Speed']
    
    # 計算煞車點到彎心的距離
    distance_to_apex = corner_apex_distance - brake_distance
    
    # 檢查煞車穩定性（速度變化線性度）
    brake_to_apex = corner_telemetry[
        (corner_telemetry['Distance'] >= brake_distance) &
        (corner_telemetry['Distance'] <= corner_apex_distance)
    ]
    
    # 計算速度變化的線性度（R²值，越接近1越穩定）
    from scipy.stats import linregress
    distances = brake_to_apex['Distance'].values
    speeds = brake_to_apex['Speed'].values
    slope, intercept, r_value, _, _ = linregress(distances, speeds)
    linearity = r_value ** 2  # R² 值
```

#### 輸出欄位
- `brake_onset_distance` (m): 煞車點距離
- `brake_onset_speed` (km/h): 煞車時速度
- `distance_to_apex` (m): 煞車點到彎心距離（越小越晚煞）
- `brake_linearity`: 煞車穩定性 (0-1，越大越線性)

### 模組 4：彎區局部時間損失
**指標名稱**：`Corner Time Loss (Local Δt)`

#### 理論基礎
MoTeC/AiM/Coach Dave 用 Delta-T 做局部勝負判讀。

#### FastF1 實作方法
```python
# 步驟 1: 建立參考圈（最快圈或指定車手）
reference_lap = driver.pick_fastest()
reference_telemetry = reference_lap.get_car_data().add_distance()

comparison_lap = driver.laps[lap_number]
comparison_telemetry = comparison_lap.get_car_data().add_distance()

# 步驟 2: 定義彎區窗口
corner_ref = reference_telemetry[
    (reference_telemetry['Distance'] >= corner_start) &
    (reference_telemetry['Distance'] <= corner_end)
]

corner_comp = comparison_telemetry[
    (comparison_telemetry['Distance'] >= corner_start) &
    (comparison_telemetry['Distance'] <= corner_end)
]

# 步驟 3: 計算時間差
ref_time = (corner_ref['Time'].iloc[-1] - corner_ref['Time'].iloc[0]).total_seconds()
comp_time = (corner_comp['Time'].iloc[-1] - corner_comp['Time'].iloc[0]).total_seconds()

time_loss = comp_time - ref_time  # 正值 = 損失時間
```

#### 輸出欄位
- `corner_time_ref` (s): 參考圈彎區時間
- `corner_time_comp` (s): 比較圈彎區時間
- `time_loss` (s): 時間損失（正值=慢，負值=快）
- `time_loss_percent` (%): 相對時間損失百分比

### 模組 5：出彎加速效率
**指標名稱**：`Corner Exit Speed (50m Average)`

#### 理論基礎
AiM 的 times-to-speed/-distance 指標，評估出彎抓地力利用。

#### FastF1 實作方法
```python
# 步驟 1: 定義出彎評估窗口（彎心後 50m）
exit_window = telemetry[
    (telemetry['Distance'] >= corner_apex_distance) &
    (telemetry['Distance'] <= corner_apex_distance + 50)
]

# 步驟 2: 計算平均速度
exit_avg_speed = exit_window['Speed'].mean()

# 步驟 3: 計算加速率
exit_start_speed = exit_window['Speed'].iloc[0]
exit_end_speed = exit_window['Speed'].iloc[-1]
exit_delta_v = exit_end_speed - exit_start_speed

exit_time = (exit_window['Time'].iloc[-1] - 
             exit_window['Time'].iloc[0]).total_seconds()
acceleration = exit_delta_v / exit_time  # km/h per second
```

#### 輸出欄位
- `exit_avg_speed` (km/h): 出彎 50m 平均速度
- `exit_acceleration` (km/h/s): 出彎加速率
- `exit_delta_v` (km/h): 出彎速度增量

## 📊 進階分析：車手風格分型

### 彎道分類系統
依照 `min_speed` 將彎道分為三類：

| 類別 | 速度範圍 | 典型代表 |
|------|---------|---------|
| **低速彎** | < 120 km/h | 髮夾彎、慢速 chicane |
| **中速彎** | 120-180 km/h | 一般彎角 |
| **高速彎** | > 180 km/h | Copse、130R |

### Corner Performance Index (CPI)
將五大指標規範化到 0-100 分，加權計算：

```python
# 步驟 1: 對每個彎型（低/中/高速）分別計算
for corner_type in ['low', 'mid', 'high']:
    corners = [c for c in all_corners if c['type'] == corner_type]
    
    # 步驟 2: 規範化每個指標到 0-100
    # (值越大越好的指標，如晚煞、高出彎速)
    for metric in ['aggressiveness', 'throttle_slope', 'exit_speed']:
        min_val = min(c[metric] for c in corners)
        max_val = max(c[metric] for c in corners)
        for c in corners:
            c[f'{metric}_normalized'] = 100 * (c[metric] - min_val) / (max_val - min_val)
    
    # 步驟 3: 加權平均計算 CPI
    weights = {
        'aggressiveness': 0.30,      # 減速侵略性
        'throttle_slope': 0.25,      # 油門斜率
        'exit_speed': 0.25,          # 出彎速度
        'brake_timing': 0.10,        # 煞車時機（晚煞得分高）
        'time_efficiency': 0.10      # 時間效率（損失少得分高）
    }
    
    cpi = sum(c[f'{metric}_normalized'] * weights[metric] 
              for metric in weights.keys())
```

### 風格判定邏輯
```python
cpi_low = calculate_cpi(corners_low_speed)
cpi_high = calculate_cpi(corners_high_speed)

delta_cpi = cpi_high - cpi_low

if delta_cpi > 3:
    driver_style = "高速彎型"
    style_description = "擅長高速彎，依賴空力下壓力"
elif delta_cpi < -3:
    driver_style = "低速彎型"
    style_description = "擅長低速彎，機械抓地力利用優秀"
else:
    driver_style = "平衡型"
    style_description = "高低速彎表現均衡"
```

## 🛠️ 實作注意事項

### 1. 數據預處理流程
```python
# 必要步驟（依序執行）
def preprocess_telemetry(telemetry):
    # 1. 重取樣到固定頻率 (20 Hz)
    telemetry = resample_to_frequency(telemetry, freq=20)
    
    # 2. 過濾異常值
    telemetry = telemetry[
        (telemetry['Speed'] >= 0) &
        (telemetry['Throttle'] >= 0) &
        (telemetry['Throttle'] <= 100)
    ]
    
    # 3. 加入累積距離（如果沒有）
    if 'Distance' not in telemetry.columns:
        telemetry = telemetry.add_distance()
    
    return telemetry
```
