## 🎯 核心理論基礎

### 難度量化的邏輯

```
彎道難度 = f(車手間表現差異)

邏輯推論：
┌─────────────────────────────────────────┐
│ 如果一個彎道「技術門檻高」：            │
│  → 頂尖車手能做得很好                   │
│  → 普通車手做得較差                     │
│  → 車手間表現差異大                     │
│  → 統計離散度高                         │
│                                         │
│ 如果一個彎道「容錯率高」：              │
│  → 所有車手都能做得不錯                 │
│  → 車手間表現差異小                     │
│  → 統計離散度低                         │
└─────────────────────────────────────────┘
```

## 📊 四大統計指標

### 指標 1: 變異係數 (Coefficient of Variation, CV)

#### 理論基礎
**變異係數 = 標準差 / 平均值 × 100%**

用於衡量數據的相對離散程度，消除絕對值大小的影響。

#### 為什麼適合評估彎道難度？
- **高 CV**：車手間表現分散 → 有人做得很好，有人很差 → **技術門檻高**
- **低 CV**：車手間表現集中 → 大家都差不多 → **容錯率高**

#### 實作方法
```python
def calculate_corner_difficulty_cv(corner_id, all_drivers_data):
    """
    計算彎道的變異係數
    
    輸入：
    - corner_id: 彎道編號
    - all_drivers_data: 所有車手在該彎道的 CPS 分數
    
    輸出：
    - cv_percent: 變異係數百分比
    - cv_score: 標準化到 0-100 的難度分數
    """
    import numpy as np
    
    # 提取所有車手的 CPS
    all_cps = np.array([driver['cps'] for driver in all_drivers_data])
    
    # 計算統計量
    mean_cps = np.mean(all_cps)
    std_cps = np.std(all_cps, ddof=1)  # 使用樣本標準差
    
    # 計算變異係數
    cv = (std_cps / mean_cps) * 100  # 百分比形式
    
    # 規範化到 0-100 分
    # 假設 CV 範圍通常在 0-30%（經驗值）
    cv_score = min(100, (cv / 30) * 100)
    
    # 難度判定
    if cv > 15:
        difficulty_level = '極難'
    elif cv > 10:
        difficulty_level = '困難'
    elif cv > 5:
        difficulty_level = '中等'
    else:
        difficulty_level = '簡單'
    
    return {
        'cv_percent': round(cv, 2),
        'cv_score': round(cv_score, 1),
        'mean_cps': round(mean_cps, 2),
        'std_cps': round(std_cps, 2),
        'difficulty_level': difficulty_level,
        'interpretation': f'CV={cv:.1f}%，車手間表現{"分散" if cv > 10 else "集中"}，難度{difficulty_level}'
    }
```

### 指標 2: 百分位間距 (Interquartile Range, IQR)

#### 理論基礎
**IQR = Q3 (75th percentile) - Q1 (25th percentile)**

衡量中間 50% 數據的離散程度，不受極端值影響，比標準差更穩健。

#### 為什麼適合評估彎道難度？
- **大 IQR**：中段車手（P25-P75）差異大 → 有明顯學習曲線 → **技術要求高**
- **小 IQR**：中段車手差異小 → 表現接近 → **容錯率高**

#### 實作方法
```python
def calculate_corner_difficulty_iqr(corner_id, all_drivers_data):
    """
    計算彎道的百分位間距
    
    優點：
    - 不受極端值影響（例如某車手失誤或特別優秀）
    - 專注於「普通車手」的差異
    """
    import numpy as np
    
    all_cps = np.array([driver['cps'] for driver in all_drivers_data])
    
    # 計算百分位數
    q25 = np.percentile(all_cps, 25)
    q50 = np.percentile(all_cps, 50)  # 中位數
    q75 = np.percentile(all_cps, 75)
    
    # 計算 IQR
    iqr = q75 - q25
    
    # 規範化到 0-100 分
    # 假設 IQR 通常在 0-20 分範圍
    iqr_score = min(100, (iqr / 20) * 100)
    
    # 難度判定
    if iqr > 15:
        difficulty_level = '極難'
    elif iqr > 10:
        difficulty_level = '困難'
    elif iqr > 5:
        difficulty_level = '中等'
    else:
        difficulty_level = '簡單'
    
    return {
        'iqr': round(iqr, 2),
        'iqr_score': round(iqr_score, 1),
        'q25': round(q25, 2),
        'q50': round(q50, 2),
        'q75': round(q75, 2),
        'difficulty_level': difficulty_level,
        'interpretation': f'中段車手差距 {iqr:.1f} 分，難度{difficulty_level}'
    }
```

### 指標 3: 時間損失敏感度 (Time Loss Sensitivity)

#### 理論基礎
**相關係數 = Corr(Corner Performance Score, Time Loss)**

衡量「技巧差異」與「時間損失」的關聯強度。

#### 為什麼適合評估彎道難度？
- **高相關性**：技巧稍差 → 時間損失大 → **懲罰性高，難度大**
- **低相關性**：技巧差異對時間影響小 → **容錯率高**

#### 實作方法
```python
def calculate_time_loss_sensitivity(corner_id, all_drivers_data):
    """
    計算彎道的時間損失敏感度
    
    概念：
    - 如果該彎道「懲罰性高」，技巧稍差會造成明顯時間損失
    - 如果該彎道「容錯率高」，技巧差異對時間影響較小
    """
    import numpy as np
    from scipy.stats import pearsonr
    
    # 提取數據
    cps_values = np.array([driver['cps'] for driver in all_drivers_data])
    time_loss_values = np.array([driver['time_loss'] for driver in all_drivers_data])
    
    # 計算 Pearson 相關係數
    # 預期：CPS 高 → Time Loss 低（負相關）
    correlation, p_value = pearsonr(cps_values, time_loss_values)
    
    # 取絕對值作為敏感度
    sensitivity = abs(correlation) * 100
    
    # 規範化到難度分數
    sensitivity_score = sensitivity  # 已經是 0-100
    
    # 統計顯著性檢定
    is_significant = p_value < 0.05
    
    # 難度判定
    if sensitivity > 80 and is_significant:
        difficulty_level = '極難'
        interpretation = '技巧差異對時間影響極大，懲罰性高'
    elif sensitivity > 60:
        difficulty_level = '困難'
        interpretation = '技巧差異對時間有明顯影響'
    elif sensitivity > 40:
        difficulty_level = '中等'
        interpretation = '技巧差異對時間有一定影響'
    else:
        difficulty_level = '簡單'
        interpretation = '容錯率高，技巧差異對時間影響小'
    
    return {
        'correlation': round(correlation, 3),
        'sensitivity_score': round(sensitivity_score, 1),
        'p_value': round(p_value, 4),
        'is_significant': is_significant,
        'difficulty_level': difficulty_level,
        'interpretation': interpretation
    }
```

#### 輸出範例
```json

  "sensitivity_analysis": {
    "correlation": -0.847,
    "sensitivity_score": 84.7,
    "p_value": 0.0002,
    "is_significant": true,
    "difficulty_level": "極難",
    "interpretation": "技巧差異對時間影響極大，懲罰性高"
  }
}
```

### 指標 4: 技巧熵值 (Skill Entropy)

#### 理論基礎
**Shannon Entropy = -Σ(p_i × log₂(p_i))**

衡量車手排名的「可預測性」，用於區分「技術導向」vs「運氣導向」的彎道。

#### 為什麼適合評估彎道難度？
- **低熵值**：車手排名穩定 → 技術決定勝負 → **純技術彎**
- **高熵值**：車手排名隨機 → 運氣/條件影響大 → **不穩定彎**

#### 實作方法
```python
def calculate_skill_entropy(corner_id, lap_to_lap_rankings):
    """
    計算彎道的技巧熵值
    
    輸入：
    - lap_to_lap_rankings: 多圈數據中，每位車手在該彎道的排名變化
      例如：VER 在 20 圈中，5 次第 1 名，10 次第 2 名，5 次第 3 名
    
    輸出：
    - entropy: Shannon 熵值
    - entropy_score: 標準化分數（反向，熵低=穩定=技術導向）
    """
    import numpy as np
    from scipy.stats import entropy as shannon_entropy
    
    # 統計每個車手的排名分布
    # 假設 lap_to_lap_rankings = [[1,2,1,1,2,3,...], [5,6,5,4,6,...], ...]
    # 每個子列表是一位車手在多圈的排名
    
    all_entropies = []
    
    for driver_rankings in lap_to_lap_rankings:
        # 計算該車手排名的分布
        unique_ranks, counts = np.unique(driver_rankings, return_counts=True)
        probabilities = counts / len(driver_rankings)
        
        # 計算 Shannon 熵
        driver_entropy = shannon_entropy(probabilities, base=2)
        all_entropies.append(driver_entropy)
    
    # 平均熵值
    mean_entropy = np.mean(all_entropies)
    
    # 最大可能熵（完全隨機排名）
    # 假設有 N 個可能排名（例如 1-20）
    max_entropy = np.log2(20)  # 約 4.32
    
    # 規範化（反向：熵低=穩定=技術導向=難度高）
    entropy_normalized = (mean_entropy / max_entropy) * 100
    skill_score = 100 - entropy_normalized  # 反向
    
    # 難度判定
    if skill_score > 80:
        difficulty_level = '極難'
        interpretation = '排名高度穩定，純技術導向彎道'
    elif skill_score > 60:
        difficulty_level = '困難'
        interpretation = '排名較穩定，技術主導'
    elif skill_score > 40:
        difficulty_level = '中等'
        interpretation = '排名有一定變化，技術+條件影響'
    else:
        difficulty_level = '簡單'
        interpretation = '排名變化大，運氣/條件影響較大'
    
    return {
        'entropy': round(mean_entropy, 3),
        'max_entropy': round(max_entropy, 3),
        'entropy_score': round(entropy_normalized, 1),
        'skill_score': round(skill_score, 1),  # 反向分數
        'difficulty_level': difficulty_level,
        'interpretation': interpretation
    }
```

#### 輸出範例
```json

    "max_entropy": 4.322,
    "entropy_score": 28.8,

    "difficulty_level": "困難",
    "interpretation": "排名較穩定，技術主導"
  }
```

## 🏆 綜合難度指數 (Corner Difficulty Index, CDI)

### 四指標加權平均

```python
def calculate_corner_difficulty_index(corner_id, all_drivers_data):
    """
    綜合四個統計指標計算彎道難度指數 (CDI)
    
    權重設計邏輯：
    - CV (35%): 最直接的離散度指標
    - IQR (25%): 穩健的中段差異指標
    - Sensitivity (25%): 結果導向的時間懲罰指標
    - Entropy (15%): 技術 vs 運氣的區分指標
    """
    
    # ========== 計算四個指標 ==========
    cv_result = calculate_corner_difficulty_cv(corner_id, all_drivers_data)
    iqr_result = calculate_corner_difficulty_iqr(corner_id, all_drivers_data)
    sensitivity_result = calculate_time_loss_sensitivity(corner_id, all_drivers_data)
    entropy_result = calculate_skill_entropy(corner_id, all_drivers_data['lap_rankings'])
    
    # ========== 加權平均 ==========
    weights = {
        'cv': 0.35,
        'iqr': 0.25,
        'sensitivity': 0.25,
        'entropy': 0.15
    }
    
    cdi = (
        cv_result['cv_score'] * weights['cv'] +
        iqr_result['iqr_score'] * weights['iqr'] +
        sensitivity_result['sensitivity_score'] * weights['sensitivity'] +
        entropy_result['skill_score'] * weights['entropy']  # 使用反向分數
    )
    
    # ========== 難度分級 ==========
    if cdi >= 80:
        difficulty_level = '極難 (Expert Level)'
        difficulty_color = '#FF0000'  # 紅色
        difficulty_description = '頂尖技術要求，極小失誤即造成重大時間損失'
    elif cdi >= 60:
        difficulty_level = '困難 (Advanced)'
        difficulty_color = '#FF8800'  # 橙色
        difficulty_description = '高技術要求，車手間差異明顯'
    elif cdi >= 40:
        difficulty_level = '中等 (Intermediate)'
        difficulty_color = '#FFFF00'  # 黃色
        difficulty_description = '中等技術要求，有一定學習曲線'
    else:
        difficulty_level = '簡單 (Beginner Friendly)'
        difficulty_color = '#00FF00'  # 綠色
        difficulty_description = '容錯率高，車手間差異小'
    
    # ========== 輸出完整結果 ==========
    return {
        'corner_id': corner_id,
        'cdi': round(cdi, 1),
        'difficulty_level': difficulty_level,
        'difficulty_color': difficulty_color,
        'difficulty_description': difficulty_description,
        'components': {
            'cv_score': cv_result['cv_score'],
            'iqr_score': iqr_result['iqr_score'],
            'sensitivity_score': sensitivity_result['sensitivity_score'],
            'skill_score': entropy_result['skill_score']
        },
        'detailed_analysis': {
            'cv': cv_result,
            'iqr': iqr_result,
            'sensitivity': sensitivity_result,
            'entropy': entropy_result
        },
        'summary': f"CDI={cdi:.1f}/100，{difficulty_level}，{difficulty_description}"
    }
```

## 🛠️ 實作注意事項

### 1. 數據預處理

```python
def preprocess_corner_data(all_drivers_telemetry, corner_start, corner_end):
    """
    預處理彎道數據
    
    必要步驟：
    1. 過濾有效圈（排除黃旗、事故、出 Pit）
    2. 標準化條件（相同輪胎配方、胎齡接近）
    3. 異常值檢測（排除極端失誤）
    """
    
    valid_laps = []
    
    for driver_data in all_drivers_telemetry:
        # 1. 過濾條件
        if not driver_data['lap']['IsAccurate']:
            continue
        if driver_data['lap']['TrackStatus'] != '1':  # 黃旗/紅旗
            continue
        if driver_data['lap']['PitOutTime'] is not None:  # 出 Pit
            continue
        
        # 2. 提取彎道區間數據
        corner_telemetry = driver_data['telemetry'][
            (driver_data['telemetry']['Distance'] >= corner_start) &
            (driver_data['telemetry']['Distance'] <= corner_end)
        ]
        
        # 3. 計算該彎道的 CPS（需要 F55 的五模組計算）
        cps = calculate_corner_performance_score(corner_telemetry)
        
        valid_laps.append({
            'driver': driver_data['driver_code'],
            'cps': cps,
            'time_loss': driver_data['time_loss'],
            'lap_number': driver_data['lap_number']
        })
    
    return valid_laps
```

### 2. 統計顯著性檢定

```python
def validate_statistical_significance(cdi_components):
    """
    驗證統計顯著性
    
    檢查：
    1. Sensitivity 的 p-value < 0.05
    2. 樣本數 >= 15（至少 15 位車手）
    3. CV 和 IQR 的一致性（兩者都高或都低）
    """
    
    warnings = []
    
    # 檢查 1: Sensitivity 顯著性
    if not cdi_components['sensitivity']['is_significant']:
        warnings.append('時間損失相關性不顯著 (p >= 0.05)，Sensitivity 分數可能不可靠')
    
    # 檢查 2: 樣本數
    if cdi_components['sample_size'] < 15:
        warnings.append(f'樣本數不足 (n={cdi_components["sample_size"]})，建議至少 15 位車手')
    
    # 檢查 3: CV 和 IQR 一致性
    cv_high = cdi_components['cv_score'] > 60
    iqr_high = cdi_components['iqr_score'] > 60
    
    if cv_high != iqr_high:
        warnings.append('CV 和 IQR 結果不一致，可能受極端值影響')
    
    return {
        'is_valid': len(warnings) == 0,
        'warnings': warnings
    }
```
