#### **什麼是 PoC 測試？**
PoC（Proof of Concept，概念驗證）測試是在正式開發前，用**最小化的測試**來驗證**關鍵假設是否成立**。目的是確保設計思路在真實數據中可行，避免開發到一半才發現技術上無法實現。

**為什麼需要 PoC？**
- **傳統開發流程風險**：需求 → 開發 3 天 → 測試 → ❌ 發現假設錯誤 → 重寫 3 天
- **PoC 優先流程**：需求 → PoC 0.5 天 → ✅ 驗證可行 → 開發 1.5 天 → 測試 → ✅ 通過
- **節省時間**：3 天重工 → 0.5 天驗證 = **節省 2.5 天**

**測試方法**：容差機制（tolerance=10m）
```python
def get_speed_at_distance(telemetry, target_distance, tolerance=10):
    """獲取最接近目標距離的速度"""
    nearby = telemetry[
        telemetry['Distance'].between(
            target_distance - tolerance, 
            target_distance + tolerance
        )
    ]
    if nearby.empty:
        return None
    # 返回最接近的點
    closest_idx = (nearby['Distance'] - target_distance).abs().idxmin()
    return nearby.loc[closest_idx, 'Speed']
```

**測試結果**：✅ **通過**
- 所有彎道的 entry_50m, apex, exit_50m 速度均成功獲取
- **數據完整性**：100%（無 None 值）
- **結論**：FastF1 遙測數據採樣頻率足夠，容差機制有效

**如果失敗的備案**：
- 方案 A: 調整容差範圍（10m → 20m）
- 方案 B: 改用區間平均速度

def _is_yellow_flag_lap(self, lap, session):
    """判斷該圈是否有黃旗"""
    if not hasattr(session, 'race_control_messages'):
        return False
    
    race_control = session.race_control_messages
    if race_control is None or race_control.empty:
        return False
    
    lap_number = lap['LapNumber']
    lap_messages = race_control[race_control['Lap'] == lap_number]
    
    for _, msg in lap_messages.iterrows():
        message = msg.get('Message', '').upper()
        if 'YELLOW FLAG' in message or 'DOUBLE YELLOW' in message:
            return True
    return False
```

# ✅ 改用「最接近」的數據點，而非精確 ±5m 範圍
def get_speed_at_distance(telemetry, target_distance, tolerance=10):
    """獲取最接近目標距離的速度"""
    nearby = telemetry[
        telemetry['Distance'].between(
            target_distance - tolerance, 
            target_distance + tolerance
        )
    ]
    if nearby.empty:
        return None
    # 返回最接近的點
    closest_idx = (nearby['Distance'] - target_distance).abs().idxmin()
    return nearby.loc[closest_idx, 'Speed']
```
