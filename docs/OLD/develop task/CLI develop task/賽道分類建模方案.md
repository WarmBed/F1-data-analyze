## 背景

當前 XGBoost 基準模型達成：
- **MAE**: 0.986s ± 0.280s
- **R²**: 0.938
- **問題**: 所有賽道用同一個模型，但不同類型賽道特性差異巨大

## 賽道分類策略

### 方案 A: 手動分類 + 獨立模型（推薦）

**優點**:
- ✅ 實施簡單（1-2 天）
- ✅ 可解釋性高
- ✅ 預期 MAE 改善 20-30%（0.986s → 0.70-0.75s）

**缺點**:
- ❌ 需要手動維護賽道清單
- ❌ 新賽道需要分類決策

```python
# CLI_modules/cli/prediction/track_classifier.py

class TrackSpecificTrainer:
    def __init__(self):
        self.track_categories = self._load_track_categories()
        self.models = {}
    
    def train_all_categories(self, data):
        """為每個賽道類別訓練獨立模型"""
        for category in self.track_categories.keys():
            # 篩選該類別的賽道數據
            category_tracks = self.track_categories[category]
            data_subset = data[data['race'].isin(category_tracks)]
            
            print(f"\n訓練 {category} 類別模型:")
            print(f"  賽道數: {len(category_tracks)}")
            print(f"  樣本數: {len(data_subset)}")
            
            # 訓練 XGBoost
            model = XGBRegressor(**self.best_params)
            model.fit(data_subset[features], data_subset['q_time'])
            
            # 評估
            mae = self._evaluate(model, data_subset)
            print(f"  MAE: {mae:.3f}s")
            
            # 保存
            self.models[category] = model
            joblib.dump(model, f'models/xgboost_{category}.pkl')
    
    def predict(self, race, features):
        """根據賽道類別選擇對應模型預測"""
        category = self._get_track_category(race)
        model = self.models[category]
        return model.predict(features)
```

## 問題討論

**Q1: 目標 MAE 是多少？**
- 若目標 0.70s → **推薦方案 A**
- 若目標 0.90s → **推薦方案 B**
- 若目標 0.30s → **需要深度學習或 ensemble**

**Q2: 開發時間預算？**
- 0.5 天 → **方案 B**
- 2-3 天 → **方案 A**
- 5+ 天 → **考慮深度學習**

**Q3: 賽道分類是否合理？**
- Baku 同時屬於「高速」和「街道」→ 需要決策
- 部分賽道難以分類（如 Red Bull Ring）→ 放入「混合」

**Q4: 新賽道如何處理？**
- 方案 A: 需要手動分類（基於賽道特性）
- 方案 B: 自動歸類到「mixed」，讓模型學習
