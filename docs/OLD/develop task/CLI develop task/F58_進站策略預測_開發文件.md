## 1. 功能概述

### 1.1 目標

F58 進站策略預測器提供三大核心功能:

| 子功能 | 功能名稱 | 說明 |
|--------|----------|------|
| **58.1** | 進站時機預測 | 預測每位車手的最佳進站圈數 |
| **58.2** | 策略組合優化 | 比較 1-stop / 2-stop / 3-stop 策略 |
| **58.3** | Undercut/Overcut 警告 | 實時偵測對手策略威脅 |

### 1.2 使用場景

```bash
# 完整進站策略分析
python f1_analysis_modular_main.py -f 58 -y 2025 -r Japan -s R

# 指定車手
python f1_analysis_modular_main.py -f 58 -y 2025 -r Japan -s R -d VER -d2 LEC

# 子功能: 只執行 Undercut 警告
python f1_analysis_modular_main.py -f 58.3 -y 2025 -r Japan -s R
```

## 2. 學術研究基礎

### 2.1 核心參考論文

| 論文 | 作者 | 年份 | 方法 | 結果 |
|------|------|------|------|------|
| **Data-driven pit stop decision support** | Sasikumar et al. | 2025 | Bi-LSTM | F1-score: 0.81, Recall: 0.86 |
| **Explainable RL for F1 Race Strategy** | Thomas et al. (Mercedes) | 2025 | PPO | 平均改善 8.6 秒 |
| **Tire Degradation State-Space Model** | Cappello & Hoegh | 2025 | 時變線性模型 | 已整合至 F56 |
| **Lo Stratega** | Marinaro | 2021 | Multi-agent RL | 策略模擬 |

### 2.2 關鍵發現

1. **Bi-LSTM 最佳性能**: 處理時序數據的雙向記憶能力
2. **特徵重要性**:
   - 輪胎壽命 (tire_life) - 最重要
   - 前車進站狀態 (driver_ahead_pitted)
   - 累計 stint 時間
   - 賽道狀態 (Safety Car, 黃旗)
3. **類別不平衡**: 進站圈只佔 ~3.5%，需使用 SMOTE

## 5. 算法設計

### 5.1 進站時機預測 (58.1)

#### 方法 A: 基於衰退曲線的啟發式算法

```python
def calculate_optimal_pit_lap(self, driver_data: Dict) -> int:
    """
    使用 F56 輪胎衰退模型計算最佳進站圈
    
    原理:
    - 每圈損失 = base_degradation + acceleration * tire_age
    - 累計損失 = Σ(每圈損失) = base * n + 0.5 * accel * n²
    - 當累計損失 > pit_loss 時，應該進站
    
    crossover_lap = 解方程: base*n + 0.5*accel*n² = pit_loss
    """
    compound = driver_data['compound']
    circuit = driver_data['circuit']
    
    # 從 tire_degradation_database.json 獲取參數
    base_deg = self.tire_db[circuit]['base_degradation'][compound]
    accel = self.tire_db[circuit]['degradation_acceleration'][compound]
    pit_loss = self.pit_loss_db[circuit]['pit_loss_seconds']
    
    # 二次方程求解
    # 0.5 * accel * n² + base * n - pit_loss = 0
    a = 0.5 * accel
    b = base_deg
    c = -pit_loss
    
    discriminant = b**2 - 4*a*c
    if discriminant >= 0:
        crossover_lap = (-b + math.sqrt(discriminant)) / (2*a)
        return int(crossover_lap)
    
    return self.tire_db[circuit]['optimal_stint_length'][compound]
```

### 5.2 策略組合優化 (58.2)

```python
def compare_strategies(self, race_info: Dict) -> Dict:
    """
    比較不同進站策略的預測總時間
    
    策略選項:
    - 1-stop: S→M, M→H, S→H 等
    - 2-stop: S→M→H, M→S→M 等
    """
    strategies = [
        {"stops": 1, "stints": [("SOFT", 20), ("MEDIUM", 36)]},
        {"stops": 1, "stints": [("MEDIUM", 28), ("HARD", 28)]},
        {"stops": 2, "stints": [("SOFT", 15), ("MEDIUM", 22), ("SOFT", 19)]},
    ]
    
    results = []
    for strategy in strategies:
        total_time = self._simulate_strategy(strategy, race_info)
        results.append({
            "strategy": strategy,
            "predicted_time": total_time,
            "laps_on_each_compound": strategy["stints"]
        })
    
    # 排序找最佳
    results.sort(key=lambda x: x["predicted_time"])
    return {
        "recommended": results[0],
        "alternatives": results[1:],
        "comparison_chart": self._generate_comparison_chart(results)
    }
```

### 5.3 Undercut/Overcut 警告 (58.3)

```python
def check_undercut_threat(self, driver: str, rival: str, 
                          race_state: Dict) -> Dict:
    """
    檢測 undercut 威脅
    
    Undercut 條件:
    1. 對手輪胎較舊 (更多衰退)
    2. 差距在 undercut 窗口內 (通常 1.5-3.0 秒)
    3. 對手尚未進站
    
    計算 undercut 增益:
    undercut_gain = (tire_delta * out_lap_advantage) - track_position_loss
    """
    gap = race_state['gaps'][driver][rival]
    tire_age_diff = race_state['tire_age'][rival] - race_state['tire_age'][driver]
    
    # Undercut 有效窗口
    undercut_window = (1.5, 3.5)  # 秒
    
    if undercut_window[0] <= gap <= undercut_window[1]:
        if tire_age_diff > 5:  # 對手輪胎老 5 圈以上
            threat_level = "HIGH"
            recommendation = "考慮提前進站執行 undercut"
        else:
            threat_level = "MEDIUM"
            recommendation = "監控對手動態"
    else:
        threat_level = "LOW"
        recommendation = "正常執行策略"
    
    return {
        "threat_level": threat_level,
        "gap_to_rival": gap,
        "tire_age_difference": tire_age_diff,
        "undercut_window": undercut_window,
        "recommendation": recommendation
    }
```
