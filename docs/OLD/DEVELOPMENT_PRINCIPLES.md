# 開發原則更新（2025-10-09）

以下原則即刻生效，適用於本專案所有新舊變更：

1. **Markdown 檔案集中管理**
   - 所有 `.md` 檔必須存放於 `docs/` 目錄或其子目錄。
   - 若是針對特定功能的說明，可在 `docs/` 下建立對應子資料夾。
   - 目的：確保文件資源統一、方便檢索並維持版本歷史一致性。

2. **測試資源統一放置**
   - 所有測試程式與相關測試檔案須存放於 `tests/` 目錄或其子資料夾。
   - 涵蓋單元測試、整合測試、測試用樣本資料等。
   - 目的：維持測試結構一致，簡化自動化工作流程與測試維護。

## 推薦執行步驟

- 新增文件或測試時，先確認目標目錄是否已存在對應子資料夾，若無可依需求建立。
- 提交 PR 或分享工作成果前，快速檢查新增檔案路徑是否符合上述原則。
- 若需重新調整既有檔案位置，請同步更新引用路徑與相關設定（如 `pytest` 設定、文件連結等）。

如需補充或調整此原則，請在後續修改中更新本檔案，並於 Commit 訊息註明。
