## 功能特性

### Tab 1: 物件統計
- 顯示記憶體中最常見的物件類型
- 顯示物件數量和百分比
- 可自訂顯示數量（5-100）

### Tab 2: 成長追蹤
- 追蹤兩次掃描之間的物件數量變化
- 顯示物件成長量（紅色/綠色標示）
- 幫助識別記憶體洩漏

### Tab 3: 引用圖
- 生成物件引用關係的視覺化圖表
- 可調整圖表深度（1-10 層）
- 圖表自動保存至 `output/objgraph/` 目錄
- 支援 PNG 格式輸出

### Tab 4: 診斷日誌
- 記錄所有診斷操作
- 包含時間戳記
- 支援清除日誌功能

### 控制面板功能
- **掃描物件**: 執行完整物件掃描
- **追蹤成長**: 啟動成長追蹤模式
- **強制垃圾回收**: 手動觸發 GC（執行 3 輪）
- **自動刷新**: 定時自動掃描（1-60 秒間隔）
- **導出報告**: 匯出完整診斷報告為 TXT 檔案

## 使用指南

### 啟動方式

#### 方法 1: 透過選單
1. 啟動 GUI: `python f1t_gui_main.py`
2. 點擊選單: **Tools** → **Memory Diagnostics** (記憶體診斷)
3. 診斷視窗將在 MDI 區域中開啟

#### 方法 2: 測試模式
```powershell
python test_objgraph_diagnostic.py
```

### 基本操作流程

#### 1. 初始掃描
- 點擊「掃描物件」按鈕
- 等待掃描完成（通常 1-2 秒）
- 查看「物件統計」Tab 的結果

#### 2. 追蹤成長
- 點擊「追蹤成長」按鈕
- 執行一些操作（如開啟分析模組）
- 再次點擊「追蹤成長」
- 查看「成長追蹤」Tab 中的變化

#### 3. 生成引用圖
- 切換到「引用圖」Tab
- 從下拉選單選擇物件類型（或手動輸入）
- 調整深度參數（建議 3-5）
- 點擊「生成引用圖」
- 圖表將顯示在視窗中

#### 4. 垃圾回收
- 點擊「強制垃圾回收」按鈕
- 對話框會顯示回收的物件數量
- 日誌 Tab 記錄詳細資訊

#### 5. 自動監控
- 勾選「自動刷新」選項
- 設定刷新間隔（建議 5-10 秒）
- 系統將自動執行定期掃描

#### 6. 導出報告
- 點擊「導出報告」按鈕
- 選擇保存位置
- 報告包含完整統計和日誌

## 注意事項

### 性能影響
- 掃描操作會暫時增加 CPU 使用率
- 建議在非關鍵分析時段使用
- 引用圖生成可能耗時較長（深度越大越慢）

### 圖表生成限制
- 需要安裝 Graphviz（objgraph 依賴）
- Windows: 需將 Graphviz 加入 PATH
- 如果生成失敗，檢查 Graphviz 安裝狀態

### 自動刷新建議
- 不要設定過短的刷新間隔（< 3 秒）
- 在執行重度分析時建議停用自動刷新
