## 修改原因

### 用戶需求 🎯
> "到300的時間看來是有點辛苦，我們能設定250km/h嗎？這樣比較有統一性"

### 技術考量 ✅

1. **統一標準** - 所有 F1 賽道都能達到 250 km/h
   - ✅ 街道賽（Monaco, Singapore）: 最高速 ~290 km/h
   - ✅ 混合賽道（Suzuka, Barcelona）: 最高速 ~310 km/h
   - ✅ 高速賽道（Monza, Spa）: 最高速 ~350 km/h

2. **比較性更強** - 不同賽道間的數據可以直接比較
   - ❌ 舊標準：部分賽道達不到 300 km/h，無法計算
   - ✅ 新標準：所有賽道都有 100→250 km/h 數據

3. **黃金加速區間** - 100→250 km/h 代表車輛的核心加速性能
   - 涵蓋大部分彎道出口到直線中段的加速場景
   - 反映車輛的實際競爭力

## 計算公式

### 加速度計算

```python
# 速度轉換
v1 = 100 km/h = 27.78 m/s
v2 = 250 km/h = 69.44 m/s

# 速度變化
Δv = v2 - v1 = 69.44 - 27.78 = 41.67 m/s

# 平均加速度
a_avg = Δv / Δt

# 範例（PIA）
a_avg = 41.67 / 2.88 = 14.47 m/s²
```

### 理論對比

| 加速度 | 性能評價 | 對比 |
|-------|---------|------|
| > 12 m/s² | 優秀 | PIA: 14.47 m/s² |
| 9-12 m/s² | 良好 | HAM: 9.30 m/s², LEC: 10.01 m/s² |
| 7-9 m/s² | 中等 | NOR: 7.44 m/s², VER: 8.40 m/s² |
| < 7 m/s² | 較弱 | - |

**參考值**：
- 一般跑車 0-100 km/h: ~3.0-4.0s (約 6-8 m/s²)
- F1 賽車 100-250 km/h: ~2.9-5.6s (約 7-14 m/s²)
