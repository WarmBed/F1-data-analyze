## 🎯 測試方法論

### 改進的彎道識別算法

#### 技術細節
```python
# 核心方法: 速度局部極小值檢測
from scipy.signal import find_peaks

# 找到速度極小值點（彎心）
peaks, properties = find_peaks(
    -speeds,  # 反轉速度使用 find_peaks
    distance=30,  # 最小間隔 30 數據點（約 200m）
    prominence=15  # 速度下降至少 15 km/h
)
```

#### 算法改進點
1. **使用 scipy.signal.find_peaks**: 比簡單差分更精確地找到速度極小值
2. **彎道長度限制**: 過濾異常長的彎道（> 500m）
3. **智能邊界檢測**: 向前後搜索速度高於彎心 30% 的點作為彎道邊界
4. **跨年匹配算法**: 使用 50m 容差匹配不同年份的彎道
