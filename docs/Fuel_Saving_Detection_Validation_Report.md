## 💡 推荐方案

### 方案 A: 动态滚动基线 ✅ **强烈推荐**

**核心思想**: 不用固定的前N圈，而是用**滚动窗口**

```python
# 使用最近 10 圈的中位数作为动态基线
baseline = median(last_10_laps_throttle)

# 示例：
Lap 15: baseline = median(Lap 6-15) = 52.0%
Lap 20: baseline = median(Lap 11-20) = 53.5%
Lap 30: baseline = median(Lap 21-30) = 55.0%
```

**优点**:
✅ 自动适应燃油消耗和轮胎磨损
✅ 不受开场圈波动影响
✅ 实时跟踪驾驶基线变化

**缺点**:
⚠️ 前10圈无法使用（数据不足）
⚠️ 如果车手连续省油10圈，基线会被拉低（需要额外逻辑）

---

### 方案 B: 分段基线 🟡 **备选方案**

**核心思想**: 将比赛分为多个阶段，每个阶段独立基线

```python
阶段 1 (Lap 1-15):   基线 = median(Lap 3-8)   # 开场阶段
阶段 2 (Lap 16-35):  基线 = median(Lap 16-21) # 中段
阶段 3 (Lap 36-58):  基线 = median(Lap 36-41) # 后段
```

**优点**:
✅ 适应不同阶段的驾驶特性
✅ 避免单一基线的偏差

**缺点**:
⚠️ 需要手动定义阶段
⚠️ 阶段边界可能不准确

---

### 方案 C: 机器学习 (XGBoost) ⚪ **不推荐（目前）**

**为什么不推荐**:
1. **缺乏标注数据** - 我们不知道哪些圈"真的在省油"（除了进站圈）
2. **特征有限** - 目前只有油门数据，缺少其他关键特征
3. **过度复杂** - 简单方法已经能检测出进站圈等明显省油
4. **实时性问题** - 模型推理可能影响性能

**如果要用机器学习，需要**:
- 标注数据（车队指令、车手自述、赛后访谈）
- 更多特征（轮胎生命、燃油剩余、引擎模式、DRS使用）
- 大量历史数据（多场比赛、多个赛道）

## 🎯 最终推荐实现

### 推荐: **动态滚动基线 + Sector 检测**

```python
class AdaptiveFuelSavingDetector:
    """自适应省油检测器"""
    
    def __init__(self):
        self.window_size = 10  # 滚动窗口大小
        self.threshold_high = -5.0
        self.threshold_medium = -3.0
    
    def get_dynamic_baseline(self, driver_code: str, sector: str):
        """获取动态基线（最近10圈的中位数）"""
        history = self.get_sector_history(driver_code, sector, last_n=10)
        
        if len(history) < 3:
            return None  # 数据不足
        
        # 排除异常值（进站圈等）
        filtered = [x for x in history if x > baseline * 0.7]
        
        return median(filtered) if filtered else median(history)
    
    def detect(self, driver_code: str, sector: str, current_throttle: float):
        """检测省油"""
        baseline = self.get_dynamic_baseline(driver_code, sector)
        
        if baseline is None:
            return "⚪ 数据不足"
        
        deviation = current_throttle - baseline
        
        if deviation <= self.threshold_high:
            return f"🔴 省油 {abs(deviation):.1f}%"
        elif deviation <= self.threshold_medium:
            return f"🟡 可疑 {abs(deviation):.1f}%"
        else:
            return f"🟢 正常"
```

**关键改进**:
1. ✅ **滚动窗口基线** - 适应燃油/轮胎变化
2. ✅ **异常值过滤** - 自动排除进站圈影响基线
3. ✅ **Sector 级别** - S1/S2/S3 独立检测
4. ✅ **数据不足处理** - 前期显示"数据不足"而非误判
