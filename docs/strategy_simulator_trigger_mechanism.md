# 策略模擬器 - 結果顯示觸發機制說明

## 📊 功能觸發流程

### 1. 基本策略模擬（策略排名）

當用戶點擊「開始模擬」按鈕後：

```
[開始模擬] 
    ↓
生成候選策略
    ↓
執行基本模擬（LapSimulator）
    ↓
更新以下 Tab：
  ✅ 策略排名（Strategy Comparison）
  ✅ 詳細資料（Detailed Data）
  ✅ 單圈曲線（Lap Curves）      ← 在此階段更新
  ✅ 對手分析（Opponent）
```

**單圈曲線**會在基本策略模擬完成後立即更新，顯示每個策略的單圈時間變化。

---

### 2. Monte Carlo 模擬（自動執行）

如果用戶勾選「啟用 Monte Carlo」，則在策略排名完成後自動執行：

```
[策略排名完成]
    ↓
自動啟動 Monte Carlo 模擬
    ↓
執行 1000+ 次隨機模擬（含 SC 事件）
    ↓
更新以下 Tab：
  ✅ 策略排名 - 更新 MC 位置分析表格
  ✅ 動態模擬（Simulation）- MC 圖表
  ✅ SC 場景（Safety Car）        ← 在此階段更新
  ❌ 位置分析（Position Analysis）  ← 已移除
  ✅ 對手分析 - 位置預測
  ✅ 完整賽事 - 接收 MC 結果
```

**SC 場景分析**會在 Monte Carlo 模擬完成後更新，包含：
- 不同 SC 時機的勝率分析
- 進站調整建議
- Bail-out 輪胎建議

---

### 3. 完整賽事模擬（手動觸發）

用戶需要手動切換到「完整賽事」Tab 並點擊「開始模擬」：

```
[完整賽事 Tab]
    ↓
點擊「開始模擬」
    ↓
選擇 SC 場景（None/Early/Mid/Late/Random）
    ↓
執行 20 車完整賽事模擬（100-200 次迭代）
    ↓
更新以下 Tab：
  ✅ 完整賽事（Full Race）
  ✅ SC 場景（Safety Car）        ← 如果 MC 未執行過
```

**注意**：如果 Monte Carlo 已經執行過，完整賽事不會覆蓋 SC 場景分析（因為 MC 的分析更準確）。

## 📝 用戶常見問題

### Q1: 單圈曲線什麼時候更新？
**A**: 在策略排名（基本模擬）完成後立即更新。不需要執行 Monte Carlo。

### Q2: SC 場景什麼時候更新？
**A**: 在 Monte Carlo 模擬完成後更新。需要勾選「啟用 Monte Carlo」選項。

### Q3: 位置分析去哪了？
**A**: 位置分析功能已移除。相關的位置預測資訊現在整合在：
- **策略排名 Tab** - Monte Carlo 位置分析表格（預期位置、位置增益、風險）
- **對手分析 Tab** - 位置預測和超車分析

### Q4: 完整賽事模擬需要先執行策略排名嗎？
**A**: 不需要。完整賽事模擬是獨立的，可以直接執行。但執行前需要：
- 選擇賽道
- 載入 FP2 數據（或使用預設退化率）
- 設定對手策略

### Q5: Monte Carlo 和完整賽事有什麼區別？
**A**: 
- **Monte Carlo**: 快速模擬（1000+ 次），評估策略在不同隨機事件下的表現
- **完整賽事**: 詳細模擬（100-200 次），包含完整的 20 車競爭和 SC 事件

## 🔄 推薦工作流程

### 方案 A：快速分析（5-10 分鐘）
```
1. 選擇賽道 + 載入 FP2
2. 點擊「開始模擬」（策略排名）
3. 勾選「啟用 Monte Carlo」
4. 查看結果：
   - 策略排名：最佳策略
   - 單圈曲線：時間變化
   - SC 場景：不同 SC 時機的建議
   - 動態模擬：MC 圖表
```

### 方案 B：完整分析（15-30 分鐘）
```
1. 執行方案 A
2. 切換到「完整賽事」Tab
3. 選擇 SC 場景（Early/Mid/Late）
4. 點擊「開始模擬」
5. 查看 20 車競爭結果
```

## 📌 技術細節

### Monte Carlo 位置分析表格

位於「策略排名」Tab，包含以下列：

| 列名 | 說明 | 來源 |
|------|------|------|
| 策略 | 策略名稱 | - |
| 停站 | 進站次數 | - |
| 輪胎策略 | 配方序列 | - |
| 勝率 | 勝利機率 | MC |
| 平均時間 | 平均完賽時間 | MC |
| 標準差 | 時間變異 | MC |
| 無 SC | 無 SC 勝場數 | MC |
| 有 SC | 有 SC 勝場數 | MC |
| 位置增益 | 預期進步名次 | MC + 起始位置計算 |
| 風險 | 最好/最差情況 | MC + 起始位置計算 |

**位置增益計算邏輯**（2026-01-07 修正）：
- 考慮起始位置限制（如從 P2 最多 +1 到 P1）
- 基於勝率和策略激進程度計算
- 風險評估包含最好和最差情況
