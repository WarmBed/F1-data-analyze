# V0.16.0 — 公開發布準備版 (Public Release Readiness)

## 重點 (Highlights)

本版本完成公開發布前的完整驗證閘門，所有 GUI 功能均以 2026 Miami 真實賽事資料完成端對端驗證：

- 非即時功能樹（歷史資料）：42/42 模組通過
- 直接 GUI 煙霧測試：10/10 模組通過
- 即時計時 (Live Timing) 回放：28/28 模組通過（含數值/語意證據驗證）
- 合併矩陣：70/70 功能樹葉節點具備 e2e 證據，覆蓋率 100%

## 變更內容 (Changes)

### 驗證與發布閘門
- 新增 `tools/run_gui_coverage_matrix.py` 合併覆蓋率報告（`--scope matrix`）
- 強化 `tools/run_live_timing_data_validation.py` 嚴格數值/語意驗證
- 新增 `docs/RELEASE_CHECKLIST.md` 發布檢查清單（驗證指令、安全掃描、已知注意事項）

### GUI 修正
- 修正本地遙測 GUI 驗證（加速度、煞車、極速、直線速度等資料載入器改用本地資料）
- 修正排位預測、FP2 排位預測、比賽預測模組的本地模式載入
- 修正踏板行為分析、車手位置分析模組
- `windows/managers/analysis_module_creator.py` 強化模組建立流程

### 安全
- 移除硬編碼 API 金鑰（歷史版本已清理並輪換）
- 預設執行模式為 local-first，無需啟動 API 伺服器
- 新增 `setup_venv_build.ps1` 建構環境設置腳本（使用相對路徑）
