# F1 TelemetryStation Pro - V0.3.0 Release Notes

**Release Date**: October 9, 2025  
**Version**: V0.3.0  
**Branch**: f54功能開發 / Feature Development

---

## ✨ Major Updates

### 🆕 Ideal Lap Ranking Analysis
- ✅ **New Feature**: Comprehensive ideal lap ranking table showing all drivers' theoretical best lap times
- 📊 **Rich Statistics**: Displays driver rankings, ideal lap times, actual fastest laps, and gaps to session best
- 🎨 **Team Color Coding**: Driver names highlighted with team background colors for easy identification
- 📈 **Summary Panel**: Shows session fastest lap, fastest ideal lap, ideal lap range, and perfect lap achievement rate
- 🌐 **API Integration**: Full support for real-time data fetching from F1T API
- 🔧 **Driver Name Enhancement**: Updated driver names to use black text for better readability
- 🗑️ **UI Simplification**: Removed Export CSV button to streamline interface

### 🌳 Interactive Lap Analysis Tree View
- ✅ **Tree Structure**: Hierarchical display of lap data organized by driver
- 🔍 **Smart Filtering**: Built-in filters for pit laps, safety car periods, and outliers
- 📊 **Statistical Summaries**: Per-driver lap count, median time, and lap range statistics
- 🎯 **Click-to-Analyze**: Double-click any lap to view detailed telemetry analysis
- 🎨 **Visual Indicators**: Color-coded lap times showing fastest/slowest laps at a glance
- 📱 **Responsive Design**: Auto-resizing columns with optimal width distribution

### 🎨 Box Plot Typography Standardization
- ✅ **Unified Font Sizing**: All text elements now use consistent 8pt font size
- 📊 **Throttle Box Plot**: Standardized axis labels, tick marks, driver names, and tooltips
- 📊 **Lap Time Box Plot**: Standardized axis titles, tick labels, and driver labels
- 🔤 **Font API**: Changed from `QFont("Arial", size)` to `QFont()` + `setPointSize(8)` for better cross-platform compatibility

### 🎨 Ideal Lap Analysis UI Refinements (October 10, 2025)
- ✅ **Sector Marks Color Separation**: Implemented custom delegate for mixed-color sector marks (green ✓, black ✗)
- 🎨 **Unified Color Standards**: Gap to Session Fastest now uses standardized gap color thresholds (0.2s, 0.5s breakpoints)
- 🔄 **Sortable Cumulative Delta**: Sector Comparison table now supports click-to-sort on cumulative delta column

---

## 🔧 Technical Improvements

### Ideal Lap Ranking Module
- Implemented `IdealLapRankingTableMDI` with UniversalAnalysisMDI base architecture
- Created `IdealLapRankingTableDataLoader` for API-first data loading
- Built `IdealLapRankingTableWidget` with custom table rendering and team colors
- Added comprehensive i18n support with English/Chinese translations
- Integrated with CLI Function 53 for backend analysis

### Lap Analysis Tree
- Developed `LapAnalysisTreeWidget` with QTreeWidget foundation
- Implemented intelligent lap filtering algorithms
- Created statistical calculation engine for lap data aggregation
- Added context menu for lap selection and analysis triggering
- Built signal-based communication for module integration

### Font Standardization
- Modified 7 font instances across 2 major box plot components
- Removed hardcoded font family names for better system integration
- Unified all chart text elements to 8pt size for consistency
- Updated tooltip rendering to match standardized font settings

# F1 TelemetryStation Pro - V0.3.0 更新日誌

**發布日期**：2025年10月9日  
**版本號**：V0.3.0  
**分支**：f54功能開發

---

## ✨ 重大更新

### 🆕 理想圈排名分析
- ✅ **全新功能**：完整的理想圈排名表格，顯示所有車手的理論最佳圈速
- 📊 **豐富統計**：顯示車手排名、理想圈時間、實際最速圈及與全場最速的差距
- 🎨 **車隊配色**：車手名稱以車隊背景色標示，便於快速識別
- 📈 **統計面板**：顯示全場最速實際圈、最快理想圈、理想圈範圍與完美單圈達成率
- 🌐 **API 整合**：完整支援從 F1T API 即時獲取數據
- 🔧 **車手名稱優化**：車手名稱改用黑色文字，提升可讀性
- 🗑️ **介面簡化**：移除匯出 CSV 按鈕，精簡使用者介面

### 🌳 互動式圈速樹狀圖
- ✅ **樹狀結構**：以車手為單位的階層式圈速數據顯示
- 🔍 **智慧篩選**：內建進站圈、安全車圈與異常值過濾功能
- 📊 **統計摘要**：每位車手的圈數統計、中位圈速與圈速範圍
- 🎯 **點擊分析**：雙擊任一圈速即可查看詳細遙測分析
- 🎨 **視覺指標**：圈速以顏色標示，一眼看出最快/最慢圈
- 📱 **響應式設計**：自動調整欄位寬度，最佳化顯示效果

### 🎨 箱型圖字體標準化
- ✅ **統一字體大小**：所有文字元素統一使用 8pt 字體
- 📊 **油門箱型圖**：標準化座標標籤、刻度數值、車手名稱與提示文字
- 📊 **圈速箱型圖**：標準化座標標題、刻度標籤與車手標籤
- 🔤 **字體 API**：從 `QFont("Arial", size)` 改為 `QFont()` + `setPointSize(8)`，提升跨平台相容性

## 🔧 技術改進

### 理想圈排名模組
- 實作 `IdealLapRankingTableMDI`，採用 UniversalAnalysisMDI 基礎架構
- 建立 `IdealLapRankingTableDataLoader`，實現 API 優先數據載入
- 開發 `IdealLapRankingTableWidget`，自訂表格渲染與車隊配色
- 新增完整 i18n 多國語言支援（英文/中文）
- 整合 CLI Function 53 後端分析功能

### 圈速樹狀圖
- 開發 `LapAnalysisTreeWidget`，基於 QTreeWidget 建構
- 實作智慧圈速過濾演算法
- 建立圈速數據統計計算引擎
- 新增右鍵選單，支援圈速選取與分析觸發
- 建置訊號機制，實現模組間通訊整合

### 字體標準化
- 修改 2 個主要箱型圖元件共 7 處字體設定
- 移除硬編碼字體名稱，提升系統整合性
- 統一所有圖表文字元素為 8pt 大小，確保一致性
- 更新提示文字渲染，符合標準化字體設定

### 理想圈分析 UI 優化 (2025年10月10日)
- 實作自訂 Delegate，實現分段標記混合顏色顯示（綠色 ✓、黑色 ✗）
- 統一 Gap to Session Fastest 顏色標準，採用統一色階門檻（0.2秒、0.5秒分界）
- Sector Comparison 表格支援點擊累積差異欄位進行遞增/遞減排序
