# 
## 1. 車手比賽排名 (Driver Race Position)

**功能 ID**: F25

顯示車手在比賽中的排名變化，包含起始排名、結束排名、最佳/最差排名及位置變化。


## 2. 排位賽預測 (Qualifying Prediction)

**功能 ID**: F74

基於機器學習模型（XGBoost v3.10），使用 FP3 練習賽數據預測排位賽成績。

---

## 3. 車輛零件變動 (Vehicle Parts Changes)

**功能 ID**: F29  
**原名**：FIA Parts Analysis → **新名**：車輛零件變動

解析 FIA 官方技術文件，追蹤所有車隊的零件變更記錄。
