### 1. Ideal Lap Analysis - 分段時間顯示 ✅

**功能描述**: 為理想圈速分析系統添加 S1/S2/S3 分段時間的完整顯示支援

  - 實現: `_transform_data_for_display()` 方法
  - 數據結構: `DataFrame(columns=driver_order, index=["S1", "S2", "S3"])`

- ✅ **Sector Comparison 區塊整合**
  - 方法: `_normalize_sector_comparison()`
  - 功能: 將 CLI JSON 的 `sector_comparison` 轉換為 S1/S2/S3 結構化數據

**關鍵代碼位置**:

##### 1.2 **Ideal Lap Sector Comparison** (分段比較)
**檔案**: `modules/gui/ideal_lap_analysis/ideal_lap_sector_comparison/`

- ✅ **分段時間比較圖表**
  - 數據載入器: `ideal_lap_sector_comparison_data_loader.py`
  - 支援格式: `ideal_sectors: [s1, s2, s3]`, `fastest_sectors: [s1, s2, s3]`

##### 1.3 **Ideal Lap Ranking Table** (排名表)
**檔案**: `modules/gui/ideal_lap_analysis/ideal_lap_ranking_table/`

- ✅ **排名表中的 S1/S2/S3 欄位**
  - Chart Widget: `ideal_lap_ranking_chart_widget.py`
  - 顯示: 每位車手的三個分段時間

#### 技術細節

**數據流向**:
```
CLI JSON (sector_comparison)
  ↓
_normalize_sector_comparison()
  ↓
{"S1": {...}, "S2": {...}, "S3": {...}}
  ↓
DataFrame 轉換
  ↓
熱力圖/比較圖/排名表顯示
```

**支援的分段模式**:
- `mode="S1"` - 僅顯示第一分段
- `mode="S2"` - 僅顯示第二分段
- `mode="S3"` - 僅顯示第三分段
- `mode="all"` - 顯示完整圈速（預設）

```python
self.use_time_axis = False  # 預設使用距離軸

# 切換方法
def set_time_axis_mode(self, use_time: bool):
    """切換時間/距離軸"""
    if self.use_time_axis == use_time:
        return
    self.use_time_axis = use_time
    self.redraw()

# X 軸數據選擇
x_data_source = self.driver1_time if self.use_time_axis else self.speed_data
```

### 3. Time Diff Analysis 模組 ✅

**功能描述**: 新增專門的時間差分析模組，用於比較兩位車手在圈速過程中的時間差異

#### 模組結構

**路徑**: `modules/gui/lap_analysis/timediff_analysis/`

| 檔案 | 功能 | 行數 |
|------|------|------|
| `timediff_analysis_mdi.py` | MDI 視窗管理 | ~500 |
| `timediff_analysis_data_loader.py` | 數據載入與處理 | ~400 |
| `timediff_analysis_chart_widget.py` | 圖表繪製 | ~600 |
| `__init__.py` | 模組初始化 | ~20 |

#### 核心功能

##### 3.1 **時間差計算**
- 計算兩位車手在每個賽道點的時間差
- 顯示領先/落後狀態
- 支援距離軸和時間軸模式

##### 3.2 **視覺化呈現**
- 折線圖顯示時間差變化
- 顏色編碼（綠色=領先，紅色=落後）
- 零線參考（0秒差異）

##### 3.3 **數據處理**
**Data Loader 實現**:
```python

            "distance": [...],
```

**主選單**:
- 路徑: `f1t_gui_main.py` → Lap Analysis → Time Diff Analysis
