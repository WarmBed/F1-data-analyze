## 🖱️ 互動功能詳情

### 功能矩陣

| 功能 | 操作方式 | 視覺反饋 | 用途 |
|------|----------|----------|------|
| **圖例拖移** | 滑鼠拖放 | 🖐️ 游標變化 | 調整圖例位置 |
| **圖例切換** | 雙擊圖例 | 高度動態調整 | 顯示/隱藏標記 |
| **懸停 Tooltip** | 滑鼠懸停 | 🔴 紅圈 + 淺黃色 | 即時查看圈速 |
| **固定 Tooltip** | 左鍵點擊 | 🔵 藍圈 + 淺藍色 | 固定比較點 |
| **時間差顯示** | 固定 2 點 | 藍色粗體文字 | 計算時間差 |
| **清除固定** | 右鍵點擊 | 固定點消失 | 重新開始比較 |

---

### 功能 1: 圖例拖移

**使用場景**: 圖例遮擋重要數據時

**操作流程**:
1. 滑鼠移到圖例上 → 游標變為 🖐️ 張開的手
2. 按住左鍵拖移 → 游標變為 ✊ 握緊的手
3. 釋放滑鼠 → 圖例固定在新位置

**特性**:
- ✅ 邊界限制（不會完全移出視窗）
- ✅ 流暢的拖移體驗
- ✅ 位置記憶（不會重置）

---

### 功能 2: 圖例顯示切換

**使用場景**: 需要更多圖表空間時

**操作流程**:
1. 雙擊圖例區域
2. 圖例在完整模式 ↔ 簡潔模式間切換

**模式對比**:

| 模式 | 顯示內容 | 高度 | 適用場景 |
|------|----------|------|----------|
| 完整 | 車手 + 5 個標記 | 100% | 需要查看標記說明 |
| 簡潔 | 僅車手列表 | 40% | 最大化圖表空間 |

---

### 功能 3: 懸停 Tooltip

**使用場景**: 快速查看圈速資訊

**操作流程**:
1. 將滑鼠移到數據點附近（20px 範圍內）
2. 自動顯示淺黃色 Tooltip
3. 滑鼠移開後消失

**顯示內容**:
```
HAM - Lap 15
Lap Time: 1:38.456
```

**特性**:
- ✅ 立即顯示（無延遲）
- ✅ 智能位置調整（避開邊界）
- ✅ 紅色圓圈高亮

---

### 功能 4: 固定 Tooltip

**使用場景**: 比較兩圈圈速差異

**操作流程**:
1. 將滑鼠移到第 1 個數據點
2. 左鍵點擊 → 固定淺藍色 Tooltip
3. 移到第 2 個數據點
4. 左鍵點擊 → 固定第 2 個 Tooltip

**限制**:
- 最多固定 **2 個**點
- 超過 2 個時自動移除最舊的

**視覺效果**:
- 🔵 藍色圓圈（與懸停的紅色區分）
- 淺藍色 Tooltip 背景
- 固定位置（不隨滑鼠移動）

---

### 功能 5: 時間差計算

**使用場景**: 精確計算兩圈時間差

**觸發條件**:
- 固定 **2 個**數據點

**顯示位置**:
- Clear 按鈕旁邊
- 藍色粗體文字

**顯示格式**:
```
時間差 < 1 分鐘: Diff: +3.456s
時間差 ≥ 1 分鐘: Diff: +1:23.456
```

**實際應用**:
- 進站前後圈速差異: `Diff: +14.333s` (進站圈)
- 輪胎衰退分析: `Diff: +3.444s` (15 圈衰退)
- 黃旗影響: `Diff: +8.123s` (黃旗減速)

---

### 功能 6: 清除固定

**使用場景**: 重新選擇比較點

**操作流程**:
1. 在圖表任意位置右鍵點擊
2. 所有固定 Tooltip 清除
3. 時間差顯示清空

**特性**:
- ✅ 一鍵清除所有固定點
- ✅ 懸停 Tooltip 仍正常運作
- ✅ 快速重新開始比較

## ⚙️ 行為變更詳情

### 遙測分析手動更新模式

**變更理由**:
1. 避免頻繁自動更新造成資源浪費
2. 給予用戶更多控制權
3. 減少非預期的數據刷新

**使用流程**:

**改進前**（自動模式）:
```
用戶改變參數 → 500ms 延遲 → 自動更新所有模組
```

**改進後**（手動模式）:
```
用戶改變參數 → 控制台提示 → 用戶點擊 "🔄 Update All Analysis" → 更新
```

**優勢**:
- ✅ 用戶可一次性調整多個參數
- ✅ 避免中間狀態的無效更新
- ✅ 減少 API 請求次數
