# 🔧 Changelog: From Auto-Update to Manual Update Mode

**Date**: 2025-10-07  
**Change Type**: Functional Behavior Change  
**Affected Scope**: Telemetry Analysis Parameter Update Mechanism

---

## 📋 Change Summary

Changed Lap Analysis parameter updates from **automatic trigger** to **manual update mode**.

### ❌ Old Behavior (Removed)

When user changed driver, lap, or checked fastest lap:
- ✅ Immediately triggered signal
- ✅ 500ms debounce delay
- ✅ Automatically updated all modules

### ✅ New Behavior (Current)

When user changed driver, lap, or checked fastest lap:
- 📝 Only logs parameter change (debug output)
- 💡 Prompts user to click update button
- ❌ **Does NOT** automatically trigger update

User must **manually click** the `🔄 Update All Analysis` button to update all modules.

## 🎯 Design Rationale

### Label Simplification
- In single-driver mode, driver code is redundant information
- Chart title already displays driver name
- Simplified labels make legend clearer

### Tooltip Simplification
- Remove redundant driver name and lap numbers
- More compact tooltip, reduced vertical height
- Clear focus, emphasize the value itself
- Avoid information duplication (chart title already shows)

## 🌐 Race Calendar Dropdown Internationalization Update

**Update Date**: 2025-01-XX

### Problem Description
When user switched interface language, the upcoming race suffix in the race calendar dropdown still displayed Chinese "[未開賽]".

### Solution
Added `season_calendar_upcoming_suffix` translation key in `core/gui_i18n.py`.

### Display Effect

**Chinese Interface**:
```

Mexico (2025-11-02) [未開賽]
Brazil (2025-11-09) [未開賽]
```

**English Interface**:
```
United States (2025-10-26) [Upcoming]
Mexico (2025-11-02) [Upcoming]
Brazil (2025-11-09) [Upcoming]
```

**Japanese Interface**:
```
United States (2025-10-26) [未開催]
Mexico (2025-11-02) [未開催]
Brazil (2025-11-09) [未開催]
```

### Translation Key Definition
```python

    'zh': '[未開賽]',
    'en': '[Upcoming]',
    'ja': '[未開催]'

```

- Any location using `_format_race_display()` method

### Stage 4: Y-Axis Spacing Optimization and Interactive Tooltip Features

**Update Date**: 2025-10-07

#### Problem Fixes
1. ✅ Y-axis too close to window boundary
2. ✅ Y-axis values overlapping with boundary
3. ✅ Added data point hover tooltip feature
4. ✅ Added pinned tooltip feature (left-click)
5. ✅ Added time difference calculation and display
6. ✅ Added clear pinned feature (right-click)

#### Y-Axis Spacing Optimization
- Left margin increased: from `margin` to `max(95px, window width 12%)`
- Y-axis title position adjusted: ensure it's outside value labels
- Improved visual readability, avoid value truncation or overlap

#### Interactive Tooltip Features

**1. Hover Tooltip (Light Yellow)**

**Display Content**:
```
HAM - Lap 15
Lap Time: 1:23.456
```

**Trigger Method**:
- Mouse hover near data point (within 20px range)
- Immediately display light yellow tooltip
- Red circle highlights current hover point
- Smart position adjustment (avoid window boundaries)

**2. Pinned Tooltip (Light Blue)**

**Operation**:
- **Left-click** data point to pin tooltip
- Maximum **2** pinned points
- Automatically removes oldest when exceeding 2

**Visual Effects**:
- Pinned point shows blue circle
- Tooltip changes to light blue background
- Fixed position, doesn't follow mouse

**3. Time Difference Calculation and Display**

**Trigger Condition**:
- Automatically calculates time difference when 2 points are pinned

**Display Location**:
- Next to Clear button
- Blue bold text

**Display Format**:
```
Diff: +3.456s       (time diff < 1 minute)
Diff: +1:23.456     (time diff ≥ 1 minute)
```

**4. Clear Pinned Tooltips**

**Operation**:
- **Right-click** anywhere on chart
- Clears all pinned tooltips
- Also clears time difference display

**Use Cases**:
- Compare lap time difference (before/after pit stop)
- Analyze tire degradation (same tire set first lap vs last lap)
- Check fastest lap vs average lap difference
- Assess yellow flag/safety car impact on lap times

**Technical Implementation**:
```python
# Enable mouse tracking
self.setMouseTracking(True)

# Pinned tooltip management
self.pinned_tooltips = []  # Maximum 2
self.max_pinned = 2

# Signal-slot mechanism
pinned_tooltips_changed.emit(count, diff_text)
```

**Color Design**:
| Type | Background Color | Highlight Circle | Purpose |
|------|------------------|------------------|---------|
| Hover | Light Yellow | 🔴 Red | Real-time view |
| Pinned | Light Blue | 🔵 Blue | Comparison analysis |
