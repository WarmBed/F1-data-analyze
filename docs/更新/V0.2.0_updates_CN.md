# F1 TelemetryStation Pro - V0.2.0 Release Notes

**Release Date**: October 8, 2025  
**Version**: V0.2.0  
**Branch**: f54功能開發 / Feature Development

---

## 🎉 Major New Features

### 🚀 Throttle Analysis Module

#### 1. **Throttle Line Chart**
- ✨ **New**: Complete throttle line chart analysis functionality
- 🎯 **Dual Driver Comparison**: Support simultaneous display of two drivers' throttle data comparison
- 📊 **Visualization Enhancements**:
  - Per-lap throttle usage percentage line chart
  - Draggable legend support
  - Pinnable and draggable tooltip feature
  - Separated dual-driver data display (Driver 1 / Driver 2)
- ⚙️ **System Settings Integration**: Throttle analysis settings integrated into system settings dialog
- 🔧 **Driver 2 Optimization**:
  - Driver 2 defaults to "None" (no automatic second driver loading)
  - Changing Driver 1 preserves Driver 2 data (chart not cleared)

#### 2. **Throttle Box Plot**
- ✨ **New**: Throttle usage distribution box plot
- 📈 **Percentage Mode**: Toggle between actual percentage or lap percentage display
- 🎨 **Visual Enhancements**:
  - Min/Max value tooltip display
  - Multi-driver comparison support
  - Team color configuration

---

## 🐛 Bug Fixes

### Fixed Tooltip Data Confusion Issue
- **Problem**: In dual-driver mode, tooltip displayed incorrect driver data
  - Example: Hovering over HAM's data point showed LEC's percentage
- **Fix**:
  - Separated tooltip maps for each driver (`_tooltip_map_driver1` and `_tooltip_map_driver2`)
  - `get_tooltip_payload()` selects correct tooltip data based on `series_name`
  - Affected files: `throttle_duration_chart_widget.py`, `lap_time_chart_widget.py`, `universal_chart_widget.py`

### Fixed Lap Analysis Dialog Auto-Add Parameters Issue
- **Problem**: When selecting Driver 1 + Lap 60, system automatically added Driver 2 = "VER", Lap 2 = 1
- **Fix**:
  - Removed `driver2 if driver2 else "VER"` default value logic
  - Removed `lap2_number if lap2_number else 1` default value logic
  - Allow `driver2` and `lap2` to be `None`
  - Affected modules: Speed, Brake, Throttle, Gear, RPM, Acceleration, Speed Diff, Distance Diff Analysis (16 lines batch fix)

### Tooltip Drag Feature
- ✨ **New**: Support dragging pinned tooltip boxes to any position
- 🔗 **Connection Line**: Maintains dashed line connection to original data point when dragging
- 🎯 **Scope**:
  - Throttle Line Chart
  - Detailed Lap Analysis
  - All charts inheriting `UniversalChartWidget`
