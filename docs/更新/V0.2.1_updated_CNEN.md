# F1 TelemetryStation Pro - V0.2.1 Release Notes

**Release Date**: October 9, 2025  
**Version**: V0.2.1  
**Branch**: f54功能開發 / Feature Development

---

## ✨ Highlighted Updates

### 🎨 Colour Palette System Overhaul
- ✅ **API-First Palette Loading**: `ColorPaletteProvider` now surfaces a strict API-only mode via the `F1T_COLOR_PALETTE_ALLOW_FALLBACK` environment variable. When disabled, the GUI stops falling back to built-in colours and surfaces clear error messaging.
- 🆕 **2025 Season Defaults**: Refreshed internal palettes for teams and drivers (Hamilton → Ferrari, Antonelli debut, rookie grid updates) ensuring consistent visuals when the API is temporarily unavailable.
- 🔁 **Metadata Propagation**: GUI chart widgets automatically pass season metadata so palette refresh follows the loaded session.
- 🧪 **New Tests**: Added coverage guaranteeing the default palette is used only when enabled and that API failures surface correctly.

### 📊 Box Plot Visual Refinements
- Median bars and outlier markers for both Lap Time and Throttle box plots now render in black, improving contrast against team colours and exporting better for reports.

### 🪟 UX Polish
- Main window title upgraded to `F1 TelemetryStation Pro V0.2.1` for instant version recognition.
- PyInstaller helper script metadata bumped to V0.2.1 to match the GUI release.

---

## 🔧 Technical Improvements
- Hardened `ColorPaletteProvider.ensure_loaded()` with explicit exception handling when defaults are disallowed.
- Added runtime toggles (`set_allow_default_palette`) so diagnostics tools can switch fallback behaviour without recreating the provider.
- Log output now clarifies API resolution flow and failure reasons to simplify support investigations.

---

## 🧪 Validation Checklist
1. **Palette API Health**: Launch GUI with API online, verify colours align with current season data.
2. **API-Only Mode**: Set `F1T_COLOR_PALETTE_ALLOW_FALLBACK=0`, confirm GUI reports palette failure when the API is unreachable.
3. **Box Plot Styling**: Open Lap Time and Throttle box plots, ensure median/outlier styling is black.
4. **Packaging**: Run `Build_F1T_GUI.bat` to confirm V0.2.1 labels propagate through the EXE build pipeline.

# F1 TelemetryStation Pro - V0.2.1 更新日誌

**發布日期**：2025年10月9日  
**版本號**：V0.2.1  
**分支**：f54功能開發

---

## ✨ 亮點更新

### 🎨 顏色系統全面升級
- ✅ **API 優先載入**：透過環境變數 `F1T_COLOR_PALETTE_ALLOW_FALLBACK` 可強制啟用純 API 模式；停用後若 API 失敗將直接提示錯誤，不再回退內建色票。
- 🆕 **2025 賽季預設**：同步更新隊伍與車手顏色（Hamilton 加入 Ferrari、Antonelli 等新秀），即使 API 暫時離線仍能維持正確配色。
- 🔁 **元資料同步**：圖表元件會依據載入的賽季自動刷新顏色設定，避免年度錯配。
- 🧪 **測試覆蓋**：新增單元測試，確保預設色票僅在允許時啟用，同時驗證 API 失敗時的錯誤處理。

### 📊 箱型圖視覺調整
- 圈速與油門箱型圖的中位數線與異常值改為黑色，更容易辨識且輸出報表時對比更佳。

### 🪟 使用者體驗
- 主視窗標題更新為 `F1 TelemetryStation Pro V0.2.1`，版本資訊一目了然。
- PyInstaller 打包腳本同步更新版本資訊到 V0.2.1。

---

## 🔧 技術細節
- 強化 `ColorPaletteProvider.ensure_loaded()`，在禁止後備色票時會直接拋出例外並提供明確訊息。
- 新增執行期間切換預設色票開關 (`set_allow_default_palette`)，方便診斷或手動測試時使用。
- 日誌輸出增加 API 解析流程與錯誤原因，利於支援團隊排查。

3. **箱型圖樣式**：開啟圈速與油門箱型圖，確認中位線與異常值皆為黑色。
4. **打包驗證**：執行 `Build_F1T_GUI.bat`，確認輸出流程標示版本為 V0.2.1。
