### [v] Corner Analysis Module - Dynamic Speed Distribution | 彎道分析模組 - 動態速度分布
- Implements dynamic corner classification system:
  - 實現動態彎道分類系統：
  - **Low-speed corners**: Slow technical sections
    - **低速彎道**：慢速技術路段
  - **Medium-speed corners**: Balanced braking/acceleration zones
    - **中速彎道**：平衡的煞車/加速區域
  - **High-speed corners**: Fast flowing sections
    - **高速彎道**：快速流暢路段
- Generates speed distribution analysis for three critical phases:
  - 針對三個關鍵階段生成速度分布分析：
  - **Entry speed**: Braking and turn-in performance
    - **進彎速度**：煞車與轉向入彎表現
  - **Apex speed**: Mid-corner handling characteristics
    - **彎心速度**：彎道中段操控特性
  - **Exit speed**: Acceleration and traction capabilities
    - **出彎速度**：加速與抓地力能力
- Visualizes data using distribution plots for comparative analysis across corner types
  - 使用分布圖視覺化數據，進行跨彎道類型的比較分析
