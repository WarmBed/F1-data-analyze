[English](README.md) | **繁體中文** | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

## 這是什麼？

PitWall 是一款 **F1 數據分析**與遙測視覺化工具。
無論是賽事工程師、模擬賽車玩家或數據愛好者，都能透過真實的一級方程式遙測資料，分析單圈時間、油門使用、速度曲線以及車手之間的比較。



這是一套專業的一級方程式遙測分析工作站，提供完整的賽事數據分析功能。

![PITWALL](/images/page01.png)

## 快速開始

### 系統需求

- Windows 10/11
- Python 3.10 以上（建議 3.13）

### 安裝

```powershell
git clone https://github.com/WarmBed/F1-data-analyze.git
cd F1-data-analyze
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 啟動 GUI

```powershell
python f1t_gui_main.py
```

首次使用時，請在工具列選擇年份／大獎賽／場次，並從左側功能樹開啟分析模組。遙測資料會從公開的 F1 來源（FastF1 / OpenF1）下載並快取於本機，因此第一次載入某個場次需要幾分鐘的時間。

### 建置獨立 EXE（選用）

```powershell
.\build_tools\setup_venv_build.ps1     # one-time: create the build virtualenv
python build_tools\build_exe_gui.py    # build with PyInstaller
```

或直接雙擊 `build_tools\一鍵建構EXE.bat`。執行檔會輸出至 `dist\`。

## 1. 歷史數據分析

此分類包含深入的賽後分析工具，涵蓋策略、輪胎、事故，以及賽道與環境背景資訊。

![PITWALL](/images/page02.png)

### 1.1 溫度分析
此模組將整個比賽週末的環境數據視覺化。除了賽道溫度（Track Temp）與氣溫（Air Temp）之外，也整合了濕度、氣壓與降雨的即時資料流。透過將所有資料對齊在同一條時間軸上，您可以精確分析環境變因如何影響特定圈的單圈表現或輪胎衰退趨勢。

支援動態切換年份與賽事，並提供自動縮放的時間軸圖表。

### 1.2 賽道分析
此模組繪製高精度的賽道地圖，並標示所有官方彎角編號以及 DRS 偵測區與啟用區。它利用 API 提供的向量資料繪製賽道幾何，並支援疊加車手行車軌跡或遙測圖層（例如速度熱力圖）。
內建座標轉換邏輯，可將 GPS 座標映射為螢幕上的 XY 繪圖座標，是分析行車路線與賽道特性的基礎工具。

### 1.3 進站分析
此模組提供詳細的進站數據分析，包含兩種檢視：車隊總覽與詳細紀錄。
它會計算每位車手的進站次數、平均靜止時間，以及總進站損失（進出站＋靜止時間）。模組內建智慧篩選，可區分正常進站與通過維修道處罰（drive-through），並顯示每次進站前後的輪胎配方變化。


### 1.4 事故與旗號分析
此工具聚焦於比賽中斷與賽會控制事件，包括黃旗（Yellow Flag）、紅旗（Red Flag）、虛擬安全車（VSC）與安全車（Safety Car，SC）。它以甘特圖風格的時間軸呈現這些事件，顯示其持續時間與發生圈數。
這對於理解比賽節奏變化、策略決策時機與有效競賽圈數至關重要，並可與特定的退賽（DNF）原因相互對照。

### 1.5 輪胎策略分析
這是分析輪胎使用策略的核心模組。它為每位車手繪製直觀的水平 stint（輪胎使用段落）長條：每段代表一套輪胎，顏色對應配方（紅／黃／白／綠／藍），長度對應該段使用圈數。
模組內部會計算每個 stint 的平均單圈時間與衰退趨勢，並標示該 stint 是以新胎或舊胎起跑。如此即可快速比較各車隊一停與多停策略的差異。

### 1.6 車手名次變化
此模組繪製整場比賽的名次走勢圖（名次 vs 圈數），並對退賽（DNF）做特殊處理，以確保仍在場上的賽車名次計算正確。
互動式圖例可快速篩選車手進行比較——例如聚焦前三名的纏鬥，或中段集團的激烈攻防。資料直接來自官方計時的逐圈名次紀錄。

### 1.7 車流分析
此進階模組量化比賽中遭遇的車流（traffic）狀況。透過計算與前後車的間距，判斷車手處於乾淨氣流（clean air）中，還是受到亂流（dirty air）影響。
結果通常以熱力圖或間距圖呈現，凸顯車手在比賽里程中有多少比例受到阻擋。這對於評估真實節奏與進站窗口選擇至關重要。

## 2. 遙測分析
此分類提供取樣率（Hz）等級的車輛物理數據分析，可精確比較駕駛風格與賽車性能。
![PITWALL](/images/page03.png)

### 2.1 主遙測分析
系統中最強大的遙測工具。支援同步顯示多個通道，包括速度（Speed）、轉速（RPM）、檔位（Gear）、油門（Throttle）、煞車（Brake）與 DRS 狀態。
採用高效能繪圖引擎，支援多車手疊加比較，並具備游標同步功能：在任一圖表中移動游標，所有相關圖表都會同步更新至相同時間點。


### 2.2 單一通道專項分析
這些模組是針對特定訊號最佳化的深入檢視：

* **速度分析**
    * 聚焦於速度曲線細節，提供更精細的 Y 軸刻度與平滑處理，以觀察彎中最低速度與直線尾端極速。

* **煞車分析**
    * 分析煞車輸入力道與持續時間，找出煞車點並辨識循跡煞車（trail braking）技巧。

* **油門分析**
    * 檢視油門開度變化，特別適合研究循跡控制與出彎時的油門調節。

* **檔位與轉速**
    * 兩者常搭配使用，分析換檔點、齒比策略，以及引擎在不同轉速區間的輸出特性。

* **加速度（通用）**
    * 計算縱向與橫向加速度以產生 G-G 圖，有助於評估輪胎抓地力極限與整體過彎表現。

### 2.3 差距（Delta）分析
* 直接計算兩車在相同賽道位置的速度差，呈現誰在彎道或直線更快。
* 對速度差積分以估算空間距離的變化，適合分析追逐過程中差距如何拉開或縮小。
* 提供經典的單圈時間差曲線（相對於參考圈），協助找出時間在哪裡賺到、又在哪裡流失。

## 3. 單圈表現
此分類聚焦於單圈時間的統計特性、穩定性與長距離（long run）表現。
![PITWALL](/images/page04.png)

### 3.1 詳細圈速資料
提供功能豐富的表格，列出所選車手每一圈的詳細資訊。欄位包括圈數、單圈時間、區段時間（S1/S2/S3）、測速點速度（speed trap）、輪胎配方與胎齡。
同時標記異常圈（例如受黃旗影響、進站後的出場圈），並以顏色標示個人最佳（綠色）與全場最佳（紫色），是進行資料完整性檢查的首選工具。

### 3.2 圈速箱型圖
以箱型圖（box-and-whisker plot）視覺化單圈時間分布，顯示中位數、四分位距（IQR）與離群值。
這有助於過濾進站圈或受車流影響的圈數，反映真實的比賽節奏與穩定性。箱體越窄，代表車手越穩定。

### 3.3 油門彎角分析
將油門數據與賽道彎角結合。計算通過特定彎角時的平均油門開度或全油門比例等指標，並以箱型圖或折線圖呈現。
這有助於評估車手信心、抓地力狀況與出彎油門運用——這些都是衡量車手過彎極限的關鍵指標。

### 3.4 踏板行為分析
![PITWALL](/images/page16.png)

此模組以堆疊長條圖呈現每位車手的踏板使用狀態分布。系統將踏板行為分為四種狀態：
* **僅油門（Throttle Only）**：只踩油門踏板，通常出現在直線加速或全油門出彎時。
* **僅煞車（Brake Only）**：只踩煞車踏板，對應入彎前的重煞區。
* **循跡煞車（Trail Braking）**：油門與煞車同時操作。這是一種進階技巧，用於在入彎時維持車身平衡並最大化過彎速度。
* **滑行（Coasting）**：兩個踏板皆未踩下，表示車手正利用慣性滑行，或執行 Lift and Coast 以節省燃油。

### 3.5 長距離分析
專為 FP2 長距離模擬（long run）分析設計。內建 **stint 偵測演算法**，可自動辨識連續且具代表性的計時圈。
核心功能包括**燃油修正**：逐圈扣除燃油重量影響以估算修正後的單圈時間，讓您能單獨觀察純粹的輪胎衰退率。這是正賽進站策略規劃的重要依據。

## 4. 理想圈與區段
此分類重組各區段最佳時間，以探索理論上的性能極限。
![PITWALL](/images/page05.png)

### 4.1 理想圈排名
將每位車手在該場次的最佳 S1、S2、S3 加總，計算其理論最佳單圈時間。
並將理論時間與實際桿位時間比較，計算「潛在差距」，揭示車手是否因失誤而未能榨出全部實力，或賽車在特定區段是否暗藏性能優勢。

## 5. 速度與彎角分析

### 5.1 直線速度
![PITWALL](/images/page06.png)
收集並比較主要直線末端的極速／測速點速度，反映空氣阻力水準與引擎動力。
此模組通常會過濾受 DRS 或強尾流（tow）影響的異常數據，以評估乾淨氣流中的真實直線性能，協助判斷下壓力設定是否過於激進。

### 5.2 煞車與加速性能
以散佈圖分析重煞區的減速性能，並比較出彎加速時累積的縱向 G 值。
這些指標與機械抓地力及煞車系統效能相關，可區分擅長走停型（stop-and-go）賽道的賽車，與在流暢彎道中更具優勢的賽車。

![PITWALL](/images/page08.png)

### 5.3 彎角性能分類
依速度將彎角分為低速、中速與高速三類，並計算各類彎角的平均最低彎心（apex）速度。
這能揭示賽車在不同空力負載狀態下的平衡表現——例如某支車隊可能在仰賴空力的高速彎極快，卻在依靠機械抓地力的低速彎陷入苦戰。

![PITWALL](/images/page07.png)

## 6. AI 預測模型

![PITWALL](/images/page09.png)
* **FP3/FP2 → 排位賽預測**
    收集練習賽圈速、輪胎配方與油載假設，透過迴歸模型預測每位車手在排位賽的潛在最快單圈。

* **排位賽 → 正賽預測**
    根據排位賽結果與各賽道的歷史超車難度係數，模擬正賽完賽名次分布，為策略提供期望值參考。

## 7. 跨季分析

### 7.1 歷史賽道地圖
![PITWALL](/images/page10.png)

此模組結合賽道地圖、海拔高度圖與逐年旗號統計表。透過 API 取得歷史事故的位置（X/Y 座標）與類型，並標示於賽道地圖上。
同時分析海拔變化，協助判斷事故熱點是否位於盲彎或坡頂路段。右側面板統計近四個賽季（2022–2025）的黃旗／紅旗／SC／VSC 次數，提供賽道安全特性的宏觀視角。

### 7.2 賽季起跑反應
![PITWALL](/images/page11.png)

聚焦車手整個賽季的起跑表現，採用 0–50 km/h 加速時間分布。
以箱型圖顯示反應／表現的中位數與穩定區間（IQR），並過濾雨戰起跑或起跑事故等極端案例，反映真實的平均起跑水準。支援車隊配色，方便比較隊友之間的差異。

## 8. 即時計時（Live Timing）

![PITWALL](/images/page12.png)

### 8.1 核心監控

* **排名塔（Ranking Tower）**
    高度最佳化的即時排行榜，顯示名次、車手代碼、輪胎資訊、區段時間（S1/S2/S3）與當前狀態（進站中／出場），並具備動畫排序與車隊配色。

* **賽道地圖**
    賽車在賽道上的即時位置。相較於靜態分析地圖，此檢視著重於相對位置與追逐態勢，並對領先集團做高亮顯示。

* **環形地圖（Circle Map）**
    將賽道抽象為一個圓環，以秒數視覺化車距。非常適合判斷 Safety Car 窗口或進站窗口是否安全。

* **賽道與天氣**
    頂部資訊列顯示賽事名稱、場次時間、圈數進度與賽道狀態（綠旗／黃旗／紅旗／SC／VSC）。第二列提供詳細天氣資訊：氣溫、賽道溫度、濕度、氣壓、風速與風向。

### 8.2 策略與處方

![PITWALL](/images/page15.png)

* **車手策略（Driver Strategy）**
    比較預測與實際的圈速曲線，包含預測區間、SC 區段與進站標記，以評估表現是否符合模型。

* **纏鬥洞察（Battle Insight）**
    針對選定的纏鬥配對進行深入分析，即時計算速度差、DRS 可用性與預測超車圈數。

* **追擊策略（Chase Strategy）**
    追擊計算器，根據圈速差與剩餘圈數，預測追擊車能否在比賽結束前進入 DRS 範圍。

* **進站窗口（Pit Window）**
    估算進站後的回場位置並標示於地圖上，計算時納入維修道時間損失與車流狀況。

* **輪胎策略（Tyre Strategy）**
    監控所有車手的胎齡與預測剩餘壽命。結合 Pirelli 衰退曲線，對潛在的性能斷崖（performance cliff）發出警示。

### 8.3 遙測與性能

![PITWALL](/images/page13.png)

* **即時遙測曲線**
    支援多車手比較的即時波形：
    * `speed_trace`：速度
    * `throttle_trace`：油門
    * `brake_trace`：煞車
    * `rpm_trace`：轉速
    * `gear_trace`：檔位
    * `drs_trace`：DRS 狀態

* **區段比較（Sector Comparison）**
    比較兩位車手在選定區段（S1/S2/S3）的時間差，採雙線設計，清楚呈現差距在何處產生。

* **SF% 歷史**
    Stint Fuel Saving Percentage（段落省油百分比）歷史紀錄。正值代表全力推進，負值代表 lift-and-coast 省油。顏色深淺（亮綠／暗綠）表示幅度大小。

* **極速歷史（Top Speed History）**
    逐圈極速表格。紫色文字標示個人極速，適合監控引擎模式與尾流效應。

### 8.4 歷史與統計

![PITWALL](/images/page14.png)

* **圈速歷史表格**
    四個獨立表格：`Lap Time`、`S1`、`S2`、`S3`。以熱力圖呈現每一圈，自動標示全場最佳（紫色）與個人最佳（綠色）。

* **圈速分布**
    視覺化全場車手的圈速分布。以最快圈為基準，縱軸繪製與領先者的差距，右側顯示輪胎配方，揭示集團結構與掉隊車手。

* **即時車流時間軸**
    熱力圖時間軸，依據與前車的距離，顯示每位車手每一圈處於「乾淨氣流」（綠色）或「車流之中」（橘色）。

* **車流距離（Traffic Distance）**
    量化車流比例與受影響圈數的統計表。此資料僅在 API-only 模式下由 JSON 提供。

### 8.5 其他

* **賽會控制（Race Control）**
    賽會控制訊息的即時串流，包括旗號變更、調查與處罰，並支援關鍵字篩選。
