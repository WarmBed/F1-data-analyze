# PITWALL

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | **日本語**

## これは何？

PitWall は **F1 データ分析**およびテレメトリー可視化ツールです。
レースエンジニア、シムレーサー、データファンが、実際のフォーミュラ1テレメトリーを使ってラップタイム、スロットル使用状況、スピードトレース、ドライバー比較を分析できます。



包括的なレースデータ分析機能を提供する、プロフェッショナル向けフォーミュラ1テレメトリー分析ワークステーションです。

![PITWALL](/images/page01.png)

## はじめに

### 動作環境

- Windows 10/11
- Python 3.10+（3.13 推奨）

### インストール

```powershell
git clone https://github.com/WarmBed/F1-data-analyze.git
cd F1-data-analyze
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### GUI の起動

```powershell
python f1t_gui_main.py
```

初回利用時は、ツールバーで年・レース・セッションを選択し、左側の機能ツリーから分析モジュールを開きます。テレメトリーデータは公開 F1 ソース（FastF1 / OpenF1）からダウンロードされ、ローカルにキャッシュされるため、セッションの初回読み込みには数分かかります。

### スタンドアロン EXE のビルド（オプション）

```powershell
.\build_tools\setup_venv_build.ps1     # one-time: create the build virtualenv
python build_tools\build_exe_gui.py    # build with PyInstaller
```

または `build_tools\一鍵建構EXE.bat` をダブルクリックするだけでもビルドできます。実行ファイルは `dist\` に出力されます。

## 1. ヒストリカル分析

このグループには、戦略、タイヤ、インシデント、コース・環境コンテキストを網羅する、レース後の詳細分析ツールが含まれます。

![PITWALL](/images/page02.png)

### 1.1 温度分析
このモジュールは、レースウィークエンド全体の環境データを可視化します。路面温度（Track Temp）と気温（Air Temp）に加えて、湿度、気圧、降雨のライブデータストリームを統合します。すべてを共通のタイムライン上に揃えることで、環境変数が特定のラップのラップタイム性能やタイヤデグラデーション傾向にどのように影響するかを正確に分析できます。

年とイベントの動的な切り替えに対応し、自動スケーリングする時間軸チャートを提供します。

### 1.2 トラック分析
このモジュールは高精度のサーキットマップを描画し、すべての公式コーナー番号と DRS 検知/作動ゾーンをラベル表示します。API のベクターデータを使ってトラック形状を描画し、ドライバーの走行ライン軌跡やテレメトリーレイヤー（速度ヒートマップなど）のオーバーレイに対応します。
GPS 座標を画面上の XY 描画座標にマッピングする座標変換ロジックを備えており、レーシングラインやコース特性の分析の基盤となるツールです。

### 1.3 ピットストップ分析
このモジュールは、チームサマリーと詳細ログの2つのビューで詳細なピットストップ分析を提供します。
各ドライバーのピットストップ回数、平均静止時間、合計ピットロス（イン/アウト＋静止時間）を計算します。通常のピットストップとドライブスルーを区別するスマートフィルターを備え、各ストップ前後のコンパウンド変更も表示します。


### 1.4 アクシデント＆フラッグ分析
このツールは、Yellow Flag、Red Flag、Virtual Safety Car（VSC）、Safety Car（SC）など、レース中断とレースコントロールイベントに焦点を当てます。これらのイベントをガントチャート形式のタイムラインで表示し、継続時間と発生ラップを示します。
レースのリズム変化、戦略の判断ポイント、有効なレーシングラップを理解するうえで極めて重要であり、特定の DNF 原因との関連付けも可能です。

### 1.5 タイヤ戦略分析
タイヤ使用戦略を分析するためのコアモジュールです。各ドライバーごとに直感的な横方向のスティントバーを使用します。各バーセグメントは1セットのタイヤを表し、色がコンパウンド（赤/黄/白/緑/青）に、セグメントの長さがスティント長に対応します。
内部では、スティントごとの平均ラップタイムとデグラデーション傾向を計算し、スティントが新品タイヤと中古タイヤのどちらで開始されたかをラベル表示します。これにより、チーム間で1ストップ戦略と複数ストップ戦略を素早く比較できます。

### 1.6 ドライバーポジション推移
このモジュールは、レース全体のポジションチャート（ポジション対ラップ）をプロットします。走行を続けている車両のポジション計算が正しく保たれるよう、DNF に対する特別な処理を含みます。
インタラクティブな凡例により、比較対象のドライバーを素早く絞り込めます — たとえばトップ3の争いや接戦の中団グループに注目できます。データは公式タイミングのラップごとのポジション記録から直接取得されます。

### 1.7 トラフィック分析
この高度なモジュールは、レース中に遭遇したトラフィック状況を定量化します。前後の車両とのギャップを計算することで、ドライバーがクリーンエアにいるのか、ダーティエア（乱気流）の影響を受けているのかを判定します。
結果は通常、ヒートマップやインターバルチャートとして表示され、レース距離のうち何パーセントでドライバーがブロックされていたかを強調します。これは真のペースの評価やピットウィンドウの選択に不可欠です。

## 2. テレメトリー分析
このグループは、ドライビングスタイルと車両性能の精密な比較のために、サンプリングレート（Hz）レベルの車両物理データ分析を提供します。
![PITWALL](/images/page03.png)

### 2.1 メインテレメトリー分析
システム内で最も強力なテレメトリーツールです。Speed、RPM、Gear、Throttle、Brake、DRS ステータスなど、複数チャンネルの同期表示に対応します。
高性能な描画エンジンを使用し、複数ドライバーのオーバーレイ比較に対応し、カーソル同期機能を備えています。1つのチャートでカーソルを動かすと、関連するすべてのチャートが同じ時点に更新されます。


### 2.2 チャンネル別分析
これらのモジュールは、特定の信号に最適化されたより深い分析ビューです。

* **スピード分析**
    * 速度曲線の詳細に焦点を当て、より細かい Y 軸スケーリングとスムージングにより、コーナーの最低速度やストレートエンドの最高速度を観察できます。

* **ブレーキ分析**
    * ブレーキ入力の圧力と持続時間を分析し、ブレーキングポイントとトレイルブレーキング技術を特定します。

* **スロットル分析**
    * スロットル開度の変化を調べます。特にコーナー立ち上がりでのトラクションコントロールやスロットル調整の研究に役立ちます。

* **ギア＆RPM**
    * 多くの場合併用され、シフトポイント、ギア比戦略、RPM レンジ全体にわたるエンジン出力特性を分析します。

* **加速度（汎用）**
    * 縦方向および横方向の加速度を計算して G-G ダイアグラムを生成します。タイヤのグリップ限界や総合的なコーナリング性能の評価に役立ちます。

### 2.3 デルタ分析
* 同一のトラック位置における2台の車両間の速度差を直接計算し、コーナーやストレートでどちらが速いかを示します。
* 速度デルタを積分して空間的な距離変化を推定します。追走中にギャップがどのように開閉するかの分析に役立ちます。
* 基準ラップに対する1周にわたる古典的なタイムデルタ曲線を提供し、どこでタイムを得て、どこで失っているかの特定に役立ちます。

## 3. ラップパフォーマンス
このグループは、ラップタイムの統計的特性、一貫性、ロングランパフォーマンスに焦点を当てます。
![PITWALL](/images/page04.png)

### 3.1 詳細ラップデータ
選択したドライバーの全ラップの詳細情報を一覧表示する、機能豊富なテーブルを提供します。列にはラップ番号、ラップタイム、セクタータイム（S1/S2/S3）、スピードトラップ、タイヤコンパウンドとタイヤ使用周回数が含まれます。
また、異常なラップ（イエローフラッグの影響を受けたラップ、ピットストップ後のアウトラップなど）をマークし、自己ベスト（緑）と全体ベスト（紫）を色分け表示するため、データ整合性チェックに最適なツールです。

### 3.2 ラップタイム箱ひげ図
箱ひげ図を使用してラップタイムの分布を可視化し、中央値、IQR、外れ値を表示します。
ピットラップやトラフィックの影響を受けたラップをフィルタリングして、真のレースペースと一貫性を反映できます。箱が狭いほど、ドライバーの一貫性が高いことを示します。

### 3.3 スロットル・コーナー分析
スロットルデータとコーナー情報を組み合わせます。特定のコーナー通過時の平均スロットル開度や全開率などの指標を計算し、箱ひげ図や折れ線グラフで可視化します。
ドライバーの自信、グリップ状況、コーナー立ち上がりでのスロットル操作 — ドライバーのコーナリング限界を示す重要な指標 — の評価に役立ちます。

### 3.4 ペダル挙動分析
![PITWALL](/images/page16.png)

このモジュールは、各ドライバーのペダル使用状態の分布を積み上げ棒グラフで表示します。システムはペダル挙動を4つの状態に分類します。
* **Throttle Only**：スロットルペダルのみが踏まれている状態。通常はストレートでの加速時や全開での立ち上がり時です。
* **Brake Only**：ブレーキペダルのみが踏まれている状態。コーナー進入前のハードブレーキングゾーンに対応します。
* **Trail Braking**：スロットルとブレーキが同時に操作されている状態。コーナー進入時のバランスを保ち、コーナリングスピードを最大化するために使われる高度なテクニックです。
* **Coasting**：どちらのペダルも踏まれていない状態。慣性での惰性走行、または燃料節約のためのリフト＆コーストを行っていることを示します。

### 3.5 ロングラン分析
FP2 のロングランシミュレーション分析向けに設計されています。連続した代表的な計測ラップを自動的に識別する**スティント検出アルゴリズム**を備えています。
コア機能として**燃料補正**があり、ラップごとに燃料重量の影響を除去して補正ラップタイムを推定することで、純粋なタイヤデグラデーション率を分離できます。これはレースのピットストップ戦略立案における重要なインプットです。

## 4. 理想ラップ＆セクター
このグループは、ベストセクタータイムを再構成して理論上の性能限界を探ります。
![PITWALL](/images/page05.png)

### 4.1 理想ラップランキング
セッション中の各ドライバーのベスト S1、S2、S3 を合計して、理論上のベストラップタイムを計算します。
理論タイムを実際のポールタイムと比較して「ポテンシャルギャップ」を算出し、ドライバーがミスによりタイムを取りこぼしたのか、あるいは特定のセクターに車両の隠れた性能の強みがあるのかを明らかにします。

## 5. スピード＆コーナー分析

### 5.1 ストレートラインスピード
![PITWALL](/images/page06.png)
主要なストレートエンドにおける最高速度／トラップスピードを収集して比較します。これは空気抵抗レベルとエンジンパワーを反映します。
このモジュールは通常、DRS や強いスリップストリームの影響を受けた異常データをフィルタリングし、クリーンエアでの本来のストレートライン性能を評価します。ダウンフォース設定が過度に攻めすぎていないかの判断に役立ちます。

### 5.2 ブレーキ＆加速性能
散布図を使ってハードブレーキングゾーンでの減速性能を分析し、コーナー立ち上がり加速時の累積縦 G を比較します。
これらの指標はメカニカルグリップやブレーキシステムの効果と相関しており、ストップ＆ゴー型サーキットで優れた車両と、流れるようなコーナーで強い車両を区別できます。

![PITWALL](/images/page08.png)

### 5.3 コーナー性能分類
コーナーを速度別に低速、中速、高速のカテゴリーに分類し、カテゴリーごとの平均最低エイペックススピードを計算します。
これにより、異なるエアロ負荷領域でのバランスが明らかになります — たとえば、あるチームは空力依存の高速コーナーでは非常に速い一方で、メカニカルグリップ頼みの低速コーナーでは苦戦する、といった傾向です。

## 6. AI 予測モデル

![PITWALL](/images/page09.png)
* **FP3/FP2 → 予選予測**
    プラクティスのラップタイム、タイヤコンパウンド、燃料搭載量の仮定を収集し、回帰モデルを用いて各ドライバーの予選における潜在的な最速ラップを予測します。

* **予選 → レース予測**
    予選結果と各サーキットの過去のオーバーテイク難易度係数に基づき、レースの最終順位分布をシミュレーションし、戦略のための期待値リファレンスを提供します。

## 7. マルチシーズン分析

### 7.1 ヒストリカルトラックマップ
![PITWALL](/images/page10.png)

このモジュールは、トラックマップ、高低差チャート、年別フラッグ統計テーブルを組み合わせています。API 経由で過去のインシデント発生位置（X/Y 座標）と種類を取得し、サーキットマップ上にマークします。
また、高低差の変化を分析して、インシデントの多発地点がブラインドコーナーや頂点を越える区間に位置するかどうかの特定に役立てます。右側のパネルには、直近4シーズン（2022–2025）の Yellow/Red/SC/VSC の件数がまとめられ、コースの安全特性をマクロな視点で把握できます。

### 7.2 シーズンスタートリアクション
![PITWALL](/images/page11.png)

シーズンを通したドライバーのスタートパフォーマンスに焦点を当て、0–50 km/h の加速タイム分布を使用します。
箱ひげ図により、リアクション／パフォーマンスの中央値と安定性の範囲（IQR）を表示します。雨天スタートやスタート時のインシデントによる極端なケースをフィルタリングし、真の平均的スタートパフォーマンスを反映します。チームカラーのスタイリングに対応しており、チームメイト間の比較が容易です。

## 8. ライブタイミング

![PITWALL](/images/page12.png)

### 8.1 コアモニタリング

* **Ranking Tower**
    高度に最適化されたライブリーダーボード。ポジション、ドライバーコード、タイヤ情報、セクタータイム（S1/S2/S3）、現在の状態（Pitting/Out）を、アニメーション付きソートとチームカラーで表示します。

* **Track Map**
    サーキット上のライブカーポジション。静的な分析マップと比べて、相対位置と追走のダイナミクスに焦点を当て、先頭グループのハイライト表示を備えます。

* **Circle Map**
    サーキットをリングに抽象化し、ギャップを秒単位で可視化します。Safety Car ウィンドウやピットウィンドウが安全かどうかの判断に最適です。

* **Track & Weather**
    イベント名、セッション時間、ラップ進行状況、トラックステータス（緑/黄/赤/SC/VSC）を表示する上部情報バー。2行目には詳細な気象情報（気温、路面温度、湿度、気圧、風速、風向）を表示します。

### 8.2 戦略＆処方

![PITWALL](/images/page15.png)

* **Driver Strategy**
    予測ラップタイム曲線と実際の曲線を比較します。予測レンジ、SC 区間、ピットマーカーを含み、パフォーマンスがモデルと一致しているかを評価します。

* **Battle Insight**
    選択したバトルペアの深掘り分析。速度デルタ、DRS の利用可否、予測オーバーテイクラップをリアルタイムで計算します。

* **Chase Strategy**
    ラップタイムデルタと残り周回数に基づき、追走車がレース終了前に DRS 圏内に入れるかどうかを予測する追走計算機です。

* **Pit Window**
    ピットストップ後の復帰ポジションを推定してマップ上にマークします。ピットレーンでのタイムロスとトラフィック状況を考慮します。

* **Tyre Strategy**
    全ドライバーのタイヤ使用周回数と予測残存寿命を監視します。Pirelli のデグラデーション曲線と組み合わせて、性能急落（パフォーマンスクリフ）の可能性を警告します。

### 8.3 テレメトリー＆パフォーマンス

![PITWALL](/images/page13.png)

* **リアルタイムテレメトリートレース**
    複数ドライバー比較対応のライブ波形：
    * `speed_trace`: 速度
    * `throttle_trace`: スロットル
    * `brake_trace`: ブレーキ
    * `rpm_trace`: RPM
    * `gear_trace`: ギア
    * `drs_trace`: DRS 状態

* **Sector Comparison**
    選択したセクター（S1/S2/S3）における2人のドライバーのデルタを比較します。デュアルラインデザインにより、どこでギャップが生まれているかが明確にわかります。

* **SF% History**
    スティント燃料節約率（Stint Fuel Saving Percentage）の履歴。正の値はプッシュを、負の値はリフト＆コーストによる燃料節約を示します。色の濃淡（明るい緑/暗い緑）が大きさを表します。

* **Top Speed History**
    ラップごとの最高速度テーブル。紫色のテキストは自己最高速度を示し、エンジンモードやスリップストリーム効果の監視に役立ちます。

### 8.4 履歴＆統計

![PITWALL](/images/page14.png)

* **Lap History Tables**
    `Lap Time`、`S1`、`S2`、`S3` の4つの独立したテーブル。全ラップのヒートマップテーブルで、全体ベスト（紫）と自己ベスト（緑）を自動マークします。

* **Lap Time Distribution**
    全車のラップタイム分布を可視化します。最速ラップを基準として、リーダーとのギャップを縦軸にプロットし、右側にタイヤコンパウンドを表示することで、グループ構造や後退したドライバーを明らかにします。

* **Live Traffic Timeline**
    前方車両との距離に基づき、各ドライバーがラップごとに「クリーンエア」（緑）か「トラフィック」（オレンジ）のどちらにいるかを示すヒートマップタイムラインです。

* **Traffic Distance**
    トラフィック比率と影響を受けたラップ数を定量化する統計テーブルです。データは API 専用モードでのみ JSON から利用可能です。

### 8.5 その他

* **Race Control**
    フラッグ変更、審議、ペナルティなどのレースコントロールメッセージのライブストリーム。キーワードフィルタリングに対応します。
