# Las Vegas 賽道訓練異常報告

## 🚨 問題摘要

Las Vegas 賽道的 XGBoost 訓練模型出現**極端特徵重要性異常**：
- **100% mid_speed_apex**（中速彎心速度）
- **0% 所有其他 16 個特徵**

## 📊 訓練統計

| 指標 | 數值 | 狀態 |
|------|------|------|
| 樣本數 | 40 | ⚠️  偏少 |
| 訓練 R² | 0.0182 | 🔴 極低（接近 0） |
| 訓練 MAE | 1.0398s | - |
| CV MAE | 1.1567s | - |

**R² = 0.0182** 表示模型幾乎**完全無法解釋目標變量的變異性**。

## 🔍 診斷分析

### 原因 1：數據樣本不足
- Las Vegas 只有 **40 筆訓練樣本**
- 相比其他賽道（通常 60-80 筆），數據量偏少
- XGBoost 在小數據集上容易過度簡化，僅依賴單一特徵

### 原因 2：特徵與目標變量無關
- R² 接近 0 表示所有特徵（包括 ideal_s1/s2/s3）與 Q 時間**幾乎無相關性**
- 可能是數據收集問題（FP3 與 Q 會話數據不一致）

### 原因 3：Las Vegas 賽道特殊性
- 新賽道（2023 年首次舉辦），歷史數據有限
- 夜間賽事，溫度、輪胎表現與其他賽道差異大
- 長直線為主的賽道特性，導致其他特徵（如彎道速度）重要性降低

## 🔄 重新訓練嘗試結果

已執行 500 trials 的 Optuna 超參數優化，結果：
```
[Optuna] 最佳 CV MAE: 1.157s (來自 500 trials)
[訓練結果] R² 0.0182, MAE 1.040s
```

**結論：重新訓練無法解決問題**，R² 依然極低，特徵重要性依然 100% 單一特徵。

## 💡 建議解決方案

### 短期方案：標記異常
在報告中標註 Las Vegas 為**數據質量警告**：
- ⚠️  **數據警告**：Las Vegas 訓練樣本不足（40 筆），模型 R²=0.02，預測可靠性低
- 特徵重要性數據可能不代表實際賽道特性

### 長期方案：數據改進
1. **增加歷史賽季數據**：
   - Las Vegas 首次舉辦於 2023 年
   - 隨著 2024、2025 賽季數據累積，樣本數會增加

2. **檢查數據品質**：
   - 確認 FP3 與 Q 會話數據的一致性
   - 檢查是否有異常值或缺失數據

3. **特徵工程**：
   - 針對長直線賽道（Las Vegas、Monza）設計專門特徵
   - 考慮加入夜間賽事的溫度修正係數

4. **模型調整**：
   - 對小樣本賽道使用正則化更強的模型
   - 考慮使用集成學習（ensemble）融合多個賽道的模型
