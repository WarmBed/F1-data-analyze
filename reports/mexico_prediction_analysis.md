## 3. 根本原因分析

### 3.1 可能原因

1. **賽道改建影響**（2022 年）
   - 2022 年 Mexico 賽道修改了多個彎道配置
   - 實測：2022 前後時間差異 +0.682s
   - 結論：改建顯著影響圈速，應分開訓練

2. **高海拔特殊性**
   - Mexico City 海拔 2,250 米（全賽曆最高）
   - 空氣密度僅海平面的 75%
   - 引擎功率損失 ~15%，下壓力減少 ~25%
   - 不同引擎供應商受影響程度不同

3. **測試集樣本不具代表性**
   - 最大誤差主要集中在：{2021: np.int64(3), 2019: np.int64(2), 2022: np.int64(2), 2024: np.int64(2), 2018: np.int64(1)}
   - 可能測試集包含極端天氣或賽道狀況樣本

## 4. 改進建議

### 4.1 短期方案（立即實施）

#### 方案 A：分年訓練
```python
# 訓練兩個獨立模型
model_mexico_2018_2021 = train(data[data['year'] < 2022])
model_mexico_2022_2024 = train(data[data['year'] >= 2022])

# 預測時根據年份選擇模型
if year < 2022:
    prediction = model_mexico_2018_2021.predict(features)
else:
    prediction = model_mexico_2022_2024.predict(features)
```

#### 方案 B：新增高海拔特徵
```python
# 新增 Mexico 特有特徵
features['altitude'] = 2250  # 海拔（米）
features['air_density_ratio'] = 0.75  # 相對海平面
features['engine_power_loss'] = 0.15  # 功率損失比例
features['downforce_reduction'] = 0.25  # 下壓力減少比例
```

#### 方案 C：移除極端值
```python
# 使用 IQR 方法移除異常值
Q1 = df['q_time'].quantile(0.25)
Q3 = df['q_time'].quantile(0.75)
IQR = Q3 - Q1
df_cleaned = df[
    (df['q_time'] >= Q1 - 1.5*IQR) & 
    (df['q_time'] <= Q3 + 1.5*IQR)
]
```

### 4.2 中期方案（1-2 週）

1. **引擎供應商特徵**
   - 新增 `engine_manufacturer` 特徵（Mercedes, Ferrari, Renault, Honda）
   - 高海拔下不同引擎性能差異大

2. **輪胎策略特徵**
   - Mexico 輪胎磨損率與其他賽道不同
   - 新增 FP3 輪胎使用狀況特徵

### 4.3 長期方案（1-2 月）

1. **賽道特定集成學習**
   - 結合多個 Mexico 子模型（按年份、引擎、車隊）
   - 加權平均預測結果

2. **遷移學習**
   - 從其他高速賽道遷移知識
   - 使用賽道相似度矩陣輔助訓練

## 5. 結論

### 5.1 核心發現

1. **R2 負值原因確認**：
   - 2022 賽道改建導致數據不一致
   - 高海拔特性未被模型充分學習
   - 測試集可能包含極端樣本

2. **訓練 MAE vs 測試 MAE 差距大**：
   - 訓練 MAE: 0.016s （模型過擬合）
   - 測試 MAE: 0.973s （泛化能力差）
