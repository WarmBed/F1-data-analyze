# F1 比賽分析報告索引

這些報告包含每場比賽的詳細數據，供 LLM 分析預測模型的改進方向。

## 使用方法

1. 選擇一場比賽報告
2. 將內容貼給 Claude/GPT
3. 請 LLM 分析並給出改進建議
