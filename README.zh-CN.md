[English](README.md) | [繁體中文](README.zh-TW.md) | **简体中文** | [日本語](README.ja.md)

## 这是什么？

PitWall 是一款 **F1 数据分析**与遥测可视化工具。
它让赛道工程师、模拟赛车手和数据爱好者能够使用真实的一级方程式遥测数据，分析圈速、油门使用、速度曲线以及车手对比。



一款专业的一级方程式遥测分析工作站，提供全面的赛事数据分析能力。

![PITWALL](/images/page01.png)

## 快速开始

### 环境需求

- Windows 10/11
- Python 3.10+（推荐 3.13）

### 安装

```powershell
git clone https://github.com/WarmBed/F1-data-analyze.git
cd F1-data-analyze
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 启动 GUI

```powershell
python f1t_gui_main.py
```

首次使用时，请在工具栏中选择年份 / 赛事 / 会话，并从左侧功能树打开分析模块。遥测数据来自公开的 F1 数据源（FastF1 / OpenF1）并缓存到本地，因此首次加载一个会话需要几分钟。

### 构建独立 EXE（可选）

```powershell
.\build_tools\setup_venv_build.ps1     # one-time: create the build virtualenv
python build_tools\build_exe_gui.py    # build with PyInstaller
```

或者直接双击 `build_tools\一鍵建構EXE.bat`。可执行文件将输出到 `dist\`。

## 1. 历史分析

本组包含深入的赛后分析工具，涵盖策略、轮胎、事故以及赛道/环境背景。

![PITWALL](/images/page02.png)

### 1.1 温度分析
该模块可视化整个比赛周末的环境数据。除赛道温度（Track Temp）和气温（Air Temp）外，还整合了湿度、气压和降雨的实时数据流。通过将所有数据对齐到同一时间轴，您可以精确分析环境变量如何影响特定圈次的圈速表现或轮胎衰退趋势。

支持动态切换年份和赛事，并提供自动缩放的时间轴图表。

### 1.2 赛道分析
该模块渲染高精度赛道地图，并标注所有官方弯道编号以及 DRS 检测区/启用区。它使用来自 API 的矢量数据绘制赛道几何形状，并支持叠加车手行驶轨迹或遥测图层（例如速度热力图）。
它包含坐标转换逻辑，可将 GPS 坐标映射为屏幕上的 XY 绘图坐标，是分析行车线和赛道特性的基础工具。

### 1.3 进站分析
该模块提供详细的进站分析，包含两种视图：车队汇总和详细记录。
它计算每位车手的进站次数、平均静止时间以及总进站损失（进出站 + 静止时间）。模块内置智能过滤器，可区分正常进站与通过维修区处罚（drive-through），并显示每次进站前后的轮胎配方变化。


### 1.4 事故与旗帜分析
该工具聚焦于比赛中断与赛会控制事件，包括黄旗（Yellow Flag）、红旗（Red Flag）、虚拟安全车（VSC）和安全车（SC）。它以甘特图风格的时间轴呈现这些事件，显示持续时间及发生的圈次。
这对于理解比赛节奏变化、策略决策点和有效比赛圈数至关重要，并可与特定的 DNF（退赛）原因相关联。

### 1.5 轮胎策略分析
这是分析轮胎使用策略的核心模块。它为每位车手使用直观的水平 stint（轮胎使用段）条形图：每个条形段代表一套轮胎，颜色对应轮胎配方（红/黄/白/绿/蓝），段长对应该 stint 的长度。
模块内部计算每个 stint 的平均圈速与衰退趋势，并标注该 stint 使用的是新胎还是旧胎。这使您能快速比较各车队的一停与多停策略。

### 1.6 车手位置走势
该模块绘制整场比赛的位置图（位置 vs 圈数）。它对 DNF 做了特殊处理，确保仍在比赛中的赛车位置计算正确。
交互式图例可快速筛选车手进行对比——例如聚焦前三名的争夺或胶着的中游大战。数据直接来源于官方逐圈计时位置记录。

### 1.7 交通流量分析
这一高级模块量化比赛中遇到的交通状况。通过计算与前后车的间隔，判断车手处于干净气流（clean air）中，还是受到乱流/尾流（dirty air/wake）的影响。
结果通常以热力图或间隔图呈现，突出显示车手在多少比例的比赛里程中被阻挡。这对于评估真实速度和进站窗口选择至关重要。

## 2. 遥测分析
本组提供采样率（Hz）级别的车辆物理数据分析，用于精确对比驾驶风格与赛车性能。
![PITWALL](/images/page03.png)

### 2.1 主遥测分析
系统中最强大的遥测工具。支持同步显示多个通道，包括速度（Speed）、转速（RPM）、挡位（Gear）、油门（Throttle）、刹车（Brake）和 DRS 状态。
它采用高性能绘图引擎，支持多车手叠加对比，并内置游标同步功能：在一个图表中移动游标，所有相关图表都会更新到同一时间点。


### 2.2 通道专项分析
这些模块是针对特定信号的优化深入视图：

* **速度分析**
    * 聚焦速度曲线细节，提供更精细的 Y 轴缩放与平滑处理，便于观察弯心最低速度和直道末端极速。

* **刹车分析**
    * 分析刹车输入压力与持续时间，识别刹车点和拖刹（trail-braking）技巧。

* **油门分析**
    * 检视油门开度变化，尤其适用于研究牵引力控制与出弯时的油门调节。

* **挡位与转速**
    * 通常结合使用，分析换挡点、齿比策略以及发动机在不同转速区间的输出特性。

* **加速度（通用）**
    * 计算纵向与横向加速度以生成 G-G 图，可用于评估轮胎抓地力极限和整体过弯性能。

### 2.3 Delta 分析
* 直接计算两辆车在同一赛道位置上的速度差，显示谁在弯道/直道更快。
* 对速度差进行积分以估算空间距离变化，可用于分析追逐过程中差距如何拉开或缩小。
* 提供经典的相对于参考圈的单圈时间差曲线，帮助识别时间在何处获得或损失。

## 3. 圈速表现
本组聚焦于圈速的统计特性、稳定性以及长距离（long-run）表现。
![PITWALL](/images/page04.png)

### 3.1 详细单圈数据
提供功能丰富的表格，列出所选车手每一圈的详细信息。列包括圈数、圈速、分段时间（S1/S2/S3）、测速点速度、轮胎配方与胎龄。
它还会标记异常圈（例如受黄旗影响的圈、进站后的出站圈），并以颜色区分个人最佳（绿色）和全场最佳（紫色），是进行数据完整性检查的首选工具。

### 3.2 圈速箱形图
使用箱形图可视化圈速分布，显示中位数、四分位距（IQR）和离群值。
这有助于过滤进站圈或受交通影响的圈，反映真实的比赛节奏与稳定性。箱体越窄，表示车手越稳定。

### 3.3 油门弯道分析
将油门数据与赛道弯道相结合。它计算通过特定弯道的平均油门开度或全油门比例等指标，并以箱形图或折线图可视化。
这有助于评估车手信心、抓地力状况以及出弯油门运用——这些都是衡量车手过弯极限的关键指标。

### 3.4 踏板行为分析
![PITWALL](/images/page16.png)

该模块使用堆叠条形图呈现每位车手的踏板使用状态分布。系统将踏板行为分为四种状态：
* **仅油门（Throttle Only）**：只踩油门踏板，通常出现在直线加速或全油门出弯时。
* **仅刹车（Brake Only）**：只踩刹车踏板，对应入弯前的重刹区。
* **拖刹（Trail Braking）**：油门与刹车同时操作。这是一项高级技巧，用于在入弯时保持车身平衡并最大化过弯速度。
* **滑行（Coasting）**：两个踏板都未踩下，表示车手依靠惯性滑行，或正在执行 Lift and Coast（收油滑行）以节省燃油。

### 3.5 长距离分析
专为 FP2 长距离模拟分析设计。它包含一个 **stint 检测算法**，可自动识别连续且具有代表性的计时圈。
核心能力包括**燃油修正**：逐圈剔除燃油重量影响以估算修正后的圈速，从而分离出纯粹的轮胎衰退速率。这是制定正赛进站策略的关键输入。

## 4. 理想圈与分段
本组通过重组最佳分段时间，探索理论性能极限。
![PITWALL](/images/page05.png)

### 4.1 理想圈排名
通过将每位车手在该会话中的最佳 S1、S2、S3 相加，计算其理论最佳圈速。
它将理论时间与实际杆位时间进行比较并计算"潜在差距"，揭示车手是否因失误而留有余地，或赛车在特定分段是否拥有隐藏的性能优势。

## 5. 速度与弯道分析

### 5.1 直线速度
![PITWALL](/images/page06.png)
收集并比较关键直道末端的极速/测速点速度。这反映了空气阻力水平和发动机功率。
该模块通常会过滤掉受 DRS 或强尾流牵引影响的异常数据，以评估干净气流中的固有直线性能，帮助判断下压力设定是否过于激进。

### 5.2 刹车与加速性能
使用散点图分析重刹区的减速性能，并比较出弯加速时累积的纵向 G 值。
这些指标与机械抓地力和刹车系统效能相关，可区分擅长走停型（stop-and-go）赛道的赛车与在流畅弯道中更强的赛车。

![PITWALL](/images/page08.png)

### 5.3 弯道性能分类
按速度将弯道分为低速、中速和高速三类，并计算每类弯道的平均最低弯心速度。
这揭示了赛车在不同空气动力负载状态下的平衡性——例如，某车队可能在依赖空气动力学的高速弯极快，但在依赖机械抓地力的低速弯中表现挣扎。

## 6. AI 预测模型

![PITWALL](/images/page09.png)
* **FP3/FP2 → 排位赛预测**
    收集练习赛圈速、轮胎配方和燃油载量假设，然后使用回归模型预测每位车手在排位赛中的潜在最快圈速。

* **排位赛 → 正赛预测**
    基于排位赛结果和各赛道的历史超车难度系数，模拟正赛完赛名次分布，为策略提供期望值参考。

## 7. 多赛季分析

### 7.1 历史赛道地图
![PITWALL](/images/page10.png)

该模块结合了赛道地图、海拔高度图和逐年旗帜统计表。它通过 API 获取历史事故位置（X/Y 坐标）和类型，并在赛道地图上标注。
它还分析海拔变化，帮助识别事故热点是否位于盲弯或坡顶路段。右侧面板汇总了过去四个赛季（2022–2025）的黄旗/红旗/SC/VSC 次数，提供赛道安全特性的宏观视角。

### 7.2 赛季起步反应
![PITWALL](/images/page11.png)

聚焦车手在整个赛季中的起步表现，使用 0–50 km/h 加速时间分布。
它使用箱形图显示反应/表现的中位数及稳定性范围（IQR）。这可以过滤掉雨天起步或起步事故等极端情况，反映真实的平均起步表现。支持车队配色样式，便于队友间对比。

## 8. 实时计时（Live Timing）

![PITWALL](/images/page12.png)

### 8.1 核心监控

* **排名塔（Ranking Tower）**
    高度优化的实时排行榜，显示名次、车手代码、轮胎信息、分段时间（S1/S2/S3）和当前状态（进站中/出站中），并带有动画排序和车队配色。

* **赛道地图（Track Map）**
    赛车在赛道上的实时位置。与静态分析地图相比，它聚焦于相对位置与追逐动态，并突出显示领先集团。

* **环形地图（Circle Map）**
    将赛道抽象为环形，以秒为单位可视化间隔。这非常适合判断安全车窗口或进站窗口是否安全。

* **赛道与天气（Track & Weather）**
    顶部信息栏显示赛事名称、会话时间、圈数进度和赛道状态（绿/黄/红/SC/VSC）。第二行提供详细天气信息：气温、赛道温度、湿度、气压、风速和风向。

### 8.2 策略与处方

![PITWALL](/images/page15.png)

* **车手策略（Driver Strategy）**
    对比预测与实际圈速曲线，包括预测区间、SC 区域和进站标记，以评估表现是否符合模型。

* **对决洞察（Battle Insight）**
    针对所选对决组合的深入分析，实时计算速度差、DRS 可用性和预测超车圈数。

* **追击策略（Chase Strategy）**
    一个追击计算器，基于圈速差和剩余圈数，预测追击的赛车能否在比赛结束前进入 DRS 范围。

* **进站窗口（Pit Window）**
    估算进站后的回场位置并在地图上标注，综合考虑维修区时间损失和交通状况。

* **轮胎策略（Tyre Strategy）**
    监控所有车手的胎龄和预测剩余寿命。结合 Pirelli 衰退曲线，对潜在的性能悬崖发出预警。

### 8.3 遥测与性能

![PITWALL](/images/page13.png)

* **实时遥测曲线（Real-time Telemetry Traces）**
    支持多车手对比的实时波形：
    * `speed_trace`：速度
    * `throttle_trace`：油门
    * `brake_trace`：刹车
    * `rpm_trace`：转速
    * `gear_trace`：挡位
    * `drs_trace`：DRS 状态

* **分段对比（Sector Comparison）**
    对比两位车手在所选分段（S1/S2/S3）的时间差，双线设计清晰显示差距在何处产生。

* **SF% 历史（SF% History）**
    Stint 燃油节省百分比历史。正值表示推进（pushing），负值表示收油滑行省油（lift-and-coast）。颜色深浅（亮绿/暗绿）表示幅度大小。

* **极速历史（Top Speed History）**
    逐圈极速表格。紫色文字标记个人最高速度，可用于监控发动机模式和尾流牵引效果。

### 8.4 历史与统计

![PITWALL](/images/page14.png)

* **单圈历史表格（Lap History Tables）**
    四个独立表格：`Lap Time`、`S1`、`S2`、`S3`。逐圈热力图表格，自动标记全场最佳（紫色）和个人最佳（绿色）。

* **圈速分布（Lap Time Distribution）**
    可视化全场圈速分布。以最快圈为基准，纵轴绘制与领先者的差距，右侧显示轮胎配方，揭示集团结构与掉队车手。

* **实时交通时间轴（Live Traffic Timeline）**
    热力图时间轴，基于与前车的距离，逐圈显示每位车手处于"干净气流"（绿色）还是"交通拥堵"（橙色）状态。

* **交通距离（Traffic Distance）**
    量化交通比例和受影响圈数的统计表。该数据仅在 API-only 模式下从 JSON 中可用。

### 8.5 其他

* **赛会控制（Race Control）**
    赛会控制消息的实时流，包括旗帜变化、调查和处罚，支持关键词过滤。
