## 🚀 快速測試流程

### Step 1: 啟動程式
```powershell
python f1t_gui_main.py
```

### Step 2: 開啟 Detailed Lap Analysis
1. 在左側樹狀選單中找到 `Detailed Lap Analysis`
2. 右鍵點擊 → 執行分析
3. 選擇賽事參數（例如：2025 Singapore R）
4. 確認選擇 `Detailed Lap Analysis` 圖表類型

### Step 3: 測試圖例顯示
- 檢查圖例右上角是否只顯示 5 個標記（無 T 和 W）

### Step 4: 測試拖移功能
1. 將滑鼠移到圖例上
2. 觀察游標變化（🖐️）
3. 按住左鍵拖移到左下角
4. 觀察游標變化（✊）
5. 釋放滑鼠

### Step 5: 測試雙擊切換
1. 雙擊圖例
2. 確認僅顯示車手列表
3. 再次雙擊
4. 確認恢復完整顯示

## 🐛 常見問題排查

### Q1: 雙擊沒有反應
**可能原因**: 點擊位置不在圖例區域內  
**解決方案**: 確保雙擊在圖例白色背景區域內

### Q2: 拖移後圖例消失
**可能原因**: 邊界限制邏輯錯誤  
**解決方案**: 回報此 Bug，圖例應該始終可見

### Q3: 游標沒有變化
**可能原因**: 滑鼠懸停位置不正確  
**解決方案**: 確保滑鼠在圖例範圍內
