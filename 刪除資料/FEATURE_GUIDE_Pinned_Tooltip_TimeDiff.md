# ✅ 功能指南：固定 Tooltip 與時間差顯示

**功能版本**: v1.0  
**實現日期**: 2025-10-07  
**影響模組**: Detailed Lap Analysis - 圖表組件  
**功能狀態**: ✅ **已完成**

---

## 📋 功能概述

### 新增功能列表

1. ✅ **滑鼠懸停 Tooltip**（淺黃色）
   - 顯示圈數和圈速時間
   - 懸停時立即顯示，無延遲

2. ✅ **左鍵固定 Tooltip**（淺藍色）
   - 點擊數據點可固定 Tooltip
   - 最多固定 2 個點
   - 超過 2 個時自動移除最舊的

3. ✅ **右鍵清除固定**
   - 右鍵點擊清除所有固定的 Tooltip
   - 同時清空時間差顯示

4. ✅ **時間差計算與顯示**
   - 固定 2 個點時，在 Clear 按鈕旁顯示時間差
   - 自動格式化（分:秒.毫秒 或 秒.毫秒）

## 🎮 操作指南

### 1. 查看圈速資訊（懸停模式）

**操作步驟**:
1. 將滑鼠移到圖表中的任意數據點附近（20px 內）
2. 系統自動顯示：
   - 🔴 紅色圓圈高亮（視覺反饋）
   - 💛 淺黃色 Tooltip（圈速資訊）

**Tooltip 內容**:
```
HAM - Lap 35
Lap Time: 1:38.456
```

**視覺反饋**:
- 懸停點：紅色圓圈（12px 半徑）
- Tooltip：淺黃色背景（230 透明度）
- 位置：數據點右上方（智能避開視窗邊界）

---

### 2. 固定圈速資訊（左鍵點擊）

**操作步驟**:
1. 將滑鼠移到想固定的數據點
2. **左鍵點擊**數據點
3. Tooltip 固定並變色為淺藍色

**固定限制**:
- 最多固定：**2 個**點
- 超過限制：自動移除最舊的固定點
- 重複固定：系統忽略（控制台顯示警告）

**視覺變化**:
- 固定點：🔵 藍色圓圈（12px 半徑）
- 固定 Tooltip：💙 淺藍色背景（230 透明度）
- 位置：保持在固定位置（不隨滑鼠移動）

**控制台輸出**:
```
[TOOLTIP] 📌 已固定 Tooltip (1/2)
[TOOLTIP] 📌 已固定 Tooltip (2/2)
```

---

### 3. 查看時間差（固定 2 個點）

**自動觸發條件**:
- 固定點數量 = 2

**顯示位置**:
- Clear 按鈕旁邊
- 藍色粗體文字

**顯示格式**:

| 時間差 | 顯示格式 | 範例 |
|--------|----------|------|
| < 1 分鐘 | `Diff: +秒.毫秒s` | `Diff: +3.456s` |
| ≥ 1 分鐘 | `Diff: +分:秒.毫秒` | `Diff: +1:23.456` |

**控制台輸出**:
```
[TOOLTIP] ⏱️ 時間差: +3.456s
```

---

### 4. 清除固定點（右鍵點擊）

**操作步驟**:
1. 在圖表任意位置**右鍵點擊**
2. 所有固定的 Tooltip 立即清除
3. 時間差顯示清空

**效果**:
- 🗑️ 所有藍色圓圈和固定 Tooltip 消失
- 時間差標籤清空
- 懸停 Tooltip 仍正常運作

**控制台輸出**:
```
[TOOLTIP] 🗑️ 已清除所有固定 Tooltip
```

## 🔧 技術實現

### 架構設計

**信號-槽機制**:
```python
LaptimeChartWidget
    ↓ (發射信號)
pinned_tooltips_changed(int count, str diff_text)
    ↓ (連接到)
DriverSelectionWidget._on_pinned_changed()
    ↓ (更新)
time_diff_label.setText(diff_text)
```

**關鍵方法**:

1. **`_pin_tooltip()`** - 固定 Tooltip
   - 檢查是否重複固定
   - 管理最大固定數量（2 個）
   - 提取圈速時間
   - 發射變化信號

2. **`_update_time_diff_display()`** - 更新時間差
   - 計算兩個固定點的時間差
   - 格式化時間字串
   - 發射 `pinned_tooltips_changed` 信號

3. **`get_pinned_time_diff()`** - 獲取時間差
   - 驗證固定點數量 = 2
   - 計算絕對時間差
   - 格式化輸出

4. **`_draw_custom_tooltip()`** - 繪製 Tooltip
   - 支援懸停/固定模式
   - 智能位置調整（避開邊界）
   - 多行文字支援

## 📊 數據流程

### 固定點數據結構

```python
pinned_data = {
    'point': ChartDataPoint,      # 原始數據點對象
    'screen_pos': QPoint,          # 螢幕座標（用於繪製）
    'text': str,                   # Tooltip 文字內容
    'lap_time': float              # 圈速秒數（用於計算時間差）
}
```

### 時間差計算邏輯

```python
# 提取兩個固定點的圈速
time1 = pinned_tooltips[0]['lap_time']  # 例如: 98.456 秒
time2 = pinned_tooltips[1]['lap_time']  # 例如: 101.912 秒

# 計算絕對時間差
diff = abs(time2 - time1)  # 3.456 秒

# 格式化
if diff >= 60:
    minutes = int(diff // 60)
    seconds = diff % 60
    return f"+{minutes}:{seconds:06.3f}"  # +1:23.456
else:
    return f"+{diff:.3f}s"  # +3.456s
```

## 📝 已知限制

### 限制 1: 固定點數量

- **限制**: 最多固定 2 個點
- **原因**: 避免圖表過於混亂，且時間差計算只支援兩點
- **解決方案**: 右鍵清除後重新選擇

---

### 限制 2: 時間差只顯示絕對值

- **限制**: 時間差顯示為絕對值（例如 +3.456s），不顯示方向
- **原因**: 簡化計算，避免混淆
- **解決方案**: 用戶需自行判斷哪個圈更快

---

### 限制 3: 固定點位置不可調整

- **限制**: 固定後的 Tooltip 位置固定，無法拖移
- **原因**: 技術實現複雜度
- **解決方案**: 右鍵清除後重新固定，Tooltip 會根據數據點位置重新計算
